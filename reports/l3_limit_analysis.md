# L3 互补层第一块砖：极限分析，以及它跑出来的 Patton 剪胀律（2026-09-21）

L5 的 TIA 首枪只能给**剪胀比**——一个几何/运动学量。要给"承载力"就得有力学。
但写整套 DDA 时间步进既重复 bdda2 又答非所问：**极限分析直接给出破坏荷载，不需要时间步进。**

## 结构：静力下限与运动上限由同一次求解同时给出

下限定理（静力）写成线性规划：

```
max α   s.t.   Σ_ij λ_ij w_ij + W_dead + α·W_live = 0 ,  λ ≥ 0
```

w_ij 是第 i 个接触第 j 条摩擦锥棱的旋量。而这个 LP 的**对偶解就是破坏机构**：
对偶可行性 yᵀw ≥ 0 正是"虚速度场不得贯入任何接触"，强对偶 α* = −yᵀW_dead 就是
上限定理的功率平衡。**所以这一层自带校验：下限必须等于上限，不等就是错。**

与盖系统的接口在这里咬合：约束 yᵀw ≥ 0 的那组法向，正是盖枚举输出的**完备清单**。
"机构不得进入入口块"就是这里的运动学容许条件——L1 与 L3 不是并列的两层，是同一件事的两面。

## 经典算例：滑动 vs 倾覆

宽 2、高 3、自重 10 的方块放在地面，水平力作用在顶部。解析解 α* = min(μW, Ww/(2h))，
分界在 μ = w/(2h) = 1/3。

九个摩擦系数逐点吻合到 1e-9，**而且破坏模式是从对偶解读出来的**：

- μ < 1/3：机构 ω = 0（平动），两个角都受力；而且 v_y = μ·v_x——**关联流动，剪胀角等于摩擦角**
- μ > 1/3：机构 ω ≠ 0，右趾速度恰为零（绕趾转动），活动接触只剩右趾

两件事：

**一、跨层交叉验证。** 无摩擦时横向承载比**精确等于 2·amp**，也就是 L5 三天前用
入口块几何 + 对偶数算出的剪胀比。**静力 LP 与入口块几何是两条毫无共用代码的路径，
给出同一个闭式答案。** 这是本项目目前最强的一次验证。

**二、引擎自己跑出了 Patton 剪胀律。** 带摩擦时承载比精确等于 **tan(ψ + φ)**，
即锯齿节理的 τ = σ·tan(φ + i)（Patton 1966，粗糙节理强度的奠基结果）。
代码里没有任何地方写过这条公式——它是平衡方程 + 摩擦锥 + 单边约束的后果。

## 三个自己踩的坑

1. **对偶行的符号。** `solve` 里为让 b ≥ 0 把部分行取负，返回的 y 就对应取负后的系统，
   与调用方手里的 A、b 差一个符号——12 组强对偶测试红了 7 组。取负的行其乘子要翻回来。
2. **机构容许性的不等号方向写反。** 正确是 yᵀw **≥ 0**（正 = 分离）。写成 ≤ 0 时
   全部算例误报不容许，而 α 值却是对的——**门和被测对象错得不一样，所以能抓住**。
3. **黏聚力写成了无界非负射线**，于是可以无限放大，LP 直接报无界。黏聚抗剪是**有界**的
   （|F_s| ≤ cA，与法向压力无关），必须为每个黏聚接触补一行 Σλ + s = 1。

## 诚实边界

- **二维摩擦锥线性化是精确的**（锥恰有两条极棱）；**三维是 k 边内接棱锥**，
  内接 ⇒ 容许集变小 ⇒ 承载力**偏安全**，偏差量级 1 − cos(π/k)。已钉成收敛门。
- **刚体、小变形、接触位置在加载中不变**——极限分析的标准前提。几何非线性不在内，
  所以大位移下的互锁"爬坡"过程它算不了（那是 L5 逃逸剖面的领域，两者互补）。
- **只做单个动体对固定边界。** 多体机构要把各体自由度并进同一组平衡方程，未实现。
- 本构只有库仑摩擦 + 黏聚力，抗拉一律为零。要接别的本构（DDA 的节理强度、夹具的
  摩擦模型）是在这一层插，内核不动——这正是 L3 的设计意图。
- 关联流动：极限分析的经典框架假定剪胀角 = 摩擦角，这对真实岩石**偏不安全**
  （实测剪胀角通常小于摩擦角）。非关联流动下上下限不再重合，需要别的方法。**必须写明。**
