# 只读交叉审查：interlock / exact_sweep

审查范围：`src/eab/kernel3d/interlock.py` 的精确根与窗口选择、`exact_sweep.py` 的事件完备性与共同窗口模型。未编辑被审查代码；复验脚本为本目录 `review_interlock.py`，结果 `review_interlock.json` / `.log`。

## 已核对

1. **同一份数据**：`_nonpenetrating_at` 在原顶点的 Fraction 值上精确加 `offset + h e_z`，与事件源构造的精确仿射运动一致；没有把 `A.translated()` 的舍入坐标拿来证明另一份几何。浮点 `report_A` 只供旧标签/并列报告使用。
2. **精确事件**：VF/FV 面方程、EE 共面时刻与段内参数是有理数；近竖直但非零分母不被噪声门剔除。永久共面的边对补端点跨边事件，平行共线退化补端点重合事件。非平面源环的事件使用确定性三角面，表面标签注明三角顶点。
3. **最早性**：默认从零状态起按精确事件值排序，逐点判定；首个非贯入根前的所有相邻事件开区间均取精确中点验证严格贯入。区间内几何布尔值恒定依赖完整 VF/FV/EE/共面退化事件划分这一前提，而非浮点采样密度。
4. **显示值**：公开 `height` 仅是向上舍入的 binary64；权威根为 `exact_height`，权威原体位移为 `exact_offset`。不能拿二次浮点平移结果替代精确证书。
5. **共同窗口**：margin 与 interlock 调用同一个 `contact_models`。其集合为原体、6 个精确轴位移模型、可证的两侧 star core。互锁对各模型求根并取最小；已有最好值只截断其他模型不可能改善结果的后半段，不改变比较的精确值。

## 独立数值复验

- 使用测试侧整数四面体并集动态 SAT oracle，不调用生产事件、法向、SAT、重叠或平移原语。
- 6 个一般位置/非对称仿射体格：尺度 `1/1000,1,1000` × 平移 `0,100000`；每格 `exact_height` 与独立根完全相等。
- 每格 5 个返回区间逐一检查端点连续、中点精确、原始仿射输入一致；独立静态整数 SAT 验证各中点严格贯入、根非贯入。共检查 30 个区间，没有用被测谓词做 oracle。
- 窗口反例专门复验：轴对齐盒体默认根 `1/5`，`w=1/100`。独立构造 9 个模型：原体/横移根 `1/5`、向下移根 `21/100`、向上移根 `19/100`、两 core 根均 `59/300`。公共 API 返回 `19/100`，已修掉“只用 core 使 margin 与 interlock 窗口最早性不同”的问题。
- 执行结果：`status=PASS`，约 0.53 秒。该有限复验不是全局完备性证明，也不替代全仓/G6。

## 必须保持的说明边界

- **窗口是有限充分证书，不是完整欧氏贯入深度偏置。** 找不到证书不可表述成真正深度大于窗口；core 是局部壳层厚度，双墙夹持的全局刚体脱开距离可以远大于窗口。
- `cover_label` / `tied_labels` 是旧 nominal 报告标签，未必是精确最早根的唯一实际表面特征；应使用 `exact_contact_label` / `exact_contact_normal` 解释精确事件。EE 符号必须与其实际表面拓扑匹配。
- 窗口模式的 `exact_contact_label` 是**胜出模型**上的标签。若胜出模型是 shift/core，冻结时必须同时重建该模型；在原体上冻结该标签仍可能得到原体 nominal 高度，而非窗口根。
- 公开 `interval_certificate` 序列化的是胜出模型的区间证书，不含所有败选模型的完整独立证书。代码确实对其他模型做有界精确搜索，但如果需要外部离线验证“所有模型合取的最早性”，应按模型集合重算；不得声称只读这一份公开元组就已验证所有模型。
- 以上检查未发现默认根/同输入证书的新 critical 或 major；范围有限，不能据此宣布独立六路 G6 退出。
