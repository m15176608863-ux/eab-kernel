# E5b 互锁执行说明（合并报告素材）

## 已实现契约

- `exact_sweep.surface_events` 以原始有理坐标和精确平移枚举完整三角表面 VF/FV/EE 接触事件；近竖直非零量不再按噪声丢弃。三角化对角棱、持续共面棱对的端点入段事件、平行端点重合均包含。事件时刻、排序及根处在程判据均为 Fraction。
- `escape_height_covers` 默认检查 0 和全部有序正事件，第一次非贯入根必须通过精确实体谓词，并逐个证明所有前序候选开区间的有理中点贯入。完整事件分割保证每个开区间状态恒定。显式返回 `exact_height`、`exact_offset`、`interval_certificate`、`nonpenetrating_state`。
- `height` 只是向上舍入的 binary64 显示；把它重新逐顶点浮点相加是**不同的输入几何**，不承诺仍不贯入。适配器应消费 `exact_offset`/`translate_exact`；若要工程分辨率接触，显式给窗口并复验，不能恢复隐藏 ctol。
- `exact_contact_label` / `exact_contact_normal` 是精确事件片；折面使用 `('face', fi, 'triangle', i, j, k)`。`cover_label` / `tied_labels` 保留名义盖及报告带，不能冒称精确事件片。非 Dual 冻结逃逸直接使用原始 Fraction 平面比值，不经单位法向舍入再除微小 n_z；4 个近竖直数据格证明冻结高度**逐值等于**精确根。
- `escape_height_brute` 保留接口但不再用可能跳过先逃逸、后重入的单调二分；它是同一完整事件解的兼容报告，**不再是独立 oracle**。独立性由测试自己的解析剖面、整数 SAT 区间并集与有理射线保证。三组有理尺度/大平移双障碍数据单独钉住先逃逸再重入。

## 共享显式窗口

`exact_sweep.contact_models(A,B,w)` 是 margin 与互锁共同使用的有限有理证书集合：原始几何、可认证的 A/B 星核同心内核，以及 A 沿六个坐标轴方向的精确 ±w 平移。

- 平移证书直接给出长度为 w 的刚体脱开上界。
- 星核严格在每个定向源三角内侧；以 `alpha=min(w/max_v ||v-c||_1,1/2)` 同心收缩。其删除壳层到原表面的距离不超过 w，因此接受的是有证明的局部浅层贯入。它不是全局最短刚体逃逸距离，也不是任意方向最小贯入深度的必要充分算法。
- margin 任一模型非贯入即接受窗口；互锁对同一集合求最早根的最小值。先有最优上界后，其余模型只审计该上界内的完整事件；没有更早非贯入事件即可排除。
- 输出 `interval_certificate` 是**胜出模型**的前序区间证明；其他模型的有界排除来自算法逐事件检查，可按同一 `contact_models` 重新计算，不声称返回元组已存储所有模型的全部证明。
- `window_core` 说明模型；窗口模式下精确事件标签在该模型上解释（可能是内核或平移后的 A），原 `cover_label` 则仍是原几何报告，用于保留旧“冻结高度约 0.2”的断言。
- 独立轴对齐盒门：窗口根恰为 `1/4-w`，margin 在该根 ON_BOUNDARY、稍低 INSIDE；三种尺度/大平移均通过，原“margin 与互锁接受集合不同”的中间方案已撤销。

## 独立 oracle 与未弱化迁移

1. 原墙 4 组 × 20 seed 输入全部保留。主 oracle 为测试独立三角化、整数投影 SAT 动态开区间并集及有理射线排除包含；再以闭三角 SAT 区间证明根右侧严格边界分离及无包含，从严格体重叠关于位移的开放性证明根安全。它不调用生产事件、几何谓词或向量原语。新门要求 Fraction 根零错。
2. 原高度 0.2、标签类型、冻结高度 0.2 和 brute 佐证断言保留在显式旧窗口口径；另增 80 格间隙 1e-6 后再抖动数据、4 格有理刚体变换的理想竖墙。
3. steep 原 72 输入及全部旧断言保留，正式加入 E5a2 草案“带内漏支”充分条件；独立同时检查法向报告带和各自 extent，不以简单高度差替代。相同生产 `_escape_solution` 竖向并列窗突变被新断言杀死。
4. E5a2 profile 原 12 格保留原无贯入/近似根断言在精确仿射轨道，并增加 Fraction 根逐值相等；另增 3 格恰可表示根保留原实际 float-translated 无贯入断言。旧“向上浮点修补”源码字符串突变迁移为“省去精确根非贯入核验”内部突变。
5. 独立 `earliest_star_escape` 以测试星核四面体并集的整数动态 SAT 给出精确根，提供给 margin 负责的 3 格 brute 零高度迁移。
