## 数学与突变检查

1. 布尔三角交：非平行平面精确切线区间，共面投影二维 SAT。选取非零法向坐标只确定不退化投影，不使用长度容差。保留闭边界。
2. 整数射线：只乘正公分母，offset/divisor 与边半空间符号正确；负 divisor 显式翻号，没有把阈值混入整数路径。
3. 星核：仅在输入三角面所有有向平面都严格包住中心时使用四面体并集，否则退回一般路径；仍依赖原 API 的闭合嵌入、外向面环前提，不应扩张到自交/非流形。
4. 横截方向满足两法向投影均为 `(n·m)^2-(n·n)(m·m)<0`；步长由精确面截距给出，且候选点重新对两个原表面判严格内，失败只退回完整排列，不会凭方向替代内点证书。
5. 已有突变门确实改生产函数内部并检查目标断言：闭端点丢失、边界奇偶取消、缓存 key 去掉顶点。未见产物后添加假数据、捕获任意失败或用非目标断言冒充咬合。
6. 等价优化门既比较旧 Fraction/点集路径，又有独立 oracle；二者角色明确。微性能数字不是全套性能验收，最终仍以主代理冻结全套为准。

## 唯一发现（minor / 文案）

`Polyhedron._sync_geometry_cache` 写“including nested lists”，但 `exact_convex_view` / 精确三角缓存仍要求 `Vec3` 内层可哈希。将 `p.verts` 改为 list-of-lists 后调用 exact_convex_view 会 `TypeError: unhashable type: 'list'`。类型声明原为 tuple Vec3，故不判新有效输入 major；建议删去泛化承诺或说明仅签名检测支持，而几何 API 仍要求 tuple 坐标。另外旧字段旁“Polyhedron 视为不可变”的缓存注释宜同步改为内容签名失效契约。

## 输入错误排除

初次亚分辨率相触探针用 `box(center=Fraction, half=默认float)`，构造阶段把 ±2^-120 舍入掉，三格实际相同；已纠正为有理 half，独立检查真实输入后得到 1/0/-1。该次不是生产几何反例，未计入 findings。

## 最后新增三角窗口平面下界快路（只读复核）

范围：`exact_geom._triangle_plane_outside_window`、`_triangles_near` 的新拒绝分支，以及 `tests/test_e5b_triangle_near.py`。本轮仅阅读代码与门，按主代理要求未另跑 CPU 测试；运行结果以主代理日志为准。

- 拒绝充分性成立：对三角形 B，线性有向平面量 `n·(p-a)` 的值域为三个顶点值的闭区间。区间严格同号时，最近平面距离为 `gap/|n|`；任意 A 上点均在该支撑平面，故两三角形距离至少为此下界。`gap² > tol²(n·n)` 可安全拒绝；两个方向取 OR 仍是充分拒绝。区间跨零时返回不拒绝，属于保守退回，不会丢近点。
- 等号处理正确：条件严格 `>`，AABB 条件也严格 `<`，闭窗口等距不会提前丢弃；`tol=0` 跳过下界快路，仍走精确三角交。契约仍是有效非退化三角形、非负有理窗口（公开调用先验证并转 Fraction）。
- 主 oracle 独立：已知族的最低上三角顶点与下三角同投影顶点垂直距离恰为 `band+delta`，既给平面下界又给达到下界的点对；自写有理正交运动和正尺度保持此距离。243 个阈值答案及 12 个超微阈值答案含等号两侧，未借用生产几何原语。180 个一般舍入输入只声称对旧全特征路径等价，不把共用生产原语冒称独立 oracle。
- 内部突变有牙：编译实际辅助函数，把 `>` 改 `>=` 后 monkeypatch 回模块；固定平行等距输入通过 AABB、实际进入该新分支，闭窗口断言由真变假。捕获的是指定 `closed boundary equality`，不是任意异常或人为追加产物。

结论：只读复核未发现新的 critical / major / minor；不扩大为全空间验证或独立 G6。
