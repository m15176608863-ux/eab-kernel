# WO-E5a 几何子任务交接

## 已落地

- `convex_hull_3d` / `_quickhull` 的全部拓扑判定改为精确符号；不再自适应放大容差、不删除真实细脊。仅保留极点，返回三角面。生产自检另用 Fraction 叉积验证全部输入点，构建与证书分开。
- `merge_coplanar` 只合并精确共面、同向、共棱连通的面；不精确平面的原面不许凭 Newell 向量混入平面组。独立代理发现此问题后已增加专门回归门并修复。
- 显式 `exact_convex_view` 定义 `conv(input vertices)`，缓存规范视图并输出 `source_vertices` / `source_faces`；一般凹块不被隐式凸化。原面列表恰为精确 facet 时保持原编号。
- `face_polygon_locate` 改为精确投影环绕数；正 `tol` 只表示调用方明确给出的欧氏边界域窗。逐运算向外取整的区间快路与纯 Fraction 版对拍 972 格，覆盖边界、工程坐标和次正规数。
- 新增显式精确 API：三角化表面成员、凸包成员、凸对 SAT、线段穿面、三角形相交。一般非平面面采用确定性投影耳切；保留三角所属原面信息。
- `_seg_seg_distance` 第五轮例修复：近平行候选用精确平方距离，最后缩放开根，避免独立浮点参数错位；另修独审发现的 `sqrt(float(1e-400))` 下溢，增加 4 个大小尺度闭式门。

## 不可声称完成的部分

`point_in_polyhedron`、`segment_crosses_face`、`polyhedra_overlap` 的一般旧入口仍有噪声带和启发式。新建精确 API 不等于旧入口已经迁移。凹多面体的完备三分类相交还需处理共面/公共棱的局部面排列；不能把旧网格或微推当作精确证明。第五轮 604 保持未完成处置。

`_seg_seg_distance` 的普通非近平行浮点距离构造没有被声称为所有输入的精确实数距离；本单修复针对第五轮不一致见证以及大小尺度转换。精确距离平方原语是 `exact_geom.segment_distance_squared`。

## 旧门迁移

`geom_test_ledger.json` 逐条记录。所有既有测试名与参数格保留；旋转后“仍恰为 8 顶点/6 面”的假设拆成两种更严格的门：

1. 已舍入坐标：零容差支持半空间、输入顶点忠实性、每个输出顶点确为极点；不把舍入造成的真实 facet 抹平。
2. 精确保平面的仿射构造：以 Fraction 计算同一个存储矩阵的变换，保留原有完整拓扑断言。远坐标 merge 门还同时检验原来的已舍入输入。
