## Oracle 独立性和自检

AST import 核验：主 oracle 仅导入 `fractions.Fraction`、`functools.lru_cache`、`math.comb`；平移辅助 oracle 仅 Fraction。
没有生产几何、根隔离、区间、接触枚举原语 import。生产适配器仅为被测/输入构造身份核验，不参与期望答案的几何计算。

人工检查了平方自由化、Sturm 根计数、显式隔离工作栈、有理端点与重复根处理、代数根比较、根上的投影符号，及 VE/EV 索引映射。
`first_events` 在每条实际轨迹上先要求独立固定时刻凸包严格分离见证；故不会把已初始接触/包含当作新的首事件。
分母公因子优化在本次使用的正 P2 二次分母及其正乘积域中有效，不把该审查扩展到任意未经检查的有理分母。

全部通过编译并替换真实被测函数体后直接执行具名门；没有在返回产物后造数据，变异报红不依赖源码哈希或冻结摘要。

实际错误证书也不都表示首标签改变：不等分母及端点/边长预算反例可表现为签发的首时刻括区错误。报告应保留这一差别。

## P2 错括区、阈值精度与非刚体扰动

不等分母 P2 构造由独立显式系数生成，再与实际 `DDAAnchoredMotion` 的适配输出逐项核对，确认两块均包含非零旋转、平移、对称应变，且分母分别非恒定且不同。
独立 oracle 给出首标签 VE(2,3) 并严格证明首时刻大于 2/5，故错误括区 `(3/10,2/5)` 不成立。

默认构造的 40 次二分得到：

* 下端 `14711044003/4398046511104`，上端 `29422088007/8796093022208`；
* 宽度恰为 `2^-43`；
* `r_lo·2^-24 / 宽度 = 14711044003/8388608 > 64`。

因此靠近阈值的采样位移显著大于二分不确定性；使用的是已认证下端，不冒称精确代数 r*。
各 guard 对非负半径单调非增：相对几何项固定、误差预算非减，再取有限 min/max；二分前提成立。

审查另用独立幂次求值（不复用 oracle 的 Horner）提取实际扰动在 s=0、1 的误差：每个误差都在半径内，且每条轨迹的两块都存在随时间变化的误差、并实际改变至少一条边的长度，排除“只是共同刚体平移”的伪覆盖。
6 条固定种子扰动分别在 `r_lo/2` 与 `r_lo·(1−2^-24)` 两处检查，共 12 条；**每条同时通过独立首次标签和首时刻严格处于 `(2/5,1/2)` 的检查**。
线性端点误差插值保证全窗在 L∞ 管内。有限搜索支持但不代替任意连续管内路径的 R3 理论。
