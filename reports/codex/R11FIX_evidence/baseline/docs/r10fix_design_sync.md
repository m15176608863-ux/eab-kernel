## 1. 闭集首入与出口的不同问题

- `first_entrance3` 先判初态相对 **E 的拓扑位置**。普通 `∂E` 初态已经满足闭集首入条件，
  不论切向、背离、进入，也不论 `t_max=0` 或正短窗口，均返回 `entrance / exact_t=0`。
- 该分支独立收集精确零间隙、有限特征域内的当前盖，不依赖“向内运动”候选过滤；
  精确并列集合和选中标签不因未来方向改变。浮点见证只作显示。
- 紧配内缝可能位于 `int(E)`，仍走既有局部出口策略，不能把所有实体相触都当 `∂E`。
- `shortest_exit[3]` 是局部最浅盖，不是一般凹体全局最短出口。
  interlock 求非贯入高度；初态已无内部相交时高度为零。这不等于求闭集完全分离距离。

门：`tests/test_r10_initial_boundary.py`，以及原 R8 初态/内缝门；二维、零裕度、互锁同类门一起核验。

## 2. 公共二维法锥的方向与窗口

`in_cone` 与 `normal_cone` 采用一致的凸法锥域：精确正转角才能给严格内部 `1`；
同向微反射只可由显式 sin 窗口接纳为 `0`，绝不将反方向薄扇区标严格内部。
大反射、反向边界射线返回外部 `-1`，零边界射线明确 `ValueError`。
窗口不能创造严格性。三维公共法锥仍按声明三角表面，而非源环 Newell 描述符。

门：`tests/test_r10_cone_contract.py`；其中含二维单盖控制、三维微反射屋脊的单位/刚体变换格。

## 3. Dual 的最终导数构造

- `sqrt` 的完整导数为 `seed/(2√v)`；用精确有理平方 `seed²/(4v)` 经统一根构造一次舍入后施符号，
  不从已舍入 primal 计算导数。非零范围外抛异常，不能静默变成 `0/inf`。
- 半整数幂导数平方同样有理化；`atan2` 导数用完整有理式，不能由 ordinary 快径多次舍入。
- `sin/cos` 的 libm 系数与 seed 在有理数中相乘再作最终范围检查。**这不是超越函数解析值的全域正确舍入证明**。
- 一般非半整数幂保留既有高精度近似系数合同；零 seed 不豁免 primal 范围检查。
  本次不改变普通 Dual 加减乘除的既有精度合同，不声称全链所有运算正确舍入。

门：`tests/test_r10_dual_construction.py`，含独立 Fraction 中点/平方证书与六种源内撤回变异。

## 4. 可分辨性是诊断，不修改承载证书

单体/多体 uncertainty 的机构读取 LP 精确见证，活荷载与扰动保持有理数；
输入舍入预算先把 norm 化为 `[1,√n]` 的无量纲构造，再保留其精确有理尺度。
它依旧是沿返回机构的一阶**估计**，不是误差界或所有对偶最优面的稳定性证明。
最终比值、邻域荷载推移与邻域相对变化先完成再显示；NaN/Inf 估计明确标 `unresolved`。
原问题的精确 `status/alpha` 不被邻域问题替换。

门：`tests/test_r10_resolution.py`，覆盖最小次正规活荷载、最优/无界两种状态、单/多体与非有限诊断注入。
退化对偶面上 uncertainty 不唯一，门检验独立解析范围，不强制求解器选择特定机构。

## 5. 静态门范围

静态门检查位置、关键字、星号解包等调用参数，`Fraction` / `map(Fraction)` 不去掉已知
舍入来源；普通/注解/增量/海象赋值、局部容器写入、循环与分支等已知本地流必须传播该来源。
复审七种原型均植入真实 `cone_intersection_margin` 源码路径：既要门拒绝，也要独立数学证书
证明注入改变了数值结果，不能仅靠追加假输出制造红灯。

门：`tests/test_r10_static_construction.py`，保留全部 R9 静态门。
此门仍不是任意动态 Python 的跨过程证明；反射、动态导入、自定义未知函数和对象协议需审查/动态数值门。
逐函数逐规则例外及覆盖边界见本轮报告，AST 零违例不代表数值或几何全域正确。
