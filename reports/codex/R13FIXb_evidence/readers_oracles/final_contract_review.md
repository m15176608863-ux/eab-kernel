## 两个 gap 核实

机读清单共有 **138 条**：`differential=107`、`nonconstructive=29`、`gap=2`；API 唯一，无多算/漏算重复行。

1. **`eab.dual.Dual.__pow__`**：保留 gap 合理。整数/半整数分支有有理/根式测试，不能外推一般幂；源码仍将指数转 float，一般分支用 libm primal 与 Decimal precision 80 导数系数。清单如实承认指数转换、一般 Decimal 失败类型及全域误差界未完全审计。
2. **`eab.dual.convergence_order`**：保留 gap 合理。误差字典与极端误差比处理有独立门，但一般 `large_h_order` 仍依赖 log、相减、相除，没有普适误差界；三次多项式给阶数 2 或特殊比例给阶数 1600 的门不能证明一般数学阶数。

“2 个 gap”仅指**原 138 项增量清单**，不能简称“整个公开 API 只剩 2 个缺口”。额外清单将 adapter `cone_tol/metadata` 记为 `limited`；旧 `dual.sin/cos/atan2` 为 `prior_coverage`，其说明亦不承诺真超越函数的全域正确舍入。README 的“不能据此声称全 API 已满足该合同”和清单的 `whole_public_surface_fully_proved=false` 与此吻合，应保留。

## 数学措辞建议（不改代码，不新增计数 gap）

### CNOTE-01：face_noise 的最终比值通常不是有理数

审阅时文档写“Newell 平方与最终比值保留有理数”。实际代码计算

`sqrt_rational(numerator² / ||Newell||²)`。

有理数是 **Newell 模平方与最终根号内比值**；最终噪声 R 通常含无理根号。建议将该句改为“Newell 模平方与最终根号内比值保留有理数”。这不影响其误差界推导或实现。

### CNOTE-02：全数值域不等于任意非法几何也有定义

建议在“任意有限 binary64 / int / Fraction 判定精确”后补“在各 API 既有几何有效性与数学定义域前提下”。全数值域指不因尺度/表示收窄；并不自动使零法向、非闭合/自交网格、未定义的除法等非法模型获得合法答案。各模块已有具体前提；这里补一句可防止单读 README 时误解。

此外，“单个双线性项 2^800”对应两个原始 D400 量的乘积；若指两差向量的分量，差各可到 `2^401`，乘积上界为 `2^802`，仍远低于 binary64 上限。这是可选精化，不影响当前“只靠 ±400 不能保证安全”的结论。

## 主代理修订后的复核

主代理已修订文档，本代理只读复核确认：

- **CNOTE-01 已关闭**：支持域节现写“Newell 模平方与最终根号内比值保留有理数（最终噪声通常是无理数）”，准确区分有理根号内量与通常无理的最终噪声。
- **CNOTE-02 已关闭**：判定条款现明示“在各 API 既有几何有效性与定义域前提下”。README 链接到该完整合同；不再要求首段重复所有前提。
- `2^800` 为原始 D400 输入的单项乘积上界；差向量乘积的可选精化不构成剩余合同缺陷。
