## 1. 判定原则

1. **允许 PARTIAL 不等于放宽必跑门。** 即使最终为 PARTIAL，也必须全套四分片全绿、收集节点集合等于执行节点集合、零 skip，贴四条原样末行。
2. 输入能构造 1810 / 450 区间，不等于相应回放已完整运行。必须分别有新鲜完整批次、最终代码哈希、规范化记录及闭集计数。
3. 代码存在、具名小门通过、全时程证据完成是三个不同层级，下表明确区分。
4. 当前不得写 `M4c_DONE`，也尚不得用一个宣称“全套仍绿”的最终 `M4c_PARTIAL` 收尾。先补齐等待中的强制验收证据，再列实质未完成项。

## 3. 四个容易被“已实现”掩盖的范围问题

### 3.1 全区间拓扑与“带洞”

当前 API 接受一条简单闭环，要求在整个 `[0,1]` 内无零长边、自交、回折或退化，不只核两个快照。步中失效即使后来恢复，也必须报错，不能将该区间当正常轨迹。

“带洞”测试目前指 **入口块 E 的洞**，与 M3 背景一致；不是材料块输入有多个边界环。实现和文档均明确不支持多环输入。最终报告必须直说这一点：若所有者的工单“带洞”原意是材料块带洞，则该部分尚未完成，不能用 E 有洞的测试顶替。无需此语义扩展时，可以接受“单环材料、多连通 E”的明确子域交付。

### 3.2 δ=0 证书不是一般扰动证书

精确计算 δ 并把所有 δ>0 样本记 UNCERTIFIED，是安全的保守实现；其证书门有意义。但它只证明两条轨迹逐值相同这一退化情形，不闭合工单中转动/应变小扰动下的首盖稳定性要求。文字中给出的非零 δ 充分条件尚未变成可执行区间证书，应保留为**实质 PARTIAL**。

两条轨迹分别精确求解得到的相等/不同可以描述，但必须与“认证一致/认证不一致”分开，不能以事后相等偷偷扩张认证域。

### 3.3 事前预测分母受事后候选选择影响

当前预测只计算“初态分离，且实际运动扫掠盒相交或任一 legacy 表列出”的块对。已实跑最小例证明：被实际候选筛掉的远块对仍可能有预测接触，故完整预测假阳性未统计。

这一限定版本可提供工单所需的初步事前证据，但不能满足“所有块对在线预测器准确率”的更强声称。最终统计必须叫**实际/legacy 候选子集条件预测一致率**；若目标升级为全块对预测验收，应列为未完成范围。

### 3.4 漏检深度必须带观测量名

现有深度字段是“步末内部顶点到对块边界的净空证人”，不是全局 PD，也不是本步最大侵入。十字横交等情况可能有严格侵入却没有内部顶点证人，字段已正确用 null 表示未知。

待全批次完成后，应逐漏检块对检查是否有有限证人。若某些没有，报告必须说“该例深度未量化”，而非深度为零；不能以已统计漏检数量宣称已完成每例深度量级要求。
