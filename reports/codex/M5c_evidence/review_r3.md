## 证明逐项核查

1. **同时间相关性消元**：先做有理函数相减/双线性恒等式再作区间包围，保持包含性；相同分母捷径只是约去相同表达式，没有浮点近似。
2. **分隔定理**：对所有顶点对的同时间投影下界都大于两管半径的 L1 对偶范数收费，则任意凸组合也分离。每段中点法向仅产生候选，整段仍由精确包围检查，不是采样冒充证明。
3. **简单环**：非零边保证每条边单射；相邻共点射线只有“共线且同向”会重叠，严格叉积或严格负点积排除；非邻边由两端严格同侧或全部端点投影分离排除交叉。这覆盖所有闭线段边对，不只局部转角。
4. **独立顶点误差**：同环差向量各有 2r 的坐标界；跨环差为 ra+rb；双线性展开含两个一阶项与二阶项。相关顶点共享时仍按独立最坏界收费，只会保守，不会少收费。
5. **首盖**：早期凸包分离排除早接触；严格异号及边内投影给括区内边界接触；简单多边形首次边界交会必有顶点—边入射；每一其他 VE/EV 都排除，故唯一标签成立。不需要扰动可微、根唯一或导数保持。
6. **严格边界**：零余量不能签；并列、VV、角点触碰均会产生另一个不能排除的入射。任意一条竞争 VE/EV 被省略都会破坏证明。

## 文义澄清（已通知作者）

`_simple` 只认证 `[l,h]`。初始 CCW 加早期两块分离，不能推出每一块在 `[0,l]` 内从未自交或方向反转。
方向同伦论证应限于**固定时刻的允许顶点配置**；不应冒称从 0 到 l 的方向保持。
这不影响上述首盖身份证明：其所需的是 `[l,h]` 两环简单，以及 `[0,l]` 两凸包分离，证明本身不依赖全早期方向延续。

## 独立性与边界

- 常值扰动 oracle：`tests/m5c_teeth_oracle.py`，仅 `fractions.Fraction`，一次方程根和闭边投影，未调用生产几何/事件/包络。
- 非刚体线性扰动 oracle：`tests/m4c_independent_oracle.py`，独立三点插值、二次根、坐标盒入射、整数 winding G0；它不导入 R3 或 R3 使用的 `model_robustness`、exact、motion、global_entrance 几何原语。G0 的 import 清单在 JSON 和该模块 docstring 内完整登记。
- 简单环 oracle：本脚本独立枚举闭线段相交与邻边重叠，没有调用生产 `_simple/_event/_relative` 来构造期望。
- 这些是有限对抗证据，不能替代连续路径定理，也不代表未知真实物理路径；任意连续扰动的保证来自经过上述检查的充分条件证明。
- C 出口排序草案正确区分“外组间隙”与“并列组成员全不变”，也明确缺少非凸全局边界特征存续层。保持 PARTIAL、不签出任何正半径出口排序是正确边界。
- 后补 C1 严格凸一般位置草案已独立核对：全凸性与跨环严格非平行保证 Minkowski 边标签存续；端点 L∞ 误差 r 给边 Hausdorff 界 `√2r`；`h=q_j-q-8r²>0`、`h²>32qr²` 等价于闭边距离差大于 `2√2r`。名义内部且 `q>2r²` 保持内部。全部闭边严格最优间隙已排除端点相邻边并列，显式双投影检查可作为冗余保守门；作者已修正文义。**该草案尚未实现，未提供任何已贯入数据的稳健出口排序结论。**
