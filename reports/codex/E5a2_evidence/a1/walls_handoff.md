# 竖墙门冻结诊断：不能以“只安全”替换“最小逃逸”

## 结论

`tests/test_interlock_walls.py` 的四组参数、每组 20 seed，共 **80 个原输入全部保留并诊断**。未改 production/test 文件，未降低精度、删格或以 tol 吞掉内部。

- 当前 covers 路径 80 格均返回约 `1.2`；旧门要求约 `0.2`，四组首个 seed 都失败。
- 四组 seed0 在实际浮点平移 `height=0.200001` 后，都有独立 Fraction 射线核验的**严格共同内部点**。这否定“原 float 输入只是理想精确刚体运动、故仍应逃逸 0.2”的解释；即使 t=0/ulps=0，旋转构造的分别舍入也能制造真实微侧向贯入。
- 但不能因此把原最小逃逸门改成只要求返回安全：有 **7 个原输入**存在严格小于 covers 返回值的分离高度，且已给出独立整数证书。因此当前返回也确实不是最小逃逸，属于 E5b 候选/近竖直法向语义缺口。
- 建议主单明确 **PARTIAL**，保留失败门及全部诊断证据。未经补齐最早根与 frozen 标签语义，不应宣布全绿或修改旧门为安全上界门。

## 独立性与证书

`walls_diagnostic.py` 的独立 oracle 只读 raw 顶点/面索引；用测试侧独立 ear triangulation（`tests/e5a2_surface_oracle.py::_ring_triangles`）解释已规定的源面三角化，用 Fraction Möller–Trumbore 射线奇偶判断内部。没有调用生产 ray、normal、membership、surface intersection、arrangement、distance、convex hull。**没有调用 star oracle，也没有把 U 凸化。**

`walls_strict_interior.json` 保存四组 seed0 的共同内部有理坐标；还逐点检查其不在任一源三角形所在平面上，排除仅边界命中被当作内部。实际浮点平移与调用方一致。

`walls_strict_separation.py` 对 7 个反例的更低高度：

1. 每体独立源面三角化；全部坐标共分母整数化。
2. **336 对闭三角形逐对**找到严格正投影间隙的整数分离轴。JSON 保存每对轴与正间隙，故无需相信生产三角相交函数。
3. 两个闭边界无交后，用独立 Fraction 射线各取对方一个边界顶点排除互相包含；对于本组连通闭边界，这给出实体严格分离。

这些是对给定 float 输入的证书，不是理想形状的近似说明。更低高度由 brute 与返回值的中点提出，**候选来自共享路径不影响独立证书**：候选提出者可以说谎，整数分离轴与独立射线仍逐条验证。brute 数值本身只作佐证，未当主 oracle 或声称精确最小根。

## 根因与不能做的“修复”

`_cover_escape_z` 仍按 `n_z <= max(1e-12, noise)` 丢掉近竖直的浮点法向；旧政策把工程舍入视作可忽略墙噪声。现在 A1 的对象是给定坐标的严格折面实体，微斜侧墙可以是真实决定某个中间高度的边界。只核验大高度安全不能证明未漏前面的逃逸事件。

这里的最小桥接只保证实际返回的高度不贯入，不负责恢复旧层原先就没有的精确候选完备性；7 格暴露了这一边界。把 noise 降小、恢复 tol 吞贯入、只 assert 安全、把 brute 直接当独立 oracle 或在失败格返回无真实 active 依据的 frozen 标签，都不符合本单纪律。

## 可行交接 / 迁移前置条件

E5b 需在实际源三角/特征数据上构造精确候选根与法锥，不能仅按浮点 nz 的噪声抑制删根；返回最早真实逃逸事件后，还需给对应 frozen 盖可解释的活动证书。一般折面与重新进入的情形必须明确最早根搜索契约，不能把假定单调的二分当普遍算法。

届时旧门迁移须：

- 保留全部 80 原 float 输入、原调用次数与 frozen 断言角色；每格以独立实际源面最早根 oracle 核验，不能仅核安全。
- 另外保留精确有理仿射的理想 U/key 支路，严格平行墙条件下继续钉住 0.2 与正确 frozen 盖。
- 对 7 格加入“更低严格分离”负证书门，防止候选消失后又静默返回 1.2。
- 在完备最早根 oracle 未建成之前，不改写现有失败门以制造绿。

- `walls_strict_separation.py/.json/.log`：7 格、每格 336 对三角形整数严格分离证书。
