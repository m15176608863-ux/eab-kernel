## 2. 精确输入拒绝：表示域及论证

表面由 `faces` 引用的有序环定义；非平面环仍按确定性投影耳切所给出的三角曲面解释。
未引用的 `verts` 行是缓冲区元数据，不是孤立几何片：入口先剔除并重映射，不能进入包围盒、凸性或体积计算。
这是既有 `merge_coplanar` 所需合同：30 行输入中可能只有 28/29 行被面引用。
门 `test_unused_vertex_buffer_is_not_an_isolated_surface_piece_or_bbox_input` 添加极远重复缓冲行，逐值核 parts、分类、线段不变。
**被引用**的零面积面/三角形、零体积壳、重复几何顶点、非流形、自交、错误定向仍拒绝。
不声称非平面环重新旋转后再耳切仍表示同一表面。

所有坐标先转 Fraction。输入谓词全是有理等式/不等式；没有 epsilon、float 转换或 κ 放大量。

### 2.1 拓扑与顶点 link

每条无向原始边必须恰有两个反向的有向 incidence。单靠这条不能排除两壳仅在一顶点相接。
每个顶点的 link 以相邻边的另一端为节点，以每个入射面为一条 link 边；要求连通且每节点度数为 2。
有限连通 2-正则多重图恰为圆，故局部邻域为盘。必须保留平行边：一个共线细分顶点仅邻两面时，link 正是两节点、两平行边的圆。
初版用了 set 去重，误拒已有 merged TIA；已改成保重 list，并以已有 merged interlocking 门验证修复。
负例覆盖缺面/边非流形、单面反向、共享一顶点且边 incidence 正常的两壳。

### 2.2 三角形交集的完整枚举

非退化闭三角形是凸集，交集是空、点、线段或共面凸多边形。

* 非共面：交集位于两个支撑平面的交线上。交集非空时，其每个线段端点或单点都落在至少一个三角形的边上；枚举双向所有边与另一平面的交点并做闭三角形包含测试，因此得到全部交集端点。
* 整条边共面于对方面平面：不能只检测端点。枚举该边与对方三条边的精确交点，平行共线时枚举同时属于两边的端点；覆盖边穿过另一三角形但其两端都在外的情况。
* 两三角形共面：凸多边形交集的每个顶点，要么是落入另一三角形的原顶点，要么是两条边的交点。前两类枚举穷尽这些点。
* `AABB` 不交仅用严格 `<` 排除；等号接触不丢。被跳过的对确不可能相交，不是探针豁免。

两输入三角形没有共有几何顶点时合法交集只能为空；共有一个顶点时只能为此点；共有两个顶点时只能为该闭棱；共有三个顶点为重复片，拒绝。
由于交集凸，其全部枚举顶点均在允许点/棱上，当且仅当整个交集在允许点/棱上。这同时覆盖非邻接穿透、非邻接贴触、共面面积重叠和相邻面越过共有棱的重叠。
门 `test_invalid_surfaces_are_rejected_exactly` 包括穿插壳与共面重叠壳；内部变异将 `_triangle_meeting` 的结果在验证代码内错误置空，预期红在精确的输入拒绝断言，而不是总量哈希或偶然求解点。

### 2.3 壳体定向与零体积

三角邻接连通分量给出壳。前述嵌入和流形条件使每个紧连通壳分离空间；无交壳之间的包含关系不随壳上采样顶点变化。
对每壳任选一个顶点，对其他壳用独立于被测外部 oracle 的生产 exact parity 计包含深度 `d`；本测试用闭式嵌套/不交壳决定预期。
偶数层壳应为向外（正有向体积），奇数层为空腔向内（负有向体积）。逐壳检查而非只检查总体积；因此小反向孤立壳不能被大正壳的体积掩盖。
零有向体积壳拒绝；闭合嵌入壳包围非空开集，正确一致定向后体积严格非零。
通用 parity 射线以 `(1,k,k*k+k+1)` 顺序试探；落在表面平面或击中边/顶点则换方向。有限退化条件只排除有限个 k，故终止。

## 4. 精确性能改动与不变量

### 4.1 任意方向包围盒参数区间剪枝

`B−A` 包含于各坐标差区间 `min B−max A ≤ x ≤ max B−min A` 的笛卡尔积。
将 `x=start+t·direction` 代入，逐坐标求闭参数区间；速度为零时必须容纳该坐标，否则排除。
三闭区间交为空才不做特征 SAT。此前只检查零速度坐标，新法还可排除各运动坐标分别相交但参数区间互不相交的斜线。
所有除法为 Fraction，`lower > upper` 才排除，等号单点相触必须留下。
门 `test_spatial_pruning_handles_nonaxial_lines_without_dropping_tangencies` 同时验证斜线早退和切触保留。
内部变异让 `_line_candidate` 漏掉上方凸片，预期红在完整闭式双区间断言。

### 4.2 缓存而非几何近似

不可变 `ConvexPart3D` 的结构 hash 用 `cached_property` 只算一次；hash 与原三个字段完全相同，不作为几何判据。
`_escape_sections` 按原始表面、offset、该直接调用层列出的实现函数身份缓存整条精确线段，避免每个候选事件重复转换、分解查询与对大型 Steiner 树 hash。
新增直接层以及 `_decompose`、`_line_sections` 的显式函数身份键使对应层的变异可见。
**这不是任意深度动态 monkeypatch 的全局失效保证**：既有外层 `_exact_escape_cached` 热命中时，不会重新进入新增层，
其键未列更深层 `_line_candidate` 等函数；对完整逃逸 API 注入此类内部变异时必须先 clear 外层缓存。
本单三条语义变异直接进入被测分解/合并/线段层，并清相关缓存；冷热性能门也明确清缓存，不借缓存绕过缺陷路径。
凸合并仍要求共有完整面及所有余面支撑整个并；没有新增近似凸化。
内部非凸合并变异穿过真实**共有完整面候选分支**：两个四面体共享 `(0,0,0),(2,0,0),(0,2,0)`，
顶点分别为 `(0,0,1)` 与 `(4,4,-1)`。绕过该候选的凸性守卫，并在同一分支错误用外包盒取代认证 `_part(faces)`；
两个部分实际被错合为一个。以 `(2,2,0)` 为心、半宽 `1/16` 的探针盒整体违反上四面体的 `x+y+2z<=2`
及下四面体的 `x+y+6z<=2`，独立预期为分离，错合后却贯入，故语义断言红。
直接测合并路径避免被下游体积护栏截断；不是替换最终返回值或在产出后追加假片。

## 5. 信任边界

本子任务不宣称完成 G6；全套、静态门、完整 replay 具体最终数字由本目录机器记录及主报告归并。
输入认证相对的是明确的有理三角曲面，不是 CAD 的未给曲率/容差模型；未引用缓冲顶点不是“豁免坏面”。
一般构造三档是逐值有限族审计，不是有限实验推出全输入证明；上面的几何完备性论证与执行证据分开列示。
