## 2. 原始几何与非唯一证书的独立核验

### 2.1 输入解析与独立性的准确范围

`formal_cases` 直接读正式 manifest、gzip 分片，核解压字节数、SHA-256、case ID、分片输入一致性与 query index 全覆盖；数字按原始 binary64 位串与规范化有理数字串读取，拒绝重复 JSON 键、NaN、BOM 和非规范分数。不共享 C++ 编码器。

L1 的接触选择以已验收 Python 裁判为期望，**本工具不是另一套独立接触枚举器**。独立的部分是：从输入多边形顶点 ID 和 CCW 原边重新构造每根力列，检查接触点在双方边界及所标边上，再核静力与阈值证书。C++ 导出的 tangent、A、b、c 均不能充当自己的正确性来源。

### 2.2 静力重建

`rebuilt_problem` 从标记的原边差得到 T，按接触侧调整方向，构造 N=(-T_y,T_x) 和未归一化 g±=N±μT。a 端取 +g，b 端取 −g；每个自由平动分量直接取力分量，自由转动分量独立计算 `(p−anchor)×g`。它与“先在冻结参考点 o 取矩，再投影至 anchor”代数等价，但不调用生产装配函数。

对荷载 F、M_o，实际转动行是 `M_anchor=M_o−(anchor−o)×F`；只保留非固定体被 dof_mask 放开的行。恒载取负形成 b，活载是 α 列，目标只有 `c_α=1`。导出列标签可以换序，但其物理标签多重集合必须与原接触列完全一致；按实际列标签重新排出矩阵后逐项核导出矩阵、行列标签、参考点、锚点、μ、profile 和 sensitivity_model。

### 2.3 非唯一 LP 证书

- **OPTIMAL**：核 x≥0、Ax=b、Aᵀy≥c、cᵀx=bᵀy=exact_value。活载列的 y 投影必须 ≥1，因此 y 同时通过关联机构驱动检查。C++ 新增 `mechanism` 附件必须等于这个已验证的 exact_y；不是无条件忽略新字段。
- **INFEASIBLE**：核 Aᵀfarkas≤0、bᵀfarkas=1。
- **UNBOUNDED**：分别核 x0≥0、Ax0=b，以及 r≥0、Ar=0、cᵀr=r_α=1；不允许用自应力替代改进射线，也不把该状态填成有限承载力或几何锁定。
- **未解析状态**：不允许附带零承载值、力学证书或机构。

因此不强迫 x、y、Farkas、射线或优化器内部 basis 与 Python 逐坐标相等；会逐字段比较状态、精确值、可解析性、原因、有效条件等真正语义字段。

### 2.4 临界基和开闭阈

`verify_branch` 对原始几何重建 A(0)、A(1)，形成仿射 A(μ)。在不少于 m+2 个不同的精确参数上，用独立 Fraction 高斯消元重算行列式、对偶松弛或改进射线的 Cramer 比值；结合显式次数上界证明全部导出多项式恒等式。它不靠单个 exported sample 的近似吻合。

`branch_signs` 独立去掉区间端点因子，再用有理 Sturm 链核内部根数与中点精确符号，复核导出的单侧延拓记录。闭阈核下侧有界延拓及临界点 UNBOUNDED；开阈核零恒载可行点、上侧归一化射线延拓及临界点 OPTIMAL。零处已无界的直接闭阈分支单独处理。二分终止字段和阈值证明原因分开保留。

末次加固新增合同：`critical_polynomials` 字段必须存在且为列表；空/非空必须同裁判语义一致，不能借非唯一基之名漏掉整个列表；每种角色最多一个，mechanism 的 sample_parameter 对应 μ_lo，improving_ray 对应 μ_hi。仍允许不同有效基、不同多项式系数及保守缺基，不强制每个括号都含两种基。具名门：

- `test_c3l3_bracket_only_result_cannot_drop_its_polynomial_list`
- `test_c3l3_branch_sample_is_bound_to_the_corresponding_bracket_endpoint`
- `test_c3l3_polynomial_identity_rejects_sample_only_agreement`

μ_lo/μ_hi 同时核 canonical rational 与 binary64 bits 的一致性；exact_threshold 可为非 binary64 有理数，不能把它舍入后冒充原阈值查询。无精确阈值时 attained、threshold_certificate、threshold_proof 必须保留 null。

## 3. P1 元门与蕴含的实质覆盖

### 3.1 精确随机旋转、单位和规定平移范数

固定种子 6033 生成三个 Pythagorean 旋转，连同恒等元：

| m,n | cos θ | sin θ | 消分母单位因子 D |
|---|---|---|---:|
| 恒等元 | 1 | 0 | 1 |
| 8,3 | 55/73 | 48/73 | 73 |
| 9,6 | 45/117 | 108/117 | 117 |
| 11,7 | 72/170 | 154/170 | 170 |

对每个旋转取长度单位因子 `s=D*u`、力单位 `f=D`，u 分别为 1、8、1/1024。原始输入是二进有理数，因 D 消去旋转分母，全部变换点和载荷仍能**精确**进入 binary64 ABI；不把舍入后旋转冒称同一几何。力旋转并乘 f，力矩乘 f*s；参考点、锚点与顶点同变换，所以无量纲 α 与 μ_crit 不变。

位移向量明确为 `(3d/5,4d/5)`，d∈{0,1000,100000}，故其范数严格为 d。源码直接核位移平方范数=d²；具名门 `test_c3l3_actual_transformed_geometry_obeys_exact_translation_norm_schedule` 从实际变换后顶点反求位移，核全部 4×3 组合，不仅检查配置或注释。最后一组仍包含特征尺度远小于坐标量级的输入。

G1 基例 t=3/32、h=1/16、μ=1/4；12 个变换均比较无界状态及精确闭阈 2039/32768。参考点在体内不需要回到原点；另由下述端板/重参数化门显式强化非对称参考点。

### 3.2 端板掩码与物理锚点

端板放转动模型采用轴对齐的 0°、90°、180°、270° 旋转。90°/270° 同步互换 x/y mask，锚点随几何移动，保持原有物理约束，不能将一般旋转直接塞入仍固定的轴向 mask。长度单位 1/2、力单位 2，平移至 (100000,−100000)，α 均应为 4/3。

三组参考点重参数化偏移为 (0,0)、(17/8,−29/16)、(2^17,−2^10)。保持几何和**物理锚点**不动，两个荷载力矩同步改成 `M_new=M_old−Δo×F`。重建后的 A、b、c 不变；`test_c3l3_reference_shift_preserves_actual_equilibrium_columns` 直接核这点。未把“任意移动端板锚点而不改变约束”当成不变性。

### 3.3 三条有效蕴含及反向反例

1. 单体封闭 cage：μ∈{0,1/4,5/2}，两组包含非零恒载和非对称活载的输入。除真 C++ L1/L3 结果外，利用零锥 ±e 乘子和 `(g+ + g−)/2=N` 独立合成任意给定恒载可行点及活载改进射线。这是符号构造恒等式的有限实例核验，不冒称对所有输入域完成枚举证明。
2. free、plane、seam、cage 四种环境；μ=0、恒载为零，对 ±x、±y、±moment 六个荷载方向逐一求解。只有 cage 的六项全无界，且与同一个 ContactSet2 的 ZERO_CONE 状态等价。
3. G1 三个取向/μ 的多体实例仅中体有活载，多体无界与将其他所有体固定后的单体无界成对核验。
4. G5 中块反向门：μ=1/4 时多体承载 1/2，μ=2 时多体承载 2；对应单体均无界但一阶锥非零。这直接阻止把单体无界倒推成多体无界或几何锁定。

## 4. 闭式与 T1b 阈值清单

### 4.1 G5 与端板反例

轴向滑动端板的 G5 闭式为 `F=min(2μP,4Ph/(L−b))`，b 是受活载中块宽度。补点取 n=3/5/7，另有 μ=3/8、h=3/2、P=5/4 的非单位输入。回归 (d) 以 N=L=3、h=P=b=1，得到 μ=0 时 F=0、μ=1/4 时 F=1/2。

μ=2、n=3、h=P=b=1 且锚点在端板面中点时，mask=(1,1,0) 放开竖向给 F=2/3，mask=(1,0,1) 放开转动给 F=4/3；不能混用锚点或把荷载施加点当锚点。

### 4.2 G1 三取向闭式

本生成族块宽 ℓ=2，记 ρ=h/ℓ=h/2。对 t≥0：

- t=0：所有取向均 μ_crit=0，**开阈**。
- t>0，`koureas`：μ_crit=max(0,t−ρ(1+t²))，**闭阈**。
- t>0，`unreversed`：μ_crit=t，**开阈**。
- t>0，`reverse_i1`：μ_crit=t，**闭阈**。

每取向核 (t,h)=(0,1)、(3/32,1/16)、(1/4,1)，合计 9 个 critical 查询。闭式仅作参考预期，最终仍要原始 LP 与阈值证书通过。
