# WO-T1a 图件合同（先于绘图）

## 核心结论与证据链

1. **TIA-G5**：已落盘的精确 LP 值符合实际尺寸与荷载给出的滑移/铰接闭式；敏感性在两区与交点分别表现为光滑和单侧导数，但 μ = 0 按一般最优面回收锥合同不报告认证斜率。
2. **TIA-G2–G4**：这是同相形貌族的退化网格，μcrit 恒为 0；λ 同时就是块高（一周期占满），不是独立波长变量。仅展示固定多边形的单体一阶零锥、`TRANSLATION_IMMOBILE` 与认证 μcrit，不宣称得到非退化设计曲线。A = 0 是接触骨架变化边界，不与 A > 0 作同骨架连续插值。

## 面板、范围与禁区

- 图 1：定量网格；容量为主面板，N = 3/5/7；另三面板为 N = 3、h = P = 1 的 dF/dμ、dF/dP、dF/dh。实线为实际参数的闭式参考，点为已保存精确裁判；交点左右导数分标记，μ = 0 不画伪零斜率。
- 图 2：定量网格；行是 TIA-G2/3/4，列是单体零锥数、平移不可动体数、认证 μcrit；每格在固定三内体查询中计数，取值 0–3，不把多体状态偷换成单体结论。注明界面分别为 2/8/8 段。
- 不绘制 TIA-G1/G5 “设计互锁曲线”；不将 UNBOUNDED 解释为锁定。
- 图 1d 在 μ = 1 的三角点直接标 `h−: 2` 与 `h+: 0`，避免把参数 h 的两侧导数看作横轴 μ 的两侧。
- 图 2 的 G3/G4 只称圆弧/正弦表形多边形轮廓，不称已认证的曲面近似。真圆格 A = 1/4、λ = 1/2 有光滑一阶机构；2/4/8/16 弦内接多边形却全部零锥，因此这些加密不能消除伪互锁。其他椭圆/正弦格未复核，不能推广此反例。
- profile1：刚体、小变形、无限抗压、无黏聚、恒定 μ、关联流动；承载力相对非关联库仑为不安全侧上界，正无界阈值为不安全侧下界。μ = 0 不受流动法则区别影响。无自重；G5 有明确端板预压。图不是弹性有限元承载力比较。
- 仅消费既有诊断 JSON；**不运行几何、LP、阈值或敏感性求解**。这是诊断图，不是 eab2.case.v1 批导出或 C++ 性能数据。
