# WO-T1a 图注与交付索引

## 图 1：TIA-G5 有限承载力及敏感性

[PNG](g5_capacity_sensitivity.png) · [可编辑 SVG](g5_capacity_sensitivity.svg) · [PDF](g5_capacity_sensitivity.pdf)

**图注。** a，N = 3、5、7 等宽矩形块在 h = P = 1 下的 F/P–μ 关系；彩色线由已冻结算例的实际 L、b、h、P 计算 `F = min(2μP, 4Ph/(L−b))`，圆点为原诊断精确 LP 值。滑移区重合的多个点按同坐标叠画，没有扰动横坐标。b–d，N = 3、L = 3、h = P = 1 时，分别为 dF/dμ、dF/dP、dF/dh 随 μ 的变化；灰线仅是闭式参考，圆点为已认证敏感性。μ = 0 的一般最优面回收锥合同给 `singular / possibly_discontinuous`，故不绘制斜率点，也不拿闭式零值填充。μ = 1 时，空心左三角与实心右三角分别表示**对该面板被微分参数**的左导数与右导数；尤其 d 面板的左右指 h 的扰动方向，并非横轴 μ 的左右。该点 dF/dμ 与 dF/dh 均为左 2、右 0，而 dF/dP = 2。各面板力与长度使用算例输入单位，a 的 F/P 与 c 的导数为无量纲。

端板只有轴向平动自由，掩码 `[1,0,0]`；自重为零，但存在明确端板预压。更改端板自由度时，本闭式不适用，相关反例见主报告，不混入本图。

## 图 2：TIA-G2–G4 同相多边形退化网格

[PNG](g2_g4_design_grid.png) · [可编辑 SVG](g2_g4_design_grid.svg) · [PDF](g2_g4_design_grid.pdf)

**图注。** 行分别为 TIA-G2 两段折线、TIA-G3 八段圆弧表形多边形轮廓与 TIA-G4 八段正弦表形多边形轮廓；不宣称它们是已认证的光滑曲面近似。每族扫描 A ∈ {0, 1/16, 1/8, 1/4} 与 λ ∈ {1/2, 1, 2}，共 36 个确定性构型。**λ 轴就是块高（一周期占满），不是独立于块高变化的波长。** 前两列分别给三个内体逐一对固定邻体查询时的一阶零锥体数与 `TRANSLATION_IMMOBILE` 体数，分母均为 3；第三列独立给认证 μcrit 与是否达到阈值。所有正幅值格为三个单体一阶零锥、三个平移不可动，且 μcrit = 0 为闭阈；A = 0 时均为非零一阶锥和缝滑，μcrit = 0 为开阈。斜线格标明 A = 0 发生 L1 接触骨架变化，不能跨该边界按同骨架光滑插值。该同相族退化，没有取得非退化形貌设计结果；新形貌族转 T1b。

锥 = {0} 推出不可动；锥非零推不出可动。平移不可动与一阶判据不是 SE(2) 有限运动复核。μcrit = 0 本身也不是锁定证书，因此图中三类量并列而不互相替代。图不含 TIA-G1/G5 “互锁设计曲线”。

本轮 dμcrit/dA 记录不认证斜率：跨越基导数合同不适用于钉在定义域边界的阈值，但只要一阶不可动性保持，μcrit 局部就恒为 0。不画裁判未认证的零斜率曲线，也不主张普遍的 h/l 无关性。

**曲面反例限定。** TIA-G3 真圆格 A = 1/4、λ = 1/2、半径 1/4 的光滑圆弧接触允许两侧内块反向转动、中块竖移的一阶机构；全弧径向法向速度恒为零，μ = 0 承载力为零。相应的固定表多边形和真圆的 2/4/8/16 弦有理内接多边形却均为一阶零锥，说明这四次加密仍保留相对于光滑界面的不安全伪互锁，不能靠分段数增加就宣称曲面极限正确。反例只证明这个真圆格；其他椭圆及正弦格未复核。本图不能据此支持起伏曲面增强互锁的普遍定性趋势。

## 共同口径、复核与源数据

所有图均为 profile1：刚体、小变形、无限抗压、无黏聚、恒定 μ、关联流动；承载力相对非关联库仑给不安全侧上界，正无界阈值则是不安全侧下界。μ = 0 不受两种流动法则区别影响。无自重。不得与弹性有限元承载力作数值等同。

这些是有限确定性精确算例，不是统计样本；无误差条、重复实验、均值或显著性检验。仅对既有结果作图，未重跑任何求解；不是正式 `eab2.case.v1` 导出，也不是 C++ 性能目标集。
