# G4 砖一·多步实验第一批数据（2026-09-18）

砖一的主张（03 文档）："入口块盖胞腔结构可作为互补问题活动集切换的先验图"。设计文档把它设为
Phase 1 末的 go/no-go。这里是二维 DDA 上的第一批数据，来自沙箱生成的三条多步 dump
（`tools/run_bdda_kernel.py`，插桩内核 df_rebuilt.exe，`BDDA_DUMP_STEPS=N`）。

## 设定

对步 k 的每条 legacy v-e 接触（键 = (顶点, {边两端}) 经回绕别名换算）：
- **真值** = 步 k+1 携带进去的状态 m0_2（即步 k 收敛后的开/闭；键消失视为张开）。
- **P1 转移态先验** = 步 k 携带进来的 m0_2（legacy 开闭迭代的起点）。
- **P2 静态几何先验** = 步初几何上盖的 gap ≤ 1e-6·w0 → 闭。
- **P3 运动学外推先验** = gap_k + (gap_k − gap_{k−1}) ≤ 1e-6·w0 → 闭（用上一步到本步的间隙趋势外推一步）。
- **后验几何一致性** = 用步 k+1 的几何算 gap ≤ tol 与真值的一致率（任何"只看 gap"的预测器的天花板）。
- **翻转事件** = P1 ≠ 真值的样本，即开闭迭代真正要解决的那部分。

## 读法（诚实版）

1. **静态几何先验对翻转事件几乎零预测力**（82 个翻转里抓到 5 个）。翻转由荷载决定，步初几何不知道荷载——这在预料之中，但现在有数了。
2. **几何轨迹（间隙趋势外推）能抓到约一半翻转**（39/82）。信息来自上一步的运动，不来自盖的组合结构本身；盖系统在这里的贡献是给每个 (顶点, 边) 键一条跨步一致的 gap 序列，使外推可做。
3. **即便拿到结果几何回看，也只有 ~70% 的翻转能由 gap 符号解释**（60/82）——其余是罚弹簧下"闭合但 gap 略正/张开但 gap 略负"的状态，纯几何谓词的天花板就在这。
4. **legacy 的开闭迭代在这些算例上两轮就收敛**（bb52 步 1 首次判定即收敛 54/54，迭代内零翻转）。任何热启动的收益天花板是省一轮。

## 对砖一的判决

- **静态版（"盖分解本身预测活动集"）：关闭。** 在 DDA 的准静态小步长下，活动集切换是荷载事件，几何先验不携带该信息。
- **运动学版（"盖键上的 gap 轨迹外推"）：有限。** 抓一半翻转，收益上限一轮迭代，对两轮就收敛的 legacy 不值得建。
- **保留的价值不在预测在枚举**：盖系统给了活动集问题一个完备、带语义、跨步可追踪的候选集——这是 G1 已经证明的（legacy 53/53 复现）。砖一的商业/学术叙事应改写为"完备候选集 + 跨步键一致性"，不再说"几何先验预测活动集"。
- **未测的一档**：接触隐式优化（Posa 系）的初值痛点是"很多接触、初值很差"的场景，与 DDA 小步长准静态不同；那里的判决需要在那种问题上另做，本数据不能外推。
