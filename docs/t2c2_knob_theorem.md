# T2c2：8 弦凸耳的刚体临界公差（所有者定理，第 2 版）

日期：2026-10-26。作者：Claude（所有者）。本稿在任何 T2c2 代码之前写入，是 WO-T2c2 的理论合同。

**修订记录。** 第 1 版为所有者初稿。第 2 版经两路非作者反驳：证明审计逐步重推，独立计算路用自写的精确腐蚀与 Q(√5) 算术复核全部数值，并在 δ° − 2^-10、δ° − 2^-14（窄窗口到 δ° − 2^-20）以 16416 个转角切片加窄窗口与随机规划搜索逃逸，均未找到；阳性对照在 δ° 以上都能找到逃逸。两路都判定理成立。第 2 版的改动：引理 A 改用未截颈的弦八边形 Q 给出完整证明；引理 C 改为一行距离论证；引理 D 改用"条带"论证并订正八边形时的颈顶顶点；引理 E 给出转动后移动体的精确竖直范围；引理 B 改用"首次离开时刻"的写法；订正 B0 的描述（九边形，不中心对称）；写明"与 K 无关"所需的条件；补充 π ± φ 的朝向与更宽的逃逸集合。

## 1. 对象

**几何。** `tolerance_knob(segments=4, head_width=2, neck_width=1, height=2, wall=2)`（T1b §3.2）。本稿只讨论这一个多边形。移动体 A 有 11 个顶点，右半边界依次为

```text
(0,0) → (3/5,1/5) → (1,1) → (3/5,9/5) → (1/2,11/6) → (1/2,2)
```

左半为其关于 x = 0 的镜像；(±1/2, 11/6) 是两个凹顶点。障碍：左墙 (−3,0), (0,0), (−3/5,1/5), (−1,1), (−3/5,9/5), (−1/2,11/6), (−1/2,2), (−3,2)，右墙为其镜像，地板 [−3,3] × [−2,0]。墙政策 e = 0（墙不腐蚀）。

**辅助多边形。** Q = conv{(0,0), (0,2), (±3/5,1/5), (±1,1), (±3/5,9/5)} 是未截颈的弦八边形，关于 c = (0,1) 中心对称。Q 在 y ≤ 11/6 的部分与 A 的鼓包相同，在 y ≥ 11/6 的部分是三角形 (±1/2, 11/6), (0, 2)，含于颈矩形 [−1/2,1/2] × [11/6, 2]，所以 **Q ⊆ A**。（A 的鼓包部分是九边形，不关于 c 中心对称；平行主弦来自 Q 的中心对称。）

**容差。** A_δ = A ⊖ δK，K 为方形 [−1,1]² 或有理八边形（顶点 (±5/12,±1)、(±1,±5/12)）。记 h = h_K(1, 1/2)（方形 3/2，八边形 29/24），ℓ(δ) = 1 − hδ，n = (1, 1/2)，c = (0, 1)，φ = arctan(1/2)，cos φ = 2/√5。

## 2. 定理

```text
δ° = (1 − 1/(2 cos φ)) / h = (4 − √5)/(4h)，   方形 δ° = (4 − √5)/6 ≈ 0.2939887，   八边形 δ° = 6(4 − √5)/29 ≈ 0.3649515。
```

**定理。** 对第 1 节的凸耳与这两种 K：对 0 ≤ δ < δ° 起始位姿 SE(2) 困住；对 δ ≥ δ° 可刚体逃出（接触允许）。因此 δ*_SE2 = δ°，不取到；平移临界公差 δ*_T = 1/(2h)，且

```text
δ*_SE2 / δ*_T = 2 − √5/2 ≈ 0.8820。
```

**适用条件（K 只通过这些性质进入证明）。** K 中心对称且 h_K(1, 1/2) = h_K(1, −1/2)（保证 ±φ 两侧对称与 δ*_T 的形式）；引理 A 的其余约束在 δ° 处有余量（见下，两种 K 均满足）；引理 C 的距离不等式成立。在这些条件下比值与 K 无关；本稿只对上述两种 K 下结论。

## 3. 证明

### 3.1 平移临界公差

A 被夹在 |x| ≤ 1 − |y − 1|/2 之间，腐蚀后 A_δ ⊆ {|x| ≤ ℓ − |y − 1|/2}，且 (±ℓ, 1) ∈ A_δ。只平移时，连接这两点的水平线段必须在 y = 2 处整段落入 |x| ≤ 1/2，故平移可逃当且仅当 ℓ ≤ 1/2，即 δ ≥ 1/(2h)。这与 T1b 的 1/(2H) 一致。

### 3.2 困住侧（δ < δ°）

**引理 A（内切圆）。** 对 δ ∈ [0, δ°]，B(c, r(δ)) ⊆ A_δ，r(δ) = ℓ(δ) cos φ = 2(1 − hδ)/√5。

证明：只需 B(c, r) + δK ⊆ Q（因 Q ⊆ A）。Q 是凸多边形，只需对 Q 的每条边所在半平面 m·(p − c) ≤ b 验证 r|m| + δ h_K(m) ≤ b。
- 四条主弦 m = (±1, ±1/2)、b = 1：r|m| + δh = ℓ cos φ · (√5/2) + δh = ℓ + δh = 1，取等号（圆盘与腐蚀后的主弦相切）。
- 其余四条边 m = (±1, ±3)、b = 3：要求 g(δ) = 3 − r(δ)√10 − δ h_K(1,3) ≥ 0。g 是 δ 的仿射函数；g(0) = 3 − 2√2 > 0；g(δ°) = 3 − √10/2 − δ° h_K(1,3)，方形约 0.2429、八边形约 0.1719，大于 0（在 Q(√5) 中平方后精确判定）。故在 [0, δ°] 上恒成立。∎

**引理 B（圆盘过不去颈）。** 圆心在 A 的内腔内部、半径 r > 1/2 的圆盘，不能在不与墙内部相交的情况下逃出。

证明：内腔被闭的墙与地板围住，只在 {y = 2, |x| < 1/2} 处开口，开口两端是墙顶点。若圆心曾离开内腔内部，取其首次离开时刻：此时圆心落在内腔边界上。若在墙上，圆盘已含墙内部的点；若在开口上，圆心为 (x, 2)、|x| < 1/2，圆盘在 y = 2 − η 处的弦半长 √(r² − η²) 对足够小的 η > 0 大于 1/2，而墙在 y ∈ [11/6, 2) 内占据 |x| > 1/2，矛盾。∎

**困住侧的证明。** 对 δ < δ°，r(δ) > 1/2。由引理 A 与圆盘绕 c 转动不变，任何位姿下圆盘都含于移动体。移动体逃出则圆盘随之逃出，与引理 B 矛盾。∎

### 3.3 逃出侧（δ ≥ δ°）

由腐蚀嵌套，逃出性随 δ 单调，只需证 δ = δ°。路径：绕 c 原地转动 θ* = −φ（或 +φ，二者对称），再竖直上移到 y = 2 以上，最后沿 +y 射线到无穷。

**引理 C（转动阶段自由）。** 在 δ = δ°，移动体离 c 最远的点距离 ρ 满足 ρ² < 4/5（方形 ρ² ≈ 0.541，八边形 ρ² ≈ 0.436），而 Q 的边到 c 的距离平方为 4/5（主弦）或 9/10（其余），所以 B(c, 2/√5) ⊆ Q ⊆ A，而 A 与墙、地板的内部不交。转动中移动体始终在 B(c, ρ) ⊆ B(c, 2/√5) 内，故绕 c 的任意转角都无内部相交。∎

**引理 D（转动后水平宽度恰为 1）。** A 的全部 11 个顶点满足 |n·(p − c)| ≤ 1，故 A ⊆ {|n·(p − c)| ≤ 1}；K 中心对称，腐蚀后 A_δ ⊆ {|n·(p − c)| ≤ ℓ(δ)}。切点 c ± r n̂ ∈ A_δ（引理 A）取到等号。R_{−φ} 把 n̂ 转成 (1, 0)，因此在 δ = δ°、转角 −φ 下移动体的水平投影恰为 [−r(δ°), r(δ°)] = [−1/2, 1/2]。∎

（八边形 K 且 δ > 2/7 时，腐蚀后的颈顶角是 (±(1/3 − 5δ/12), 2 − δ)，由凹顶点处的 δK 截出；第 1 版写的 (±(1/2 − δ), 2 − δ) 不是顶点。条带论证不依赖具体顶点。）

**引理 E（平移阶段自由）。** 在引理 D 的位姿下，移动体落在 [−1/2, 1/2] × [1/2 − 1/(5√5), 1 + (1 + √5)/(2√5)] ≈ [−1/2, 1/2] × [0.4106, 1.7236] 内（两种 K 相同）。闭条带 [−1/2, 1/2] × [1/6, ∞) 不含墙与地板的内部点（内腔半宽在 [1/6, 2] 上不小于 1/2，y > 2 以上没有墙）。竖直上移时移动体始终在该条带内，故无内部相交。∎

**逃出侧的证明。** 由引理 C、D、E，δ = δ° 时路径存在；δ > δ° 由单调性。∎

## 4. 补充事实（非定理所需）

- 失效模式（供 T2c 的盖标签）：临界时移动体以两条平行主弦同时贴住颈部两侧竖直墙面（两处平行的边-边接触）；方形 K 时腐蚀后的颈顶角也在 x = 1/2 处与墙相触（y ≈ 1.5393）。这与平移临界时"最宽顶点对颈宽"的模式不同。
- 逃逸朝向有四个：±φ 与 π ± φ（π ± φ 时块倒置通过）。在 δ° + ε 处，固定转角的逃逸在每个朝向附近约 |α| ≲ 24hε/√5 的范围内存在（块沿倾斜的主弦方向穿过高 1/6 的颈），比"先转后竖直上移"的路径宽；后者对方形只容许 α ∈ [−2.49ε, 5.37ε]，因此 δ° + 2^-24 处的证书需要 |u − (2 − √5)| 约 10⁻⁷。
- 笼证书形式的佐证：只用不变圆片的闭链笼证书要求圆内接多边形 D 的内切半径大于 1/2、外接半径不超过 r(δ)。正多边形所需边数约 π/√(2(r − 1/2)/r)：δ° − 2^-12 处约 87 边，δ° − 2^-24 处超过 5500 边。困住侧的结论来自定理本身，证书只作有限个 δ 的佐证。

## 5. 交 WO-T2c2 的精确核验义务

1. 定理中全部数值不等式的精确核验（引理 A 的 g(δ°) > 0、引理 C 的 ρ² < 4/5 与边距、引理 D 的 11 个顶点、引理 E 的竖直范围与内腔半宽），在 Q(√5) 中或以平方比较完成，写成标准库的精确测试。
2. δ° 处的精确逃逸核验：以 Q(√5) 中的精确转动（cos = 2/√5、sin = −1/√5）给出转动后位姿，核验水平投影恰为 [−1/2, 1/2] 与上移自由（独立于 `se2_paths` 的实现）。
3. 有限个 δ 的证书佐证：δ° − 2^-k（k = 6…12）的双核验笼证书；δ° + 2^-k（k = 6…24）的双核验逃逸证书（生产核验器与独立 oracle），两种 K 都做。
4. 与 T1b、T2c1 一致：δ*_T 复现；T2c1 的凸耳括号都落在定理值两侧。

只对本稿的 8 弦凸耳、e = 0、两种 K 下结论。e = 1 与更细刻面（16/32/64 弦）不在本定理内，留作 WO-T2c2 的 P1 探索与 T2d。
