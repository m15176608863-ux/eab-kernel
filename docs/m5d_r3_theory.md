## 合同与 oracle 边界

R3 证书对任意连续、逐顶点坐标 L∞ 管内路径成立。拒签只表示充分条件不足，不能解释为实测模型敏感。内部变异限定在真实函数体，直接调用具名语义断言；源码绑定和冻结摘要不参加判红。

主 oracle `tests/m5d_r3_oracle.py` 的完整 import 清单是 `fractions.Fraction`、`functools.lru_cache`、`math.comb`。平移辅助 oracle `tests/m5c_teeth_oracle.py` 只 import `fractions.Fraction`。没有生产几何、区间、求根或接触枚举原语导入。测试驱动另用 itertools、random、pytest 和内部变异脚手架；这些不是 oracle 的几何原语。

平移事件使用线性入射精确根。有理运动由独立多项式运算、Sturm 精确根计数和显式工作栈枚举全部 VE/EV 入射，并在根上核验闭边投影符号。每个名义输入和每条扰动先由独立顶点投影提供初态凸包严格分离见证；没有该见证就拒绝使用首次事件结论。已知有理根、重复根和端点根另有自检门。

## 八类子条件

1. **早期全窗**：必须覆盖 `[0,l]`，不是 `[0,l/2]` 或 `[l/2,l]`。否则括区前可能已有接触并离开。分别用两条不同多项式轨迹杀掉跳过、缩短和只查后半段三种变异。
2. **EV 竞争者**：不能只查 VE；另一块的顶点可能先碰本块的边。
3. **两侧投影**：目标的两侧边内投影都须严格正，否则支撑线根不是闭边接触。
4. **末段**：必须检查每个子窗，包括最后一个。端点跨号不能替代整窗的投影和竞争者检查。
5. **L1 对偶归一**：坐标 L∞ 管的投影误差为 `||n||1(ra+rb)`，不能用 `||n||∞`。
6. **端点扣费接线**：目标端点的符号必须扣除误差预算。删掉 `endpoint_end` 的扣费会允许管内真实首时刻移出所签括区。
7. **边长误差预算**：双线性预算为 `du||W||1+dw||U||1+2du*dw`，其中 `du=2rb`、`dw=ra+rb`；另一端 V 也要独立计入。删掉 `dw||U||1` 有 A 顶点移动及 B 边端点移动两个实际反例。
8. **不等分母**：相对向量必须按 `(Np*Dq-Nq*Dp)/(Dp*Dq)` 构造。真实 P2 的 `D(s)=1+u1²s²` 非常数；两块不同转动参数不能走等分母捷径。

端点扣费与边长项的真实反例都有独立精确首时刻 `103/200`，位于错误签发的括区 `(1/4,51/100)` 之外。额外的 `du||W||1` 与混合项拒签门只证明严格预算合同被破坏；不把这两项声称为已找到物理错标签。W/V 各三个删项变异另核精确预算恒等式，也不夸大为实际错签反例。

## 阈值边缘、非刚体扰动与多样性

固定名义几何时，各误差预算随半径非减，每个 guard 是非增函数的有限 min/max，因此可二分最大可认证半径。默认 pytest 进行 40 次精确有理二分，保留上下界而不冒称精确 r*；另断言二分宽度不超过 `rlo*2^-24/64`。验签与对抗点是 `rlo*(1-2^-24)`、`rlo/2`。

两块 P2 都有非零转动、平移和对称应变，分母不同。逐顶点独立的两个时间端点坐标误差均不超过半径，线性插值保证整个时间窗处于管内；其轨迹非刚体且随时间变化。每条轨迹同时检查首次标签和首时刻严格处于开括区，有限搜索不代替 R3 全管定理。

长证据脚本扩展多个非等价形状和相对位置，独立求首标签与括区；零半径都无法签发的构型单列拒签，不虚构稳健半径。它补强 M5c 旧 D=1 有限对抗的覆盖，不重写旧冻结证据。默认 pytest 保持规模适中。

## 不变性与数值边界

单位缩放必须同时缩放管半径。大公共平移不改相对运动。有理非轴向正交旋转后的 L∞ 半径按诱导范数保守放大；元门检查标签与独立首时刻，不要求保守包络的最大可认证半径旋转不变。全程使用整数和 Fraction，无浮点判定阈值、无绝对容差。日志与显示数字不是判定输入。
