## 1. 只读核对的 b-DDA 更新

来源：`D:/b-DDA/bdda2/geom/moments.hpp` 的 `update_block_vertices`（51–63 行）；哈希冻结在 `reports/codex/M5a2_evidence/affine_full_summary.json`。

以输入形心为 c、两项平移为 d、转角为 θ、常应变矩阵为

```text
E = [[ex, gxy/2], [gxy/2, ey]]
```

其理想实数端点更新为

```text
x' = c + d + [R(θ) + E] (x-c).
```

有限转动与应变是**相加**，不是 `R(θ)(I+E)`。源文件还规定逐语句浮点分组，故其 binary64 顶点结果一般不严格落在同一个精确仿射映射上。本单只读取源码和既有快照，不运行或修改 b-DDA。我们没有取得每一步内部 d、θ、E，所以拟合模型不是内部自由度的唯一恢复。

## 2. T-A1：精确仿射最小二乘拟合（已证明、已实现）

输入按固定顶点身份配对的有理点 p_i、q_i。取**等顶点权重**形心 c=mean(p)、t=mean(q)，令 X_i=p_i-c、Y_i=q_i-t。

```text
C = Σ X_i X_i^T,  H = Σ Y_i X_i^T,
M = H C^(-1),  d = t-c,
e_i = q_i - [c+d+M(p_i-c)],  δ_aff = max_i ||e_i||∞.
```

初始顶点张成平面时 C 正定；二次目标 `Σ||Y_i-MX_i||²` 的梯度为 `2(MC-H)`，故上述 M 是唯一最小二乘解。所有量使用 Fraction，行列式只判断严格正，不使用条件数或绝对容差。δ 是该模型的准确最大残差，**不是 L∞ 最优拟合值**。

生产实现：`src/eab/kernel2d/affine_motion.py::fit_affine`。主 oracle 在 `test_fit_matches_independent_three_point_and_normal_equation_oracles` 中使用未中心化的 3×3 正规方程和显式 Cramer 行列式，与生产 2×2 中心化解不共用拟合原语；同时检查残差对常数/x/y 三列正交。

公共 `AffineFit`/`DDAAffineMotion` 及拟合入口拒绝 float、bool 和错误维度；`AffineFit` 拒绝空残差表。记录的 `EXACT_AFFINE_ENDPOINTS` **仅表示给出的残差表恰好为零，不表示物理路径、首入或接触拓扑已认证**。通过 `fit_affine` 返回的残差表由上述公式精确计算。

## 3. T-A2：端点闭合的 additive 有理轨迹（已证明、已实现）

选择有理半角参数 |u|≤1（回放使用旧刚体拟合提出的 u，不声称它就是内部 θ 的半角），定义

```text
R(v) = [[1-v², -2v], [2v, 1-v²]]/(1+v²),
E* = M-R(u),
X(s,p) = c+s d + [R(su)+s E*](p-c),  0≤s≤1.
```

直接代入得 `X(0,p)=p`、`X(1,p)=c+d+M(p-c)`。它与 DDA 具有“有限转动 + 常应变线性增长”的相加结构，但有三点不等价：

1. `E*` 是由选定 u 得到的补偿矩阵，未必对称，不能解释为 b-DDA 原始应变；
2. 转角时间律为 `2 atan(su)`，不是线性转角 `sθ`；
3. 只知道离散端点，无法据此恢复或认证 b-DDA 的连续物理路径。

若 δ_aff>0，一般不存在对全部快照顶点精确闭合的共同仿射映射。我们另外明确**定义**逐顶点校正族

```text
Xhat_i(s) = X(s,p_i)+s e_i.
```

它严格闭合原始快照两端，但通常不再是整块共同仿射映射。不能同时声称“共同仿射”和“正残差快照端点完全闭合”。

退化门：

- `E*=0`（即 M=R(u)，乘法分解语言中的 S=I）时，逐有理时刻、逐坐标严格等于 M5a `SE2Motion`；
- u=0 时，`X(s,p)=(1-s)p+s X(1,p)`，即拟合端点之间的 M4c 顶点弦；校正族则逐坐标等于**原快照**的 M4c 顶点弦；
- 原始两端若严格仿射相容，δ=0，两个弦族相同；否则不能把拟合端点弦等同于原快照弦。

对应门：`test_additive_trajectory_matches_independent_component_oracle`、`test_zero_strain_is_se2_and_zero_rotation_is_m4c_vertex_chord`、`test_linear_residual_correction_closes_data_without_certification`。u=0 的扩张方块最小例右边界是 `1+2s`、墙是 x=2，首接触 1/2；用 M4c 核验，但不据此声称一般仿射首入已实现。

## 4. T-A3：事件次数上界（证明完成，求解实现未完成）

每个块的分母 `D(s)=1+u²s²` 在实数区间严格正。每个顶点的坐标分子次数≤3；逐顶点 `s e_i` 校正也不改变该上界。边向量分子次数≤3。异块点差写成共同分母后分子次数≤5。点在线、投影下界、投影上界的分子分别由叉积/点积构成，在分母 `D_A D_B²>0` 下，次数均≤8。

因此零多项式以外的一维事件可以用有理 Sturm 隔离，仍是可精确代数处理的问题；恒共线时还必须加入投影端点事件，路径中多边形自交/塌缩也必须先拒绝或分类。这里的“≤8”是可靠通用上界，不声称不可约或最小。

**未实现**：当前已验收 `RealAlgebraic/roots_interval` 明确支持≤5次。本单不偷偷放宽构造域，也不把一般事件截到5次。完整八次隔离、法锥重建、事件完整性和独立首入 oracle 门属于后续 B8 工作。

## 5. T-A4：非反转充分条件（已证明、已实现）

令 `a=max_i Σ_j |E*ij|`。任意二维旋转满足 `||R^-1||∞≤2`，故若 `2a<1`，则对 0≤s≤1，`||s R(su)^-1 E*||∞<1`，Neumann 级数保证 `R(su)+sE*` 可逆。行列式连续、s=0 时为1，所以整个区间行列式严格正。它保持初始简单环的简单性与方向。

`orientation_preserving_sufficient=False` 只表示此充分条件无结论，不表示已经倒置。该证明**不覆盖正残差逐顶点校正后的环**。最小反例 M=−I、u=0：两端均正向，但中点塌缩。门：`test_orientation_sufficient_bound_and_degenerate_counterexample`。全数据15220块帧的共同仿射轨迹均通过此保守充分条件，但没有因此得到首盖证书。

## 6. T-A5：残差界能证明什么（部分证明，首盖证书未实现）

对上面**明确指定**的校正族，有严格恒等式 `Xhat_i(s)-X_i(s)=s e_i`，因而 `||Xhat_i(s)-X_i(s)||∞≤s δ_aff`。边上相同重心系数的点也服从同界。这是两种指定模型之间的整段顶点/边偏差界，不是未知实际轨迹的界。

端点误差单独不能控制未知路径：任意 K>0，`h(s)=4K s(1-s)` 在两端为零，中点为K；静止路径与平移 h(s) 的路径可有完全一样的端点和 δ=0，却有任意大的步内差异。门：`test_endpoint_residual_cannot_bound_unknown_interior_path`。

对于已指定的校正族，尚需证明并实现：首盖的严格横截界、竞争事件的间隔、非首事件的符号间隔，以及正残差校正后环的有效性。精确接触时刻一般会随扰动改变，故证书必须先明确认证的是“首盖身份/事件顺序”还是“同一个精确时刻”。本单**没有**这些完整证书；所有63910个正仿射残差块对帧均标未认证，100个零端点残差块对帧也不等于取得了首盖或物理路径证书。

### 7.2 三模型端点诊断，不冒充三模型首盖重算

对M5a的937个 SE(2)/弦模型首结果差异，从原快照重新算三种端点的独立实心重叠状态：

- 933个：刚体拟合端点与原快照端点的重叠/接触/分离状态不同；仿射拟合端点状态与快照相同。
- 4个：刚体端点状态与原快照相同；仿射拟合端点状态也相同。
- 仿射拟合端点状态与快照不一致：0/937。

这是**伴随端点状态翻转的分层统计**，不是“933个已证明纯端点原因、剩余4个已证明纯路径原因”。相同重叠状态仍容许端点形状/盖身份不同，翻转也不排除步内路径同时起作用。若要因果分离，需要固定两端的反事实轨迹、一般仿射精确首入及事件对应证明。

最小真实例保存在冻结 JSON 的 `cases.<case>.examples`：bb05第3步(2,3)是端点状态翻转；bb05第9步(1,4)是端点状态不翻转但首结果不同；bb10第2步(1,7)提供另一同状态反例。它们存储四组完整精确顶点和历史首结果，可单独重算，不依赖长运行临时几何文件。

另外 `reports/codex/M5a2_evidence/affine_minimal_examples.json` 自包含前三种关键诊断：bb05第3步(2,3)端点翻转、bb05第9步(1,4)端点同状态、bbF038第1步块1与邻块2的 δ_aff/gap≈2.945。命令 `python reports/codex/M5a2_evidence/affine_minimal_examples.py` 只用该JSON内嵌的精确顶点即可重算三例；不需要ignored全时程输入。`--freeze` 才需要原始全时程文件，默认验证不会重冻结。

在初始已压入时，三模型使用相同初始环，因此该时刻的全局最短出口/参考边问题几何上不随后续插值改变；这是共享初态的逻辑性质，不是本单新增的独立全量PD计算。legacy首盖、漏检、仿射首盖分类尚未重算，B10仍为PARTIAL。

## 8. 门、imports 与变异

主拟合/轨迹 oracle imports：`fractions.Fraction`；`random.Random`仅产生固定seed参数，`pytest`仅断言基础设施。测试中SE2/M4c imports是退化一致性检查，不当独立oracle。间隙归一化的独立基准是显式3-4-5矩形闭式；长诊断的端点状态用 `g0_oracle` 的整数绕数/相交，与生产事件算法零几何原语共用。

不变性门含 `2^-400 / 1 / 2^397` 单位缩放、|t|=0/1e3/1e5/1e6、6个固定seed有理旋转。L∞残差的数值本身不是旋转不变量，所以检查的是残差向量协变及平方L2总残差按s²缩放，不偷换范数。生产核心imports仅dataclasses/Fraction；没有姊妹代码依赖。

`reports/codex/M5a2_evidence/affine_mutations.py` 直接编译三处生产函数体的缺陷版本，在运行前注入；不调用源码哈希门，也不伪造输出。三种缺陷均由指定新语义断言杀死：拟合交叉系数反号、≤2^-52正残差冒充精确、残差校正项反号。`affine_mutations.json`给出红断言原文。

数值合同：所有生产标量/矩阵为int/Fraction，正规方程/残差/轨迹不做binary64构造；回放显示仅调用既有`scalar_rational`/`sqrt_rational`，显示不参与分类。静态准入统一纳入M5a2主报告。
