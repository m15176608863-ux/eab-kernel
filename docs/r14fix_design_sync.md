## 1. 分项数值合同

本节补充并优先于 [R13FIXb 基础合同](exact_predicates_plan.md#r13fixb-numeric-domain)。
**D400 不是所有物理量的统一支持域**；精确判定/有理模型不缩域，连续输出另有 RN-even 边界。
下表中的“有理数”只指有限 `int/Fraction` 或给定有限 binary64 的精确值，不指任意用户定义标量协议。

| 物理量 / 参数 | 支持域与入口处理 | 不可推论的内容 |
|---|---|---|
| 坐标、平移、参考点、方向、速度、力、力矩、荷载旋量 | 精确几何/LP/完整有理代数路径保留全部有限有理数；非零方向等几何有效性仍由原 API 检查；要求 float 输出的量在最后走 `scalar_rational` / `sqrt_rational` / `unit_rational` | 不因坐标在 D400 就保证所有派生量可表达；数据容器不是提前舍入入口 |
| 长度、间隙、面积、体积、距离报告、导数 | 完整代数表达式先求值；非零结果必须位于有限非零 RN-even 舍入胞；正负号/是否允许负数由相应量语义决定 | 间隙可有符号；面积与黏聚强度非负；不能统一强加“所有数非负” |
| 黏聚强度与接触面积 | `LimitContact` 要求有限且非负；`c*A` 精确进入 LP；黏聚切向方向须精确垂直于存储法向，且位于单位圆盘内 | `contacts_from_covers` 不知道真实面片分配，继续拒绝非零黏聚，不把代表面面积当接触分配面积 |
| 摩擦系数 μ | **`0 ≤ μ ≤ 2^20`**，`check_mu` 用精确值比较，接触构造、生成锥、盖转接（含空输入）均检查；二维/三维和多体共用这一界 | 数值界本身不是内接证明；最终生成元另经逐条精确认证 |
| `sin/cos` 弧度、`atan2` 两分量、一般非整数幂的底数/指数 | 必须**可无损表示为有限 binary64**；`binary64_argument` 在任何转换前检精确二进制有效位与指数。含所有 binary64 次正规数，不强套 D400 | libm 是近似模型，不主张全域正确舍入；拒绝有损精确实参不等于提高 libm 精度 |
| 精确整数/半整数幂指数 | 先按精确分母分派；整数不转 float、不丢奇偶；半整数用精确有理平方与平方根。非平凡底数的展开设有具名资源上限；0/±1 的可表达大幂不因此被拒 | 不能承诺任意精确表达式的无界资源；输出非零下溢/溢出仍报错 |
| 二维显式转角窗口 `reflex_vertices.tol`、骨形生成器 `phase` | 在 libm 或混合浮点加法前检查无损 binary64；负窗口仍拒绝；phase 的 Dual 通道不丢弃 | 生成器保留既有分段曲面/libm 模型，不是任意理想曲面的精确表示 |
| b-DDA 检测角 `h1_degrees` | `0` 或 `[2^-400, 90)` 度；构造入口先精确检查，角系数采用明确的 RN 后 radians/sin 模型 | 这是 legacy 显式域窗，不是默认几何谓词；三点测量门不是跨平台 libm 定理 |
| 检测长度窗 `d0/seg_tol/fit_tol` | 有限非负，连续输出可表达；保留精确原参数给几何分支，不能用 fit_tol 替代枚举域窗 | 这是调用方政策，不把舍入噪声偷偷加进窗口 |
| 文本/JSON 连续数值字面量 | 先精确解析，`q=0` 或 **`2^-1075 < |q| < 2^1024-2^970`**；通过后 RN-even 到 binary64。端点分别舍到零/无穷，因此拒绝；标准 JSON 的 NaN/Infinity 亦拒绝 | 不要求十进制字面量无损 binary64；不能在 JSON 默认 float 解析已经归零后再校验 |
| 整数身份、拓扑编号、离散计数 | 保留精确整数，非整数不得截断；枚举尺寸还遵守各 API 的有效性/资源约束 | 不把整数编号与连续测量量混用同一个 float 转换器 |
| 随机几何/有限差分诊断的尺度和步长 | 既有显式 D400 检查保留；随机数与回调值为给定模型样本，报告的最终量检查可表达性 | 三档抽样不是所有 API 的全域误差定理 |
| 骨形示例 `lx/ly/lz/amp/center` | 各非零物理参数在 D400；三长度为正，网格计数为正整数；保留原精确系数和既定浮点网格/正弦样本，坐标完整表达式最后检查舍入胞；Dual 通道保留 | 即使输入均在 D400，抵消后的非零坐标也可能不可表达，此时具名报错，不静默归零 |
| 拱示例 `rin/rout/rho/n` | `0<rin<rout`、非零半径/密度在 D400、密度非负、整数分段数 `2≤n≤4096`；μ 走公共界；坐标、鞋带面积与重力旋量先完成精确代数再检查输出 | 这是有限采样示例构造器的分项域，不向精确几何/LP 强加同一资源界 |
| LP 精确证书的 float 视图、明确的无界/退化哨兵 | 仍按原合同单独标记，权威数值在 exact 见证或 status；不当普通有限物理量 | 不可利用显示例外让普通 primal/读入的非零量静默变零 |

### 无损参数检查的推导

约分有理数 `q = odd * 2^e` 可无损 binary64，当且仅当分母为 2 的幂、去掉分子二进制尾零后有效位数 `b ≤ 53`、
`e ≥ -1074` 且 `e+b-1 ≤ 1023`（零单独处理）。所有比较发生在整数上，再转换；不使用 `float(q)` 自己充当预检。
门：`tests/test_r14_dual.py`、`tests/test_r14_domain.py`。整数幂、tiny/tiny、一般位置/边界/次正规量保留独立 Fraction 参考。

### 为什么 μ 上限仍须配精确圆锥认证

记 `eps=2^-52`、`u=2^-53`。μ≤2^20 给出 `μ*eps≤2^-32`，避免高切向量相加时压缩分量被宏观吞没；
但即使 μ=0.5，sin/cos 与基架的逐分量舍入也可能微量出圆锥，**上限不能单独保证安全**。
对存储法向 n 和最终方向 g，以有理数检查

`n·g > 0`，且 `||n||² ||g||² ≤ (1+μ²)(n·g)²`。

这是任意非零 n 的压缩单边圆形库仑锥，不假定浮点 n 严格单位长，也不调用切向生成器当真值。
候选若不满足，二维先在各分量相邻一 ulp 的有限网格中按精确距离选最近安全表示（保留原非零分量符号，不准变零或非有限）；没有合格邻点才走内缩后备。三维仍作有限次向法向收缩并重新认证；失败则具名拒答。自校验另用叉积平方核验，防止生成器检查被删后两侧一起放行。
二维邻点步骤是为防止过粗内缩在近自锁位置放大容量误差；原 `test_lp_certificates.py` 的 28 格、可分辨要求及闭式误差断言全部不改，`test_r14_cone.py` 另用二维精确行列式核最邻安全表示与删除该步骤的变异。
同类的黏聚方向在 LP 中保留精确有理投影，独立核 `n·d=0` 与 `||d||²≤1`。
这些条件按正线性组合/凸组合保持，因而给定模型不会靠舍入产生抗拉射线或超圆锥抗剪。
门：`tests/test_r14_cone.py`；向内调整量与原候选的逐值门不能被同一生成器自证替代。

## 2. N05 数学订正

理想正 k 棱锥与圆锥、固定相同几何/荷载/黏聚模型时，集合包含只推出
`C(μ cos(π/k)) ≤ C_k(μ) ≤ C(μ)`。**不推出** `C_k(μ) ≥ cos(π/k) C(μ)`。
后者需要容量正比切向能力等额外条件；一般多接触/倾覆/自锁耦合不满足该条件。
实际经认证的 binary64 射线保证圆锥内接上包含；向内收缩后不声称理想内切半径下包含仍逐位成立。

旧 `test_limit.py` 的断言确实检查相对短缺，但只有固定 `amp=.25, μ=.2` 的 k 网格，不能作为一般定理。
全部旧数值断言与网格保留，文案收窄；新门对同几何 `μ=1.8, k=5/6/7` 用独立精确静力可行证书建立真圆锥容量下界，
由此反驳错误相对界，不把 Patton 公式 23 猜作该几何的真容量。
