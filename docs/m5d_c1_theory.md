# M5d C1：严格凸一般位置下的全局最短出口标签证书

## 合同与研究边界

输入是按 CCW 给出的两个二维环 A、B、非负有理顶点 L∞ 半径 ra、rb，以及固定查询点 x（默认 0）。
输出只有 `CERTIFIED_UNIQUE_EXIT` 或 `UNPROVED`；后者不是反例、不是模型敏感性结论。
证书量词是任意独立顶点盒内配置，不限刚体扰动，不要求给出时间路径。
C1 不认证凹环、平行跨环边、原并列集合，也不把凸包边界冒充凹 Minkowski 并集边界。
证明先于实现落盘；计数、测试与变异结果另见 `reports/codex/M5d_evidence/c1_summary.json`。

## 1. 严格凸环存续

对每一条有向边 u=p[i+1]−p[i] 和每一个非端点顶点，令 w=p[k]−p[i]。
逐项要求 `cross(u,w) > 2r(||u||1+||w||1)+8r²`。
两向量的坐标扰动各至多 2r；双线性展开的绝对误差不超过右端。
因而在整个顶点盒及其中任意线性同伦上，每个其余顶点严格在每条边左侧。
这不只是相邻转角检查：每一条边是所有顶点凸包的暴露边，且没有额外顶点落在该边上。
给定循环包含所有这些暴露边，故它就是严格凸 CCW 凸包边界；自交、倒折、重复顶点均被排除。
这里“严格凸多边形”意为每个顶点内角严格小于 π，而不是边界上任意两点的严格凸集合定义。

## 2. Minkowski 边界特征存续（关键补全）

对每对跨环边 u∈A、v∈B，要求
`|cross(u,v)| > 2ra||v||1 + 2rb||u||1 + 8ra rb`。
于是同伦中无跨环边平行（包括反平行）；同环边的循环序由第 1 节固定。
严格凸多边形的支撑面为单点或单边；`face(B−A,n)=face(B,n)−face(A,−n)`。
若 n 是 B 的边外法向，A 在 −n 的支撑面不可能为边，否则跨环平行，故它是唯一顶点；
同理 −A 的每条边对应 B 的唯一顶点。除此以外两个支撑面都是点，不能产生边。
因此 B−A 的边恰为 B 边平移和 −A 边平移，各一条，无遗漏、无合并、无新暴露边。
支撑顶点若沿同伦改变，改变时相邻支撑顶点同值，必出现对应平行边；第 2 条排除了它。
每条边因而保留同一 VE/EV 标签与相同端点的顶点差身份。此支撑面论证同时证明存在性、
穷尽性和标签一一对应，不依赖实现排序算法或角度浮点比较。

## 3. 距离、内部性与唯一最短出口

记 r=ra+rb。每个对应边端点（B 顶点减 A 顶点）坐标位移≤r，欧氏位移≤η=√2r。
对应线段用相同重心系数配对，其 Hausdorff 距离≤η；全部边的并集也满足此界。
名义 x 必须严格在全部 Minkowski 支撑边左侧。对全部闭边计算精确平方距离 q_i；
必须保留相邻边与完整闭端点，不能只列 legacy 选中的边。
令 q 为唯一最小值，要求：

* `q > 2r²`；
* 对所有其他边 j，`h=q_j−q−8r² > 0` 且 `h² > 32qr²`。

第二组当且仅当 `√q_j−√q > 2√2r`：移项再平方时 h>0 保证无赘根。
第一组使同伦中边界到 x 的距离至少 √q−η>0；x 不可能跨边界，因此所有配置仍内部。
距离到紧集为 Hausdorff 度量下 1-Lipschitz；第二组保证任意配置中最优边的距离严格小于每个竞争边。
最优点不能是端点，否则相邻闭边也有同样距离，与唯一性矛盾。
所以认证结果既是唯一闭边、也是完整最短出口特征集合中的唯一 VE/EV 标签。

## 4. 禁止外推与不变性口径

凹环在第 1 节拒签：没有证明遮盖边存续、新暴露边缺失和全局边界分解一一对应。
平行边在第 2 节拒签：拆分后的标签不能由旧合并 facet 的距离差独自认证。
原并列在第 3 节拒签：排除第三名不保证旧并列集合仍全部最优。
旋转 L∞ 盒后用诱导 L∞ 范数扩张半径；该扩大盒会使充分条件更保守，不能声称认证状态对任意旋转完全等价。
元门检查留有余量的旋转/平移/单位变换认证标签，以及距离平方按 s² 协变；边界附近的“不认证”可合法增加。
所有生产判据为精确 Fraction，半径与坐标拒绝 float、bool、字符串，无绝对容差。

## 5. 独立 oracle 与门索引

`tools/m5d_c1_oracle.py` 只 import `fractions.Fraction`：枚举全部顶点差、独立单调链凸包，
再用行列式/垂足分段公式计算点到闭边距离与标签，不调用生产几何原语或生产证书。
生产证书不用凸包，它以支撑顶点列出所有差体边；二者共享的只有精确有理数算术。
具名测试在 `tests/test_m5d_exit_certificate.py`，包含阈值边缘、非刚体扰动、全部竞争边、
内部性、凸性/法向序、精确输入与刚体/单位协变，变异通过真正修改生产函数体执行。
