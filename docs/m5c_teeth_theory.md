# M5c A1–A4：证书语义补牙的先行论证

本文件先于测试实现写入。只补既有 R1/R2 的逻辑门，不扩大充分条件，不修改生产几何原语。

## 独立 oracle 与边界

独立模块 `tests/m5c_teeth_oracle.py` 只导入 `fractions.Fraction`。平移多边形的每个顶点—边事件满足
`cross(edge, vertex-edge_start + s*(va-vb))=0`，因此可用一次方程精确枚举；只保留时间窗内、投影落在闭边上的事件。
输入由构造保证初态分离，最早事件就是首接触。oracle 不调用生产坐标、区间、事件、凸性、重叠或求根代码。
非线性早期回返例由唯一最高顶点的线性 y 首次到达障碍底边，精确计算初触时刻；再独立代入 x 多项式验证严格位于该闭边内部，无需生产非线性求根。

## 必要逻辑与可证伪输入

1. **早期窗必须完整**：细菱形（原菱形 x 缩小十倍）共同平移 `x(s)-1=400(s-.4)(s-.5)(s-.6)`、`y(s)=20s-11`。
   在 `17/40` 以前全部顶点严格低于 y=-2；该时刻唯一最高顶点 3 在 `(33/32,-2)` 首次碰到 B 底边 0。
   之后退出，再在 `[.59,.61]` 由右顶点 2 横截 B 左边 3。跳过早期窗或只查前半窗会**真的签错首盖标签**，不只是错括区。
2. **EV 不可省略**：A 三角形 `(-2,-10),(0,0),(-2,10)` 以 `(4,0)` 平移，B 为 `(1,1),(3,-1),(3,3)`。
   EV 在 `3/10` 首入；被提名 VE 在 `1/2` 才发生。只查 VE 会把真正错误的首盖签出。
3. **边内两侧投影均必需**：菱形从障碍边的上方或下方穿过其支撑线，线根存在但闭边接触不存在。
   漏任一侧投影会把延长线根当成接触。
4. **最后一段不可漏**：三角形尖端在 `.599` 穿过墙延长线，但在 `.597` 已越过上端点；最后一段以前投影为正。
   漏末段会认证实际上不存在的首接触。
5. **r2 不能漏**：端点向 y 偏移 1、名义 P2 静止；另一三角形在 x 方向距 1。两条名义路径无接触，
   但半径为 1 的管有触点见证。删 r2 则错误签发整个管无接触。
6. **L∞ 管的对偶范数是 L1**：对角分离的两个三角形，支撑法向 `(1,1)`；归一化用 L∞ 会把间隙夸大两倍。
7. **P1/P2 必须各查**：长薄三角形的有理转动端点尖端均为 x=10，中点尖端为 `16030/1601>10.012`；
   端点弦扫掠盒看不到该弧形凸出。位于凸出处的小矩形被 P2 接触而被 P1 避开。

## 误差项与严格性

双线性误差的三个项 `du*||W||1 + dw*||U||1 + 2*du*dw` 分别来自
`β(ΔU,W)`、`β(U,ΔW)`、`β(ΔU,ΔW)`；W 与 V 两套各自检查，不以产物哈希作证。
凸性三项为 `2r||U||1 + 2r||V||1 + 8r²`。矩形 `10×6`、r=1 的最小差恰好为零，
因此给出严格判据等号与逐项删减的独立拒绝门。该充分界可以保守；等号拒绝并不声称形状必然失凸。
竞争事件余量恰为零也必须拒绝；这是证书的严格排除契约，不等价于声称每个零余量例都有错误首盖。

近阈值接受门采用放大菱形、静止墙、仅 A 半径 `199999/1000000`，端点事件余量相对误差约 `5×10^-6`；
同时独立平移 oracle 核对生产证书的标签和括区。旋转、平移、单位门继承 M5b，并新增对角归一化尺度/大平移门。

## 变异隔离

所有变异均由 `tests/mutation_support.py` 读取真实函数体、唯一锚点替换、在副本全局命名空间编译。
新门只执行语义测试，不调用摘要/来源哈希检查；每个变异要求在指定语义断言上失败，错误信息必须匹配。
此为真实内部变异，不在生产输出后追加假数据。事件删项门检验生产预算契约，结构门检验真实错误证书。
