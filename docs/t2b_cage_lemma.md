## 1. 对象与定义

**移动体。** A0 是起始位姿下的闭多边形实体（有理顶点、简单环、全维）。转动中心 c 为有理点。体坐标 A = A0 − c。位姿 (θ, t) ∈ S¹ × R² 下移动体占据

```text
X(θ, t) = R_θ A + c + t.
```

起始位姿 q0 = (0, 0)。平移坐标 t 是相对起始位置的位移，与 T1b 的平移证书口径相同。

**障碍。** O_1, …, O_m 为固定的闭多边形实体（有理顶点、简单环、全维），可以互相接触。

**自由集与贯入集。** 接触允许：

```text
F = {(θ, t) : 对每个 j，int X(θ, t) ∩ int O_j = ∅},     P = (S¹ × R²) \ F.
```

固定转角切片记作 F_θ、P_θ ⊆ R²。P_θ 为开集，F_θ 为闭集。

**刚体困住。** 若 F 中含 q0 的连通分量 C 在 t 方向有界，称起始位姿 SE(2) 困住。该性质与转动中心 c 的选取无关：换成 c' 时，R_θ(A0 − c) + c + t = R_θ(A0 − c') + c' + t'，其中 t' = t + (R_θ − I)(c' − c)；映射 (θ, t) ↦ (θ, t') 是保持 θ、把 q0 映到 q0、平移部分只差有界量的同胚，两种参数化下的自由集一一对应。因此 c 可以由证书给出。存在逃逸证书（WO-T2a 的 C-E）时，C 含一条通向无穷的路径，因此逃逸证书与笼证书不可能在同一输入上同时成立。

**转角参数与图。** Cayley 转动 R(u) = [[1−u², −2u], [2u, 1−u²]]/(1+u²)，θ(u) = 2 arctan u。全圆用提升参数 λ ∈ R 表示，周期为 4，分两张图：

```text
图 0：λ = 4k + u，        u ∈ [−1, 1]，R_λ = R(u)，    θ = 2πk + θ(u) ∈ 2πk + [−π/2, π/2]
图 2：λ = 4k + 2 + u，    u ∈ [−1, 1]，R_λ = −R(u)，   θ = 2πk + π + θ(u)
```

每次计算 R_λ 都必须在所用图内得到 u ∈ [−1, 1]，否则拒收。两图在 λ ≡ 1 与 λ ≡ 3 (mod 4) 处重合，并给出同一有理矩阵（R(1) = J = −R(−1)，R(−1) = −J = −R(1)，J = [[0, −1], [1, 0]]）。θ 是 λ 的严格增函数，λ 增加 4 恰好转一整圈。有理 λ 给出精确有理转动矩阵。

**区间的图坐标。** 区间 [λ^−, λ^+] 的图由中点 λ_m = (λ^− + λ^+)/2 决定：取整数 k 使 λ_m − 4k ∈ (−1, 3]；若 λ_m − 4k ∈ (−1, 1] 用图 0，否则用图 2。两个端点用**同一个** k 与同一张图换算成图坐标 u^−、u^+，必须满足 −1 ≤ u^− < u^+ ≤ 1（于是 u^+ − u^− = λ^+ − λ^−，区间不跨图边界）。区间中心取 u_c = (u^− + u^+)/2，对应提升值 λ_c = λ_m，R_c = R_{λ_c}。由 |u_c| < 1 知对 |u| ≤ 1 有 1 + u·u_c > 0。

**凸片与严格贯入片。** 对严格凸多边形 X、Y（定义见 §2.0），

```text
M(X, Y) = {t : int(X + t) ∩ int Y ≠ ∅}.
```

由分离轴定理，t ∈ M(X, Y) 当且仅当在 X、Y 的每条边法向 n 上，两者投影区间严格重叠：max_{x∈X} n·(x+t) > min_{y∈Y} n·y 且 max_{y∈Y} n·y > min_{x∈X} n·(x+t)。每个条件对 t 是开的仿射不等式，所以 M(X, Y) 是开凸集。若有限个点都在 M(X, Y) 中，它们的凸包也在其中。该刻画只对凸多边形成立，且要求每条法向非零；§2.0 的检查保证这两点。

## 2. 证书数据

一份笼证书由以下数据组成。核验器只信任这些数据加上本节与 §3 的检查，其余一律重算。

### 2.0 环的检查（V0 的一部分，对每个环都做）

- **严格凸环**：顶点表 (v_0, …, v_{k−1})，k ≥ 3，顶点两两不同；对每条边 (v_i, v_{i+1})（下标模 k），其余每个顶点都**严格**在其左侧：cross(v_{i+1} − v_i, v_j − v_i) > 0。满足者是逆时针、正面积、无共线三点、无零长边的凸多边形，边界恰绕一圈。移动体片、障碍片、转动收缩片 E、不变圆多边形 D 都必须是严格凸环。
- **简单环**：k ≥ 3，顶点两两不同；不相邻的两条边不相交，相邻两条边只交于公共顶点；有向面积为正。移动体 A0 与每个障碍 O_j 都必须是简单环。
- **闭合折线**：顶点表 (g_0, …, g_m)，m ≥ 1，且 g_m = g_0 逐坐标相等；段为 [g_s, g_{s+1}]（s = 0…m−1），不得隐式补首尾边。Γ_n、连接链与封口链中的**每一条**折线都必须是闭合折线。允许零长段与重复顶点。**常值折线**是全部顶点相同的闭合折线。
- 任何分离轴检查中出现零向量即拒收（V0），零向量不得作为分离轴。

### 2.1 数据项

1. **划分。** 移动体 A0 的划分 {A0_i}、每个障碍 O_j 的划分 {O_{j,l}}，每片为严格凸环。移动体与**每一个**障碍都至少有一片，每片的母体下标在范围内。核验：每片含于其母多边形（§4.1 引理 0 的判据），同一母多边形的片两两内部不交（存在非零的弱分离轴），片面积之和精确等于母多边形面积。由此各片之并等于母多边形（§4.1）。
2. **半径。** 有理数 r > 0，满足 r² ≥ |v − c|² 对所有 A0_i 的顶点 v。
3. **转角链。** 严格递增的有理提升断点 λ_0 < λ_1 < … < λ_N（N ≥ 1），以及类型：
   - **闭链**：λ_N − λ_0 = 4；
   - **封口链**：λ_N − λ_0 < 4，两端 λ_0、λ_N 各带一个封口。

   每个区间 I_n = [λ_{n−1}, λ_n] 都必须按 §1 的规则得到合法图坐标。**起始区间** n0：必须存在整数 k 使 λ_{n0−1} ≤ 4k ≤ λ_{n0}（两种链都要查）；封口链另须 λ_0 < 4k < λ_N，即起始转角严格落在覆盖弧内部。
4. **区间内核。** 每个区间 I_n 给出有理收缩量 ρ_n ≥ 0 和至少一个内核片，每片是以下两种之一：
   - **转动收缩片** (i, E)：引用移动体片 A0_i，给出严格凸环 E（转动后体坐标）；
   - **不变圆片**：引用第 5 项的 D。
5. **不变圆。** 可选。有理半径 r_D > 0、宿主片下标 i_D、严格凸环 D（体坐标）。
6. **屏障折线。** 每个区间 I_n 一条闭合折线 Γ_n（§2.0），并给出每段的见证（本区间内核片下标，障碍片下标）；见证表长度必须恰等于段数 m。
7. **连接。** 需要连接的断点是 λ_n（1 ≤ n ≤ N − 1），闭链另加首尾相接处（记 n = N，连接 Γ_N 与 Γ_1）。每个需要连接的断点**恰有一项**连接，给出同转角连接链 H^0, H^1, …, H^q（q ≥ 1）：H^0 与左侧折线（Γ_n）逐顶点相同，H^q 与右侧折线（Γ_{n+1}，首尾相接处为 Γ_1）逐顶点相同；每条 H^j 都是闭合折线，相邻两条折线顶点数相同（允许重复顶点），因此同一条链中所有折线顶点数相同。必须给出见证：恰有 q 组，第 j 组恰有 m 项（m 为 H^j 的段数）。连接项的 at 取值集合必须恰为 {1, …, N−1}（闭链再加 N），不得重复或多出。
8. **封口。** 封口链**恰有两项**封口：at = 0 的连接链首条与 Γ_1 逐顶点相同，at = N 的首条与 Γ_N 逐顶点相同；两者末条都是常值折线；链中每条折线都闭合，相邻两条顶点数相同；见证规则同连接。封口项的 at 取值必须恰为 {0, N} 各一次。闭链不得有封口项。

## 3. 核验条件

记号：区间 I_n 的图坐标 u^−、u^+、中心 u_c 与 R_c 按 §1 计算。

**(V1) 收缩界。** 要求 ρ_n ≥ 0（半径 r 的两条要求 r > 0 与 r² ≥ |v − c|² 已在 V0 检查，本条依赖它们）。区间含转动收缩片时还要求

```text
ρ_n² ≥ 4 r² · S_n，   S_n = max_{u ∈ {u^−, u^+}} (u − u_c)² / ((1 + u²)(1 + u_c²)).
```

区间只含不变圆片时 ρ_n 不参与任何包含关系，只查 ρ_n ≥ 0。

**(V2) 转动收缩片。** 对片 (i, E)：把 A0_i 化为体坐标并转到 R_c A_i，取其每条边的外法向半平面 n·y ≤ b（n 不必单位化，非零）。E 的每个顶点 y 都满足

```text
b − n·y ≥ 0   且   (b − n·y)² ≥ ρ_n² |n|²，
```

即 y 到每条边所在直线的内侧距离不小于 ρ_n。

**(V3) 不变圆。** 宿主片 A_{i_D}（体坐标）的每个边半平面 n·y ≤ b 满足 b ≥ 0 且 b² ≥ r_D² |n|²；D 的每个顶点满足 |y|² ≤ r_D²。

**(V4) 屏障。** Γ_n 的每段 [g_s, g_{s+1}] 有一对（本区间的内核片 K，障碍片 O_{j,l}）使两端点都严格属于 M(K + c, O_{j,l})。

**(V5) 连接与封口。** 断点 λ* 处允许的凸片：
- 精确转动片 R_{λ*} A_i + c（`exact`）。内部断点 λ_n 用 I_n 或 I_{n+1} 的图计算（公共端点两图给出同一矩阵）；首尾相接处取 λ* = λ_N、用 I_N 的图（等价于 λ_0 与 I_1 的图）；封口 at = 0 用 λ_0 与 I_1 的图，at = N 用 λ_N 与 I_N 的图；
- 不变圆片 D + c（`disk`）；
- 内部断点与首尾相接处：左区间（`left`）与右区间（`right`）的内核片 K + c；首尾相接处左区间为 I_N、右区间为 I_1；
- 封口 at = 0：只允许 `right`（I_1）、`exact`、`disk`；封口 at = N：只允许 `left`（I_N）、`exact`、`disk`。用到其余引用即拒收。

连接链或封口链中每对相邻折线 H、H' 的每个四边形 (h_s, h_{s+1}, h'_{s+1}, h'_s) 的四个顶点都严格属于同一个 M(·, O_{j,l})，其中 · 是上列某个允许的凸片。

**(V6) 起点。** 起始位姿自由：每个移动体片 A0_i 与每个障碍片 O_{j,l} 内部不交（存在非零的弱分离轴）。Γ_{n0} 不经过原点，且关于原点的绕数非零。绕数按带符号的半开穿越计数：对每段 [a, b]，若 a_y ≤ 0 < b_y 且原点在其左侧记 +1，若 b_y ≤ 0 < a_y 且原点在其右侧记 −1；零长段贡献 0；只计列出的段。

## 4. 引理与定理

### 4.1 划分与片含于母体

**引理 0。** 设 C 为严格凸多边形，S 为简单多边形。若 C 的某个内点严格位于 S 内部，且 S 的每条边与 int C 不交，则 C ⊆ S。

证明：int C 连通且不与 ∂S 相交，所以 int C 整体在 int S 中或整体在 S 外；给定的内点决定前者。C 是 int C 的闭包，S 是闭集，故 C ⊆ S。∎

实现：内点取 C 顶点的有理平均（严格凸环的顶点平均在 int C 中），用精确射线穿越判定它严格在 S 内部（不在 ∂S 上）；"边与 int C 不交"用线段与 C 的弱分离检查（候选轴为 C 的各边法向与该线段法向，均非零）。

**划分推论。** 若各片含于 S、两两内部不交、面积和等于 S 的面积，则各片之并 U 等于 S。证明：U 闭且 U ⊆ S。若 S \ U 非空，它在 S 中相对开；S 是其内部的闭包，故 S \ U 含 int S 的一个非空开子集，面积为正，与面积和相等矛盾。∎

于是"移动体与障碍内部相交"当且仅当"某一对片内部相交"。必要性：int A0 ∩ int O_j 为非空开集，面积为正，被有限个 A0_i ∩ O_{j,l} 覆盖，必有一对交集面积为正，凸集交集面积为正时内部相交。充分性显然。(V6) 因此等价于 q0 ∈ F。

### 4.2 内核引理

**引理 1（转动收缩）。** 若 (V1)(V2) 成立，则对每个 λ ∈ I_n 有 E ⊆ R_λ A_i ⊆ R_λ A。

证明：区间只含不变圆片时无须证明。否则取 y ∈ E。由 (V2)，以 y 为心、ρ_n 为半径的闭圆盘含于 R_c A_i；又 E ⊆ R_c A_i 且转动保长，所以 |y| ≤ r（用到 r > 0 与 r² ≥ |v − c|²）。令 z = R_c R_λ^{-1} y。两图中都有 R_c R_λ^{-1} = R(u_c) R(u)^T（图 2 的两个负号相消），这是绕原点转过 φ 的转动，tan(φ/2) = (u_c − u)/(1 + u·u_c)（|u_c| < 1 保证分母为正）。于是

```text
|z − y|² = 4 |y|² sin²(φ/2) = 4 |y|² (u − u_c)² / ((1 + u²)(1 + u_c²)).
```

函数 g(u) = (u − u_c)/√(1 + u²) 的导数为 (1 + u·u_c)/(1 + u²)^{3/2} > 0，所以 |g| 在区间端点取最大，|z − y|² ≤ 4 r² S_n ≤ ρ_n²。故 z 落在以 y 为心、ρ_n 为半径的圆盘内，z ∈ R_c A_i，从而 y = R_λ R_c^{-1} z ∈ R_λ A_i。∎

**引理 2（不变圆）。** 若 (V3) 成立，则对一切 θ 有 D ⊆ R_θ A。

证明：(V3) 前半给出圆盘 {|y| ≤ r_D} ⊆ A_{i_D}，后半与 D 的凸性给出 D ⊆ 圆盘。圆盘绕原点转动不变，故 D ⊆ R_θ A_{i_D} ⊆ R_θ A。∎

### 4.3 屏障与连接引理

**引理 3（屏障）。** 若 (V4) 成立，则对每个 λ ∈ I_n 有 Γ_n ⊆ P_{θ(λ)}。

证明：每段落在开凸集 M(K + c, O_{j,l}) 中。由引理 1、2，K ⊆ R_λ A，所以 int(K + c + t) ⊆ int X(θ, t)，M(K + c, O_{j,l}) ⊆ P_θ。∎

**引理 4（连接）。** 若 (V5) 在断点 λ* 成立，则对每个 t ∈ F_{θ*}，左右两侧折线关于 t 的绕数相等。封口处则对每个 t ∈ F_{θ*} 有 wind(Γ, t) = 0。

证明：对每对相邻折线，取同伦 H_σ = (1−σ)H + σH'（σ ∈ [0, 1]，按同一顶点参数分段线性）。因 h_0 = h_m、h'_0 = h'_m，每个 H_σ 都是闭合折线，绕数有定义。第 s 段在任一 σ 下的每一点都是四个顶点的凸组合，落在它们的凸包中（四边形非凸或自交时同样成立），后者含于某个 M(·, O_{j,l})。允许的凸片都含于 R_{λ*} A：精确转动片显然；两侧内核片由引理 1 在端点 λ* 处成立；D 由引理 2。所以整个同伦像含于 P_{θ*}，不经过任何 t ∈ F_{θ*}，绕数不变。常值折线 p ∈ P_{θ*}，对 t ≠ p 绕数为 0。封口 at = 0 处没有左区间；封口链 λ_N − λ_0 < 4，λ_0 不属于 I_N（模 4 也不属于），I_N 的内核片在 λ_0 处没有包含关系，所以不得借首尾相接使用。at = N 同理。∎

### 4.4 笼定理

**定理。** 若 V0～V6 与 CHAIN 全部成立，则 F 中含 q0 的连通分量 C 满足：

- C 的转角投影落在链覆盖的弧内；封口链时落在开弧 (θ(λ_0), θ(λ_N)) 内；
- C 的平移投影含于 ∪_n {t : wind(Γ_n, t) ≠ 0}，因而有界。

所以 q0 SE(2) 困住。

证明：在 F_A = F ∩ (覆盖弧 × R²) 上定义 w(θ, t) = wind(Γ_n, t)，其中 θ ∈ I_n。由引理 3，t ∉ Γ_n，w 有定义。断点处两种取法由引理 4 一致；连接链首尾与两侧折线逐顶点相同，保证引理 4 连接的正是 Γ_n 与 Γ_{n+1}。

w 在 F_A 上局部常值。若 θ 在 I_n 内部，Γ_n 紧且不含 t，绕数在 t 的一个邻域内不变，邻近的 F_A 点仍属 I_n。若 θ 是断点，两侧折线都不含 t，各自在 t 的邻域内不变，且在 t 处相等，故在邻近点也相等。封口角处 w ≡ 0。

令 S = {p ∈ C : θ(p) 在开覆盖弧内且 w(p) = w(q0)}。起始区间含转角 0 且 Γ_{n0} 关于原点绕数非零，所以 q0 ∈ S，w(q0) ≠ 0。若 0 恰为断点，两侧取法一致，不影响结论。S 在 C 中开，因为开弧是开集且 w 局部常值。S 在 C 中也闭：设 p ∈ C 是 S 中点的极限，θ(p) 落在闭弧中。若 θ(p) 是封口角，则 w(p) = 0，而 w 在 p 附近的 F_A 点上常值，S 中靠近 p 的点 w = w(q0) ≠ 0，矛盾。所以 θ(p) 在开弧内，由局部常值得 w(p) = w(q0)，p ∈ S。C 连通，所以 S = C。闭链时没有封口角，同样的论证直接给出 S = C。

于是 C 中每点的 t 都满足 wind(Γ_n, t) = w(q0) ≠ 0。绕数非零的点落在 Γ_n 的有界补分量中，有限条折线的并有界。∎

**推论。**
- 记 δ*_SE2 = sup{δ : 起始位姿在 δ 下 SE(2) 困住}。设移动体与障碍都按 δ 腐蚀嵌套、平移 t 对各 δ 都从同一起始摆放量起、转动中心 c 不随 δ 变，且 δ = 0 时起始位姿自由（T1b 各例成立）。若笼证书在 δ 成立，则对一切 0 ≤ δ' < δ 也 SE(2) 困住：F(δ') ⊆ F(δ)，F(δ') 中含 q0 的分量是 F(δ) 中含 q0 的连通子集，落在有界的 C(δ) 内。于是 δ*_SE2 ≥ δ。
- 笼证书在 δ 成立蕴含 T1b 意义下平移困住（取 θ ≡ 0 的子集）。
- 同一输入上笼证书与逃逸证书不可能同时成立。

## 5. 真值例（闭式，门用）

1. **门洞**（WO-T2a 真值库 `doorway(δ)`）。移动矩形 [−3/2+δ, 3/2−δ] × [δ, 1−δ]，转动中心 c = (0, 1/2)（矩形中心），门宽 3/4、门深 1。内切圆直径 1−2δ。δ < 1/8 时圆盘无法通过门：圆心须穿过门的中线 y = 13/2，此时 |x| ≤ 3/8 − (1−2δ)/2 < 0。所以 δ < 1/8 SE(2) 困住；δ ≥ 1/8 由 WO-T2a 的逃逸证书可逃。δ*_SE2 = 1/8，不取到。δ = 1/8 − 2^-10 时取 r_D = 3/8 + 2^-10（等于矩形半高，V3 取等号）、D 为顶点 (±r_D, 0)、(0, ±r_D) 的菱形；D 的水平宽度 2r_D > 3/4，平移困住，只需不变圆片。
2. **风车**（`windmill()`）。移动体为正方形 [−1, 1]²，c = (0, 0)，内切圆半径 1。相邻楔块最近距离为 √10/2 < 2，各楔块按半径 1 外扩后首尾相连，圆盘被困，正方形 SE(2) 困住。D 取半径 1 的圆内接有理多边形（顶点用勾股有理点）。真正的要求是相邻两个严格贯入片 M(D + c, W_k) 相交，才能把折线连成圈；对大致均匀的中心对称 D，这近似于 D 过中心沿间隙方向的弦长大于间隙 √10/2。只看"间隙方向的宽度"不够：顶点 (±1, 0)、(0, ±1) 的菱形宽度 1.897 > 1.581，却连不成圈。由 (1, 0)、(12/13, 5/13)、(4/5, 3/5)、(3/5, 4/5)、(5/13, 12/13) 及其四分之一转得到的 20 边形可行。
3. **中点楔**（`midpoint_wedges()`）。移动体为正方形 [−1, 1]²，c = (0, 0)。相邻楔尖 (1, 0)、(0, 1) 距离 √2 < 2，同理困住；例 2 的 20 边形 D 同样可行。
4. **菱形与四板**（`diamond_plates()`）。移动体为菱形 |x| + |y| ≤ 1，c = (0, 0)，可以原地自由转动，内切圆半径 1/√2。相邻板角 (1, 1/4)、(1/4, 1) 距离 3√2/4 ≈ 1.061。取 r_D = 7/10 ≤ 1/√2（V3：1 ≥ 0.98）。D 必须在对角方向足够宽：顶点 (±7/10, 0)、(0, ±7/10) 的菱形对角宽度约 0.99，不足 1.061，证不出；取轴对齐正方形 [−49/100, 49/100]²（顶点半径约 0.693）或 8 边以上、大致均匀的圆内接有理多边形即可。
5. **低房间与长烟囱**（需要分段与封口）。移动体为矩形 [−3/2, 3/2] × [−1/2, 1/2]，c = (0, 0)，r = 8/5。房间内腔 x ∈ [−8/5, 8/5]、y ∈ [−3/5, 3/5]；地板、左右墙厚 1；顶板厚 4，中间开竖直烟囱 |x| < 11/20（宽 11/10）。精确实例：rect(x0, y0, x1, y1) 表示从 (x0, y0) 起逆时针的四顶点环 (x0, y0)、(x1, y0)、(x1, y1)、(x0, y1)（同 `tests/t2a_truth_geometry.py` 的 `rectangle`）；移动体 rect(−3/2, −1/2, 3/2, 1/2)；障碍依次为地板 rect(−13/5, −8/5, 13/5, −3/5)、左墙 rect(−13/5, −3/5, −8/5, 3/5)、右墙 rect(8/5, −3/5, 13/5, 3/5)、左顶板 rect(−13/5, 3/5, −11/20, 23/5)、右顶板 rect(11/20, 3/5, 13/5, 23/5)。
   - **困住论证。** 块的内切圆直径 1 < 11/10，不变圆证不出。记 θ_w = arcsin(10/11) ≈ 65.38°。块绕自身中心的外接圆半径 √10/2 ≈ 1.581。
     - 逃出必经烟囱：墙、地板、顶板围合，块中心只能在内腔与烟囱内移动，最终越过烟囱顶 y = 23/5。因此存在首个时刻 T1，块中心到达烟囱中段 y = 13/5。此时整块落在 y ∈ (3/5, 23/5) 的烟囱带内，水平宽度 3|cos θ| + |sin θ| ≤ 11/10，即 θ mod π 与 π/2 相差不超过约 1.92°。
     - T1 之前转角被卡在小角度：设某时刻 θ ∈ (θ_max, θ_w)（θ_max ≈ 6.2°）。此时块的最宽水平弦大于 11/10，不能在烟囱带内；又因中心低于 13/5、外接圆半径 1.581，该弦低于烟囱顶，所以落在内腔中（y ≤ 3/5）。块伸到 y = 3/5 以上的部分是顶角楔，在 y = 3/5 处弦长不超过 11/10，深度至多 (11/10) sin θ cos θ（楔形弦长 = 深度/(sin θ cos θ)，θ < θ_w 时此深度未越过下一顶点）。块的竖直跨度 3 sin θ + cos θ 因而不超过 6/5 + (11/10) sin θ cos θ，而这只在 θ ≤ θ_max 时成立，矛盾。θ = θ_w 时最宽弦恰为 11/10，由连续性归入同一结论。
     - 从 θ = 0 连续出发，要接近竖直必先经过 (θ_max, θ_w)，所以 T1 之前 |θ| ≤ θ_max，与 T1 时须接近竖直矛盾。负转角与 θ 加 π 的情况对称。故块 SE(2) 困住。
     - 手推的 6.2° 只是上界。非作者审查的切片扫描表明，含起点分量的实际转角范围约为 |θ| ≤ 3.87°，仅由内腔高度决定（3 sin θ + cos θ ≤ 6/5）。块中心在结构内部（低于烟囱顶）时，(3.87°, 86.18°) 内任何转角都没有自由位姿；结构外部在任何转角都有自由位姿，它们属于外部分量。
   - **证书要求。** 小转角处 Γ 跨过烟囱口，接近竖直时同一 Γ 失效，所以必须分段并封口。封口角可取 (3.87°, 86.18°) 内任意值。
   - **对照例。** 内腔高改为 y ∈ [−2, 2]，其余不变。精确实例：移动体同上；障碍依次为 rect(−13/5, −3, 13/5, −2)、rect(−13/5, −2, −8/5, 2)、rect(8/5, −2, 13/5, 2)、rect(−13/5, 2, −11/20, 6)、rect(11/20, 2, 13/5, 6)。块的外接圆半径 √10/2 < 8/5 且 < 2，块可原地转到竖直，再沿烟囱上升逃出。逃逸证书须成立，笼证书须证不出。
   - 若生产管线找到低房间的逃逸路径，说明本论证有错，按发现上报，不得改例迁就。

## 7. 证书 JSON 格式（两个核验器共用，`eab.t2b.cage/1`）

**核验入口是 (实例, 证书)。** 实例是调用方从几何生成器独立得到的 `{"moving": simple_ring, "obstacles": [simple_ring, ...]}`；证书中的 `moving` 与 `obstacles` 必须与实例逐顶点、逐项精确相同（顶点顺序与起点也相同），否则 V0。证书不得自带实例几何而绕过这一步。

**下标。** 数组下标（`obstacle` j、`piece` i、`host`、`exact` 的 i、见证中的 k 与 l）一律从 0 起算，必须是非负整数（布尔值不算整数）；除 `left`/`right` 的 k 外都在 V0 查范围，`left`/`right` 的 k 的范围与侧别一起在 V5 检查；`start_interval` n0 与 `at` 是引理中的数学下标（n0 ∈ 1…N，`at` ∈ 0…N）。越界或类型不符归 V0。

**JSON 卫生。** 格式中列出的键全部必须出现（允许为 null 的写 null，不得省略）；拒收重复键、未知键、NaN/Infinity、非字符串的有理数；每个有理数字符串解码后长度不超过 4096 个字符。整数（下标、n0、`at`）必须是 JSON 整数记号且匹配 `0|[1-9][0-9]*`（不接受 `1.0`、`1e0`、`-0` 与布尔值）；实现须在解析层检查原始记号。

有理数一律写成字符串（`"3/8"`、`"-2"`），文法为 `-?(0|[1-9][0-9]*)(/[1-9][0-9]*)?`（仅 ASCII 数字），分数须为既约且分母 ≥ 2，不得写 `-0`；点为 `[x, y]`；环为逆时针顶点表，不重复首点；折线显式闭合（末点等于首点）。坐标系：`moving`、`obstacles`、`moving_pieces`、`obstacle_pieces` 为世界坐标（起始位姿）；内核片与 `disk.polygon` 为"转动后体坐标"（原点在转动中心 c，朝向为世界朝向），世界位置为 `polygon + c + t`；折线顶点是平移 t。`simple_ring` 与 `convex_ring` 按 §2.0 检查。

```text
{
  "format": "eab.t2b.cage/1",
  "moving": simple_ring,                   // A0
  "obstacles": [simple_ring, ...],         // O_j
  "center": point,                         // c
  "radius": rational,                      // r > 0
  "moving_pieces": [convex_ring, ...],     // A0_i
  "obstacle_pieces": [{"obstacle": j, "ring": convex_ring}, ...],   // O_{j,l}，l 为本表下标
  "disk": null | {"radius": rational, "host": i, "polygon": convex_ring},
  "chain": {"kind": "closed" | "capped", "breakpoints": [rational, ...]},   // λ_0 < … < λ_N，N ≥ 1
  "start_interval": n0,                    // 1 ≤ n0 ≤ N
  "intervals": [                           // 恰 N 项，第 n 项对应 I_n = [λ_{n-1}, λ_n]
    {"rho": rational,                      // ρ_n ≥ 0
     "pieces": [{"kind": "rotated", "piece": i, "polygon": convex_ring} | {"kind": "disk"}, ...],   // 至少一项
     "loop": closed_polyline,
     "witnesses": [[k, l], ...]}           // 每段一项：本区间 pieces 下标 k、obstacle_pieces 下标 l
  ],
  "links": [                               // 每个需要连接的断点恰一项：1 ≤ at ≤ N−1；闭链另有 at = N（λ_N 与 λ_0 相接）
    {"at": n, "chain": [closed_polyline, ...],      // 至少两条；首条 = Γ_n，末条 = Γ_{n+1}（at = N 时末条 = Γ_1），逐顶点相同
     "witnesses": [[[ref, l], ...], ...]}           // 每对相邻折线一项，其中每个四边形一项
  ],
  "caps": [                                // 封口链恰两项（at = 0 与 at = N），闭链为空表
    {"at": 0 | N, "chain": [closed_polyline, ..., constant_polyline], "witnesses": 同上}
  ]
}
```

连接与封口见证中的 `ref` 取 `["exact", i]`（断点处精确转动片 R_{λ*}(A0_i − c)）、`["left", k]`、`["right", k]`（断点左、右区间的第 k 个内核片）或 `["disk"]`，侧别限制见 V5。见证必须给出，核验器只检查给出的见证、不自行搜索；见证不成立即拒收。

**给证明者的提示。** 同一条连接或封口链中所有折线顶点数相同，需要时用重复顶点补齐；区间内部不得含 λ ≡ 1 或 3，所以闭链至少要在这两处设断点，即使只用不变圆片也要 N ≥ 2 并给出相应的连接。

拒收必须给出首个不满足的条件编号。检查顺序固定为 V0 → CHAIN → V1 → V2 → V3 → V4 → V5 → V6，同一条件内按 JSON 中出现的先后。各数据项归属：

- `V0`：JSON 卫生、类型、整数记号与有理数文法；固定取值的字符串（`format` 必须为 `eab.t2b.cage/1`，`chain.kind`、内核片 `kind`、见证引用标签 `exact`/`left`/`right`/`disk`）取值不符；`start_interval` 不在 1…N；证书几何与实例不符；下标越界（`left`/`right` 的 k 除外）；r > 0 与 r² ≥ |v − c|²（对所有 A0_i 的顶点）；`intervals` 恰 N 项；每个区间至少一个内核片；每条连接与封口链至少两条折线；`disk` 非 null 时 r_D > 0（V3 在 `disk` 非 null 时总要检查，不论是否被引用）；环的检查（§2.0，含每条折线闭合、m ≥ 1）；连接与封口链中相邻折线顶点数相同；划分（每个母体至少一片、含于、两两内部不交、面积和）；零向量轴；`disk` 为 null 却被引用；见证表长度不符。
- `CHAIN`：断点严格递增且 N ≥ 1；每个区间的图坐标合法；闭链总长恰为 4，封口链总长小于 4；起始区间规则；连接项与封口项的 `at` 取值集合；首末折线逐顶点相同；封口末条为常值折线；闭链不得有封口项。
- `V1`～`V6`：§3 各条；ρ_n < 0 归 V1；R_λ 求值时 u 越出 [−1, 1] 归所在条件；封口与连接的引用侧别归 V5。
