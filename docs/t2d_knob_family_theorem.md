## 1. 对象

**凸耳族。** `tolerance_knob(segments=N, head_width=2, neck_width=1, height=2, wall=2)`，N ∈ {4, 8, 16, 32}，墙不腐蚀（e = 0），转动中心 c = (0, 1)。截颈点：N = 4 为 (1/2, 11/6)，N = 8 为 (1/2, 37/20)，N = 16 为 (1/2, 67/36)，N = 32 为 (1/2, 567/304)；记截颈高度 y_N。

**未截颈弦多边形 Q_N。** 全部采样点 (cos α, 1 + sin α)（α = 2 arctan u）及其镜像的凸包。采样集在 y ↦ 2 − y 与 x ↦ −x 下都不变，所以 Q_N 关于 c 中心对称；每个采样点都是 Q_N 的顶点。Q_N 在截颈高度以上的部分含于颈矩形，所以 Q_N ⊆ A_N，A_N 的凹顶点在 ∂Q_N 上。（N ≥ 8 时 conv(A_N) \ A_N 不是单个三角形，凸包会跳过若干弧上顶点；精确腐蚀须按扇形三角化处理。）

**容差元。** 方形 [−1,1]²；T1b 有理八边形；K16 = {(±99/101, ±20/101), (±20/101, ±99/101), (±91/109, ±60/109), (±60/109, ±91/109)}（单位圆上的有理点，对 D4 精确对称，h_K16(e_x) = 99/101，max h_K16 = 1）。

**弦的量。** 对 Q_N 的边 e：单位外法向 n̂_e，c 到支撑线的距离 d_e。以 Cayley 参数 u1 < u2 表示右侧的弦时，外法向 m = (1 − u1u2, u1 + u2)，c 到支撑线的距离为 (1 + u1u2)/|m|。

## 2. 结论

### 2.1 困住侧（定理 1，对全部 12 种 (N, K) 成立）

```text
δ_disk(N, K) = min_e (d_e − 1/2) / h_K(n̂_e)。
```

对 δ < δ_disk，起始位姿 SE(2) 困住。证明：凸集含于凸多边形的支撑函数判据给出 B(c, r) + δK ⊆ Q_N 当且仅当对每条边 r + δ h_K(n̂_e) ≤ d_e（只需 K 凸且含原点）；δ < δ_disk 时取 r > 1/2；圆盘绕 c 转动不变；圆盘过不去颈（T2c2 引理 B，把 11/6 换成 y_N，墙在 y_N < y < 2 内占据 |x| > 1/2）。∎

### 2.2 逃出侧（定理 2，充分条件）

记 e* 为取到 δ_disk 的弦对（由中心对称，对边同时取到）。若
- (S) 原移动体 A_N 落在 e* 的闭条带 {|n̂_{e*}·(p − c)| ≤ d_{e*}} 内（K 中心对称时可推出腐蚀体落在半宽 d_{e*} − δ h_K(n̂_{e*}) 的条带内）；
- (C) δ = δ_disk 时移动体离 c 的最远距离小于墙到 c 的最近距离；

则 δ ≥ δ_disk 时可刚体逃出：绕 c 转到 n̂_{e*} 水平，再竖直上移（(C) 使转后移动体落在 B(c, ρ) ⊆ A_N 内；A_N 中 |x| ≤ 1/2 的点上方竖直射线自由）。于是 δ*_SE2 = δ_disk，不取到。

(S) 不是必要条件：它只保证这一条"先转后升"的路径。

### 2.3 平移临界公差（对全部 12 种成立）

```text
δ*_T(N, K) = min over 右侧弦 [u1, u2] of (1 + 3 u1 u2) / (2 h_K(1 − u1 u2, u1 + u2))。
```

理由：长于 1 的水平弦过不去颈；最宽水平弦总在 y = 1 处取到；腐蚀体半宽 ≤ 1/2 时可竖直上移。只看最宽顶点两侧邻弦的形式 1/(2 h_K(1, t_N))（t_N = 2/N）在 12 种中有 9 种成立，在 (16, 方形)、(32, 方形)、(32, 八边形) 三例不成立。

## 3. 转动好处的分解

记 G = 1 − δ*_SE2/δ*_T。

1. **刻面项。** 若 e* 是主弦，比值 = 2 − √(1 + t_N²)，t_N = 2/N，G_facet = √(N² + 4)/N − 1 ≈ 2/N²：N = 4、8、16、32 时约 11.8%、3.1%、0.78%、0.20%。在主弦卡住的 5 种情形中比值精确等于此式。
2. **各向异性项。** 其余情形比值低于刻面式；差值（G − G_facet）在 (16, 八边形) 约 3.49%、(16, K16) 约 0.005%、(32, 八边形) 约 3.55%、(32, K16) 约 0.92%。
3. **圆形极限。** N → ∞ 时 δ_disk → 1/(2 max h_K)；平移临界值 δ_T^∞ 为使 K 的每个角点 k 留在单位圆内的最小 δ，即 √(1 − δ²k_y²) − δk_x = 1/2 的最小根：

| K | δ_T^∞ | 极限比值 | 极限 G |
|---|---|---:|---:|
| 方形 | (√7 − 1)/4 | (√14 + √2)/6 ≈ 0.859312 | ≈ 14.07%（以 δ_disk 为准；方形的 δ*_SE2 尚为猜想） |
| 八边形 | (6√651 − 72)/169 | (√651 + 12)/39 ≈ 0.961915 | ≈ 3.81% |
| K16 | (2√10101 − 99)/202 | (99 + 2√10101)/303 ≈ 0.990124 | ≈ 0.99% |
| 欧氏圆盘 | 1/2 | 1 | 0 |

**含义（待 WO-T2d 核验后才可写进结论）。** 对这一凸耳族，刻面带来的转动好处按 2/N² 消失；细刻面极限下剩下的好处完全来自容差元的各向异性，K 越接近各向同性越小，欧氏圆盘时为零。用方形这类轴对齐容差元研究互锁接头的刚体锁定，会把容差元的各向异性（方形约 14%）当成几何效应。

**N > 32 的注意。** 更细刻面时，e* 可能漂到 (S) 允许的锥（法向角不超过约 36.87°）之外，定理 2 的路径不再适用；极限值本身不受影响（允许的 max-h 方向存在）。
