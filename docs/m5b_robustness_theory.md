# M5b：对指定连续模型扰动管的充分认证

状态：严格充分条件，不是完备分类；未通过统一标 MODEL_SENSITIVE_OR_UNPROVED，
不能将“未证”统计误写成实证模型差异率。这里的扰动不是未知真实物理路径。

## R1 无接触证书

每条顶点坐标为有理函数 N(s)/D(s)，D>0。将时间窗口划为有限闭区间，
使用精确 Bernstein 系数凸包包住投影分子与正分母，再以区间除法包住商。
设某区间上一固定法向 n 的两多边形投影包络有严格间隙 g。
若顶点 L∞ 误差分别≤εA、εB，边的同重心系数点同样满足此界，
投影误差≤||n||1 ε。因此 g/||n||1>εA+εB 保证该整个区间无接触。
所有区间有此证书则整个窗口无接触；轴/法向可逐区间变化。
该值是最小间隙的严格**下界**，不是已求得全局最小距离。

P1 与 P2 分别检验，均须通过；P2 的 ε 包含 P2-P3 全程界与明确规定的
端点舍入线性校正族上界。仅给端点误差不能推出任意未知路径误差。
回放具体取 `b=全窗P2-P3界`，`r2=max|P2(1)-观测末帧|∞`，
`e=最大L1半径×2epsilon_u`（端点只有半角参数误差，无时间律差），
统一收费 `ε=b+r2+e`。因为 P3 自己的闭合残差 `r3<=r2+e`，
这也覆盖 `P3(s)+s(观测末帧-P3(1))`，不只覆盖 P3 或 P2 的闭合族。
零初始校正不能被误写成任意实际物理路径的界。接线门：
`test_p3_own_endpoint_closure_has_separate_parameter_error_budget`。
门：`test_no_contact_requires_strict_margin_and_covers_whole_window`。

## R2 单首盖证书

仅处理严格凸、逆时针简单环以及边内部的单个 VE/EV 首盖。
多盖同时首入、VV、端点接触、凹环不强行认证。候选括区间 [l,h]：

1. [0,l] 按 R1 证明扰动管严格分离。
2. 对整个 [l,h]，每条边的所有非邻顶点严格在左侧，且余量大于误差界；
   因而任意管内连续顶点路径保持严格凸简单环（不只检查相邻转角，避免星形漏洞）。
3. 指定事件 f=cross(U,W)，U=Bk-Bj，W=Ai-Bj。在 l 时严格负、h 时严格正，
   两端余量均大于误差；名义 f' 的有理区间下界严格正。事件投影
   dot(U,W)>0 与 -dot(U,Ai-Bk)>0 在整个括区间对管内扰动保持严格正。
4. 每个竞争 VE/EV 在每个子区间，要么 f 严格非零，要么一个投影严格负，
   且相应余量大于误差；故不可能有任何竞争接触。

**误差证明。** 若顶点误差 L∞≤εA/εB，则 ||ΔU||∞≤2εB=du，
||ΔW||∞≤εA+εB=dw。展开双线性叉积或点积得

`|Δβ(U,W)| ≤ du ||W||1 + dw ||U||1 + 2 du dw`。

区间包络的 L1 上界代入是严格安全的；上投影对 W=Ai-Bk 同理。
凸性条件采用同式 du=dw=2ε。所有判断使用有理数，不加绝对容差。

**首盖证明。** R1 排除 l 之前接触；连续性与两端异号保证 [l,h] 有指定
边内部接触。紧性保证首时刻存在；竞争排除保证任一首接触只能是此顶点—边。
严格凸性和首次不穿透给该事件正确外支承法锥，所以首盖集合恰为指定单标签。
名义路径横截保障非切触候选；扰动后的 f 未假设 C1，因此**不声称扰动后的
导数、唯一根或精确首时刻保持不变**。仅幅值管不能证明那些更强结论。
门：`test_single_cover_certificate_has_independent_closed_form_oracle`、
`test_single_cover_rejects_endpoint_uncertainty_and_competing_tie`。

## Oracle、变异与不变性

主 oracle：菱形右顶点 x=2s+da 与竖墙 x=1+db，首时刻 (1+db-da)/2，
其余顶点严格在墙左；不调用生产几何、求根或区间代码构造期望。
Bernstein 主 oracle 独立展开 Bernstein 基到幂基，精确恒等核对。
import：Fraction、itertools.product、math.comb；pytest 仅设施。
旋转（非轴对齐有理旋转）、大平移、2^-120/2^100 单位缩放含不对称参考系。
内部变异：严格间隙 > 改 >=，两端符号误差反号；红在对应语义断言，未使用哈希绊线。

已贯入时的最短出口及参考边排序，不属于 R1/R2：共享初态只证明三模型
在零扰动初态一致，不能证明正舍入管内最短盖排序不变。未另证余量则保留未证。
