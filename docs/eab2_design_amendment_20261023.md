## 1. 单基隐函数并非分支完备性证明

临界机构或改进射线的基不唯一，退化顶点还可能有多个基。单一基的
`−φ_p/φ_μ` 只是候选分支斜率，不必是全问题阈值的方向导数。
即使一个闭阈射线基在 μ* 可行，若其可行连续区间退化为 `[μ*, μ*]`，
也不能由该基推出邻域内的阈值导数。原语料中对称种子恰使多分支斜率相同，
不能据此证明单基方法适用于非对称种子。

## 2. 域内双无穷小夹逼定理

固定原始搜索域 `[0, μ_max]`，沿原始仿射输入路径 `p(ε)=p₀+εd`，定义

`μ_crit(ε) = inf { μ ∈ [0, μ_max] : L3 在 (μ,p(ε)) 为 UNBOUNDED }`。

这里 μ*=μ_crit(0) 已由 L3 精确证书绑定；所讨论方向须在邻域内保持
L1 接触骨架和模型有效条件。L3 原问题为 `max α, Ax=b, x≥0`，
目标向量为 `c=e_α`，非负 μ 上的可行力锥随 μ 单调嵌套。
因此归一化 `r_α=1` 确实是改进射线；本定理不是任意 LP 的无条件结论。

设 s 为有理数，取有序域 `K=Q(η)(ε)`，序为 `0<ε≪η≪1`。
非零多项式先按 **ε 的最低次项**、其系数再按 **η 的最低次项**定号；
有理函数的符号为分子、分母符号之积，不可交换定号次序。

若在同一 K 中下列条件全部成立：

1. `μ₋=μ*+(s−η)ε ≥ 0`；
2. `μ₊=μ*+(s+η)ε ≤ 原始 μ_max`；
3. 于 `(μ₋,p(ε))` 存在 `Aᵀy≥c` 的精确对偶可行点；
4. 于 `(μ₊,p(ε))` 存在 `Ax₀=b, x₀≥0` 及 `Ar=0, r≥0, r_α=1`；

则正向右导 `D⁺=lim ε→0+ (μ_crit(ε)−μ*)/ε=s`。
理由：精确有序域证书保证对每个充分小正 δ，再对依赖 δ 的充分小正 ε，
两界分别不是无界、是无界。域内的 μ 单调嵌套于是给出
`μ_crit(ε)∈[μ*+(s−δ)ε, μ*+(s+δ)ε]`，夹逼得所述极限。
反向种子 `−d` 单独构造相同证明；其值为 D⁻，通常意义左导为 **−D⁻**。
证明不依赖候选分支枚举是否完备。

K 是有序有理函数域，并非实闭域。这里的有限有理函数证书可直接解释为：
存在 δ₀>0，对每个 0<δ<δ₀，存在 ε₀(δ)>0，使 0<ε<ε₀(δ) 时
全部分母非零、证书与域条件成立。若采用实闭域转移表述，须先嵌入保序实闭包。

### 搜索域前提的必要性

令 `A=[[-μ,μ,1],[1,1,−t]]`, `b=0`, `c=(0,0,1)`，原始 `μ_max=t₀=μ*=1`。
沿 `t=1−ε`，候选 `s=1` 在域外的 `μ*+(1±η)ε` 确有上述对偶/无界证书，
但原域 `[0,1]` 内无界集合为空；原定理缺少域内条件时结论错误。
相应接触几何实现及逐项精确复核见修复证据中的
`theorem_domain_counterexample.*`、`boundary_geometry_probe.*`。
因此必须保存并使用**原始**上界，不得使用二分收窄的 `μ_hi/μ_lo`。

当 `μ*` 严格在域内，域条件自动成立；当 `μ*=μ_max`，需 `s<0`；
当 `μ*=0`，需 `s>0`。域条件不成立的方向统一为 `unresolved`，
reason 为 `threshold_search_domain_boundary`，不以域外有限导数代替，
也不要求另证无界集合为空。下界钳制导数为 0 的合同留待后续，不在本单新增。

该 reason 的实际语义（验收 2026-10-23 澄清）是："阈值位于搜索域边界
（`μ*=0` 或 `μ*=μ_max`）且该方向没有取得域内 K 证书"。实现在边界阈值上
总会先试探 `s=0`（它必然违反域条件），因此边界阈值上任何未认证的方向都带此
reason——包括向内方向真实导数非零而搜索未找到的情形。它不是"已证明向外"的
断言；想区分"向外"与"向内未找到"需要另一个 reason，留作后续。
在 `μ*=0`、`s≤0` 时夹逼不可能成立（`μ→−μ` 的锥对称把 (a)(b) 变成矛盾），
所以向外方向永远不会被误认证。

## 3. 候选、证书及失败语义

- 临界基的隐函数根、其他机构/射线基及邻近有理探测点只用于**候选生成**。
  具体枚举与探测上限必须可审计；达到上限不构成认证，不得回退到旧单基结果。
  暂不满足域条件的试探斜率仍可用于发现其他候选，不能在探测之前把整条候选链剪掉。
  例如 μ*=0 时初候选 s=0 不可认证，但邻近基可揭示 s>0 的域内分支。
  这不放宽认证：最终输出的每个斜率仍须同时满足原始域两条件及上下两端 K 证书；
  仅得到域外夹逼的方向仍报 `threshold_search_domain_boundary`，不输出域外斜率。
- 完整多项式由原始顶点、锚点、荷载及其仿射种子重建：点、T、N、
  `g±=N±μT`、`(p−anchor)×g±` 及荷载力矩逐项精确展开。
  不能从一阶 `dA/db/dc` 反推二阶及更高阶项。
- 对每个候选分别核验上下两端全部等式、不等式以及原域两条件。
  无穷小算法若采用级数截断，只有精确算出的系数足以决定符号才可认证；
  未知高阶项不能当作零。本轮优先使用不截断的完整多项式。
- 没有可用证书时该方向为 `unresolved`，通常 reason 为
  `threshold_branch_certificate_unavailable`；不补值。已取得的 K 证书优先于
  旧所选基的奇异诊断。仅两方向均未取得 K 值且不是域边界等独立拒收原因时，
  旧临界基奇异或真实越零分量 `φ_μ=0` 才保守保留 singular 诊断、不给斜率；
  这不是全问题不连续性的证明。非阈值回收锥的 possibly_discontinuous 规则不变。
- 两方向均认证且 `D⁺=−D⁻` 为 smooth；均认证而不等为 one_sided。
  只有一方向认证时只给该方向的值。`exact_jet` 只能用于确有精确证书的值。
- 阈值通道的非零 μ 种子拒收：`dμ_crit/dμ` 不属于此输入路径合同。
  C ABI 返回 INVALID_INPUT 及准确的数组字段、元素/通道下标。

## 4. 输出与独立复核

CriticalParameter2 新增 `search_domain`，同记原始输入 binary64 位模式、
可读数值及精确有理上下界；旧字段含义不变。公开 C 结构布局不变，
原始仿射路径可由句柄内部持有。

敏感性新增可序列化 `branch_certificate`：版本、无穷小次序、原搜索域，
以及 forward/reverse 的候选 s、认证/失败状态、探测点、基行列标识、
共同分母与各分量分子的完整多项式系数。独立 checker 从原始输入重建矩阵，
复核基公式及全维残差和字典序符号，不采信证书自报的符号。
工具层 `.certificates.jsonl` 另以顶层 `mu_max_binary64` 绑定调用方原始请求（来自 `base_query.mu_max_bits`），独立 checker 核它等于返回 `search_domain`；缺字段拒绝，不从返回域倒填。这不是公共 C 结构新增字段；门见 `test_archive_caller_domain_forgery_is_rejected_by_independent_checker` 与 `test_certificate_archive_writer_binds_the_original_caller_request`。

本轮实现的有限搜索预算为每方向最多 64 个不同有理候选；每候选采用
`ε∈{2^-8,2^-16,2^-24,2^-32}` 与 `η∈{2^-4,2^-8,2^-12,2^-16}`，
一对筛选探测加最多 16 对网格探测（探测点不按种子幅值缩放：缩放因子会被静态构造门判为
带舍入标记的量，而探测点只选基、不进证明，故不值得为此放宽门）。
候选集合不声称穷举全部临界基，认证不依赖其完备性；
预算用尽而无证书时不补值。墙钟与内存并非由该搜索次数预算保证。
下端探测点原问题 INFEASIBLE 时，对偶可行点取自齐次问题
`max cᵀx, Ax=0, x≥0` 的精确对偶（它恰在 `Aᵀy≥c` 可解时 OPTIMAL，
且其对偶是带 m 个独立紧列的基本点）；分裂变量见证 LP 不保证返回顶点，
曾使 C++ 在恒载 / 活载种子上取不到下端证书（2026-10-23 验收发现）。
见证基在退化探测点上依赖于 LP 返回的顶点：同一探测点用另一组基提升的公式
可能在 K 中通过而本基失败。两后端因此保留本方向各探测点见过的下端对偶基、
上端点基与射线基（C++ 另加"裁判式"基：按下标序的独立行、支持优先的独立列、
射线排除 α 后归一化），缺哪端就用最近 6 组已见基在当前探测点重新提升并核 K；
复用的基还须在当前有理探测点非负，使证书记录的 probe 可被独立核验器复核。
Python 已把 `_probe_consistent` 并入 `_vector`：带 ε/η 记录的见证提升返回前同时检查记录探测点的分母与相应可行性；不只在复用循环外检查。无探测记录的奇异候选元数据不作有限点检查。C++ 复用路径仍由 `probe_primal_ok` / `probe_dual_ok` 把关。K 可行而当前有限探测点为负的基必须跳过；反之有限点非负也不能代替 K 核验。
基只负责选择，不构成证明。
候选斜率同样依赖 LP 返回的顶点：退化临界面上不同的最优对偶顶点给出不同的
一阶越零根，一侧可能恰好取到暴露竞争分支的顶点而另一侧取不到（验收所见
g1_slender 三个方向）。因此当全部顶点派生候选都失败时（内部阈值与边界阈值皆然：边界阈值上向内方向仍可能有有限导数，向外夹逼仍被域条件拒绝），两后端
再各用一次"探测几何自身的精确阈值"生成候选：固定 ε=2^-24，
在原始域 [0, μ_max] 上对 μ 二分（可行力锥随 μ 嵌套，单调），取商括号
`[(μ_lo−μ*)/ε, (μ_hi−μ*)/ε]` 内的最简有理数作候选。这一路不依赖 LP 顶点；
它仍只生成候选，是否为导数仍由 K 证书判定。二分只用 ε=2^-24、56 步，
矩阵元对 μ 仿射，故由两次求值的 A(0)、A(1) 线性组合得 A(μ)，不逐步重建多项式。
每个候选先经一次**筛选探测**（ε=2^-24、η=2^-8 的一对 LP）：下端须非无界
（允许原问题不可行而取得齐次问题的对偶见证），上端须无界，才进入 16 点探测网格与提升；
被筛掉的候选仍贡献其基作为新候选来源。
筛选是搜索预算的裁剪，不改变"证不出即 unresolved"的语义；两后端同一规则。
上端的点与射线同样依赖 LP 返回的退化顶点（验收所见 t1b/03 单面反向：C++ 的归一化射线
LP 在 16 个探测点都返回同一顶点而其提升在 K 中为负，Python 的 LP 核恰好访问到第 7 个顶点）。
两后端因此在本探测点的提升失败时，对每个在 K 中为负的分量 j 再解一次
`max r_j`（或 `max x_j`）于筛选探测点（ε=2^-24、η=2^-8）的多面体，每次 point/ray 定向调用最多选 8 个负分量，
先用最近 6 组已见基重试，再取定向顶点并立即在当前探测点提升、核 K 与探测点一致性（顶点在哪个有理点取得
无关紧要：基只负责选择）。两后端的筛选条件相同：下端须取得对偶可行点（原问题不可行时来自齐次问题）、上端须无界。
C++ 另有最后一道**有序域换基修复**（验收 2026-10-25：t1b/06、t1b/15 单面反向，LP 核在全部探测点都返回同一个在 K 中恰有一个分量为负的退化顶点）：对本探测点自取的点 / 射线公式，若某基变量在 K 中为负，按 Bland 规则把最小下标的这样的列换出、把在 K 中主元为负的最小下标非基列换入（零目标，故比值检验对任何此类列都成立），最多 32 步；修好的公式照常核等式与 K 符号。它在 K 中非负，但未必在其提升时所用的网格点上非负，因此在更细的二进日程（η=2^-b，b∈{4,…,64}；ε=η^m，m∈{2,4,8}）里取第一个使其非负的点作为该见证的记录探测点——探测点不是定理前提，只为让证书在记录点上可被独立复核。Python 裁判不做此修复；C++ 因此可能多证出方向，差分以 `verified_cpp_only_branch_slope` 处置登记。
最后一道**形状不变量**：某方向只有在下端对偶、上端点、上端射线三份 K 证书齐全时才算
certified；缺任何一份一律改报 unresolved（reason `internal_certificate_shape`），
两后端各有具名门守护，使"报了值却没有证书"的缺陷不能静默通过。诊断性的逐探测点跟踪不放在生产模块里（静态构造门不接受 os / print 等闭集外调用）；需要时在工具层对照两后端证书的候选与探测记录。

奇异候选基另存 `singular=true`；每个匹配约束携带最低 ε 阶
`leading_epsilon_order` 和常数项在前、保留重数的 monic
`leading_polynomial`。独立核验器以 Cramer 行列式重建该多项式，
逐项核系数及其在所证 s 的零值；不能因为原点基奇异而隐去其候选标签。
这些字段仍只解释候选，不代替上下两端 K 证书。

有限探测可行不意味着 K 可行。本轮非对称荷载回归中，曾取得一个在
`ε=1/65536,η=1/256` 全分量非负的射线基，但某分量分子、分母的
最低 `(ε,η)` 次数同为 `(1,0)`，系数分别为
`−63893565/8589934592` 与 `651714363/17179869184`，所以在 K 上为负。
实现必须拒绝此基，再寻找基或缩小探测点；不能用有限点成功替代定理。

## 5. tied_labels：承接 10-23 Claude 裁定

阈值导数的 tied_labels 是基依赖证书字段，不是跨后端语义不变量。
本修复将其细化为：候选分支中一阶根斜率等于所证 s 的约束标签。
正规基使用 `−φ_p/φ_μ`；原点奇异基使用精确分子最低 ε 次系数的
η 多项式之有理根，允许重根，不伪造隐函数比值。
每侧独立核验其所选候选基、全部匹配根及根斜率，不得多报、漏报或报错斜率；
两后端集合不同逐查询登记，不算失配也不得隐藏。
方向导数、可微性、quality、reason、有效条件、阈值及开闭性仍严格比较。
非阈值（固定基 / Mills–Freund）的 tied_labels 仍严格比较。

## 6. 兼容与验收边界

证书路径假定沿 `p₀+εd` 的 L1 接触骨架与 LP 列集不变（validity_conditions
"L1接触骨架不变"）；证书本身不检查这一点。目前的守卫是：C ABI 拒收同一坐标
顶点带不同速度的种子；非对称差分族在每侧三个精确探测点重装配并比对带标签的
骨架，不同则该方向不计入。一个顶点沿边滑到端点、或重合顶点在一阶分离的种子，
会使多项式族成为错误的 LP——这是已声明的前提而非已证的性质，列为遗留：
后续应在证书路径上核每个接触顶点在 ε 一阶仍落在其边的内部。

冻结语料不改。旧认证值或类别发生变化（含新域规则导致 unresolved）时，
逐查询建立 errata 覆盖，记录旧值、新值和证据。C++ 证明能力下限以修后 Python
为准；双方同错由独立 K 核验、非对称种子、精确差商红旗与具名内部变异门防守。
差商只是红旗，不是导数证明。人工所有者验收与新鲜 Git 树复核由 Claude 安排。
