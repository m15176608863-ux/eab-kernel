# M3b：三维显式边界、闭盖裁剪与出口合同

本文只补 M3；不改二维 SE(2) 的平行工单。代码为 `kernel3d/boundary.py`，门为
`tests/test_m3b_boundary3d.py`。下面定理为本仓库自包含证明，不冒称石根华原文逐字命题。

## 1. 精确模型及产物

输入为已经认证有限满维紧凸分解的 A、B；`global_entrance` 提供
`C_ij = B_j - A_i`，`E = union C_ij` 和物理贯入集合 `O = union int C_ij`。
`E = closure(O)`，但 `O` 可以严格小于 `int E`，紧配内缝是明确反例。

输出不是半边数据结构或焊接流形网格，而是**有限闭凸多边形片覆盖**。片之间可以共享边、
重叠共面的边和重复标签；集合意义的边界完全明确。每片带来源、精确法向、精确双侧探针和三态。
所有坐标、平面、交点、中心、距离平方和见证用 `Fraction`，无浮点构造出口、无隐含容差。

## 2. T3B：显式边界强完备（已证明）

条件：`C_1,...,C_N` 为有限个非空满维紧凸多面体，且 H/V 描述精确一致。
将每个 `C_i` 的每个 facet 以全部 `C_j` 支撑平面加细。对于每个所得二维相对开片 P，
沿其法向取最近非零平面事件距离的一半作为双侧采样；保留当且仅当两侧的**闭占据**不同。
所有保留片闭包的并等于 `boundary E`。

证明分四步。

1. `boundary(union C_i)` 包含于 `union boundary(C_i)`。否则一点若落在某 C_i 的内部，
   则在 E 内部；若不落在任何 C_i，有限闭并的补集为开，亦不是边界。
2. 全部支撑平面安排使每个相对开二维片的两侧分别落在固定满维开胞内，且每个半空间符号恒定。
   因而每个 C_i 及闭 E 的占据在各胞上恒定。最近非零事件的一半严格不穿过任何其他平面。
   当前片的平面在法向两侧给出严格相反的符号。重复共面平面只有零事件，不产生 epsilon。
3. 若两侧异标，一侧为 E 内点、另一侧为补集内点，P 上每一点都是二者极限，故 P 包含于边界。
   若两侧同标为内，则 P 邻域两侧均被占据，不属于二维边界；同标为外亦不能是 E 的二维边界。
4. E 是有限满维凸体的并，因此正则闭且其多面边界纯余维一。每个低维边界点都在某暴露二维片
   的闭包内（否则一个小球的所有满维胞都同标，点不是边界）。取所有保留片闭包即补足全部棱/顶点。

不要求一般位置。共面、多重相交、平行棱及零面积候选均按精确秩处理；真正二维片才入表，
低维边界由闭包保留。该算法不输出 O 的内部缺失缝，物理三态仍必须由全局 E/O 模型查询。

`C_ij` 的 V 描述可由所有 `b-a` 取凸包；其每个 facet 位于 A/B 面法向或非平行棱叉积法向
的支撑平面上：凸体和的支撑面是两支撑面的和，二维支撑面只能由 VF/FV、非平行 EE 或其退化
面-边/面-面产生；退化支撑面仍位于对应面法向平面。因此 SAT 给出的支撑平面与其上差顶点
的二维凸包恰为全部 facet。实现对平面内点做有理单调链凸包，不用显示浮点 hull。

## 3. T3L：原始有效局部盖的条件强完备（证明完成，条件不可删除）

局部候选为原始平面环的闭有效 VF/FV 三角片以及非平行 EE 平行四边形。
有效条件用既有闭法锥包含判据，不以 strict 过滤；凹面环先精确三角化，保留原始 face 标签。
非平面环必须由调用方显式三角化；本 API 响亮拒绝偷偷将其当单平面使用。

**一般位置 GP 的充分条件**：A、B 为嵌入定向多面实体，面为平面简单环；跨实体的两面不平行，
跨实体的任一棱不平行于另一实体的任一面，跨实体两棱不平行。它们是原坐标精确叉积/内积的非零
条件，强于实际所需，但不依赖“已知覆盖”的循环前提。共面细分可先按真实几何特征复形理解。

**GP ⇒ H 的证明**：边界任一点使两闭实体接触而内部不交（若内部相交，平移的一个开邻域均相交，
点会在 O 内部）。选接触点在双方特征的相对内部。VV 的平移集合为有限点，VE/EV 为有限线段，
其并维数至多一，不能占据边界的二维相对开层。EF/FE 接触若横截面，则棱在接触点附近穿入对方
面的内部半空间，附近实体内点也进入，矛盾；因此非贯入 EF 必须棱平行于面，GP 排除了它。
FF 接触若两面不平行，两个局部实体内半空间的交含开楔，亦必贯入；平行 FF 被 GP 排除。
剩下稠密二维边界层的接触只能是 VF/FV 或非平行 EE。

VF 时，接触面邻域的实体就是一个内半空间。为了避免内部相交，另一实体顶点的全部局部实体方向
都在互补闭半空间，因此面法向或其相反数满足顶点闭法锥判据；点位于有限面内，恰属于所生成 VF/FV
多边形。EE 时两个接触棱方向非平行；不贯入先迫使双方局部内楔为凸：若一方是大于 π 的反射楔，
其小于 π 的补楔不能同时容纳另一非平行棱的两个相反横向投影。两个凸局部切锥因此可用凸锥分离
定理分离。局部不贯入要求分离平面同时包含两条棱直线，否则一条直线
的两向至少一向进入另一实体局部内部。其法向只能为两棱叉积的两个符号之一。两个局部内楔分别在
该平面的互补闭侧，故两闭棱锥判据成立，有限棱参数属于 [0,1]，平移位于对应 EE 平行四边形。
由此每个二维边界层的稠密子集被有限闭有效候选覆盖；有限闭并是闭集，取闭包覆盖该层全部点及
纯余维一边界的全部低维层，得到 H。此证明也说明为何闭锥有效而非严格有效是必要的。

**条件 H（弱覆盖）**即原始特征闭有效候选 L 的并覆盖 `boundary E`；以上给出 GP 的非循环充分条件。
退化时必须将共面 face/edge 接触域精确分解，并验证它由闭有效 VF/FV/EE 候选覆盖；不能仅
以“微扰后成立”推断原始索引法锥实现也成立。本轮没有证明**任意**嵌入凹多面体都满足 H。

在 H 下，对每个 L 与显式全局边界共面片求精确多边形交，所得闭片并恰为 `boundary E`。
证明：每个交集是边界子集（可靠性）；对任意边界点，H 给一个含它的 L，T3B 给一个含它的
全局片，所以在某交集中（完备性）。仅输出二维非零面积交时，尚须 H 在每个暴露二维开片成立；
边界其余低维点由这些片闭包恢复。这就是二维 T2 的三维条件对应，不将条件 H 偷换成实验事实。

测试不仅查面中心：在每个全局片内以全部共面局部盖边线再次完整加细，逐原子片中心检查至少
一个保留标签；符号在该原子片内恒定，故该有限门证明**该输入**的全片覆盖，不是随机点经验。

## 4. 出口与独立 oracle

`ExplicitBoundary3D.shortest_exit(t)` 对 `t in E` 返回到 `boundary E` 的最小距离平方和全部
并列有理最优点。每片的正交投影若在片内则加入，否则最近点在边界；每条边的钳位投影亦全部加入。
凸片距离最小点由此穷尽；有限片取最小得到 `PD_closed`。返回点仍相触，是严格分离距离的下确界，
不称“已分离”。并列点集合协变，不引入不可能普遍旋转协变的单一字典序代表。

`g03.g0_distance_completeness3` 原来遇相交/接触样本直接跳过。本轮逐个执行：
原始表面独立 VF/FV/EE 支撑事件超集 → 确定性 moment-curve 非平行方向 → 相邻事件区间中点
的独立表面闭集合分离判定 → 第一个外部开区间的左端点；与全局闭区间出口逐值 Fraction 比较。
有限坏方向由有限个非零二次多项式的根给出，故选方向必终止。事件超集不裁剪、不做法锥过滤，
因此不会自己删除错误候选。每个真实 E 边界事件均是一个特征支撑面事件；事件间成员恒定。
这关闭了相交样本**沿此方向出口**的缺口，不宣称 g03 随机采样本身证明任意方向或最短出口。

oracle import 清单：`g03_exit_oracle`: fractions、itertools、g03_surface_oracle；
`g03_surface_oracle`: fractions、functools、math、kernel2d.g0_oracle.sqrt_display。
其几何使用独立整数面绕数、射线奇偶、线段/面检测、点面/棱棱距离，与被测 BSP/SAT/裁剪无共用。
边界样本三态另用 `geom3.polyhedra_overlap -> exact_geom`，原始表面的独立三角分割/奇偶；
未调用被测 global_entrance、boundary 或 covers3。Cartesian 紧配盒最短出口门不 import 几何 oracle。

## 5. 变异及诚实边界

- 删除 `clip_local_covers` 裁剪、直接返回原局部候选：红在“buried polygons”语义断言。
- 将暴露判断换成物理 `classify(片中心)==0`：误收紧配内缝，红在双侧闭占据语义断言。
  **不能伪造另一条变异结果**：在正确的完整安排满维双侧开胞上，物理值只能为 -1/1，
  因而将 `>=0` 字面改为 `>0` 是等价变异，无法也无需杀死；误收内缝的是把片上的 0/1 当拓扑边界。
- 恢复相交跳样：红在“intersecting exit sample must execute”，不是源码哈希。

这些门直接 exec 修改函数内部，未运行也不依赖任何源码哈希检测。
本模块不引入空间索引或新的凸合并；不承诺复杂度优于完整平面安排。全局 N 个 facet、H 个平面
的朴素二维逐平面切分最坏增长可达 `O(N H^2)` 片；候选与全部片的笛卡尔求交也可能很大。
局部查询版可只选与查询域有交的凸胞及片，但必须由精确包围盒证明排除，不能用浮点阈值。
本轮先冻结小型凹块与紧配实例的完整探针；未把有限规模成功写成任意大型网格的可承受性证明。
