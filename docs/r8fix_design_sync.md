## 1. 二维初态：实体相交态不等于 E 的拓扑态

`int(A+x) ∩ int(B) ≠ ∅` 是 `x ∈ int(E)` 的充分条件，不是一般凹对的必要条件。紧配内缝可以只有实体边界接触，却仍位于 `int(E)`。

生产侧先保留严格相交/分离快路；相触态用精确三角对 Minkowski 单元及其局部闭切锥，按全部活动边方向划分扇区，判定邻域是否被覆盖。首入初态与凹 `membership_convex` 使用 E 的拓扑态；实体相交 API 仍使用原三态，不偷换其合同。

进入 `exit` 分支不意味着局部 `shortest_exit` 已成为任意凹体全局 PD 算法。紧配缝的局部接触片仍可给零 gap；该结果是既有局部出口策略，不得宣传为到真正全局 ∂E 的最短距离。门：[二维初态及同类扫描](file:///D:/eab-wt/cx-e2/tests/test_r8fix_initial_state.py)。

### 1.1 同类修复：三维初态和零裕度成员分类

同一紧配反例挤出到三维后，旧 `first_entrance3` 也会报 `entrance/t=0` 或误抛漏报异常，零裕度 `inflated_membership` 则误报边界。三维生产侧从全部三角片 VF/FV/EE 配置平面构造局部中央平面排列，使用有理交射线和横截面扇区枚举每个开室；两层精确步长分别避免跨越非入射中央面及非中央配置面。任一室在 E 外即为边界，全部室在 E 内才为内部。不得用固定 epsilon 或有限随机方向代替全室枚举。

仅物理相触态需要该拓扑判定；严格相交/分离沿用快路。零裕度分支在原 `_resolved` 自校验之后运行，不能绕过最近特征完整性门；非零显式边界带/接触窗口仍保持原口径。三维局部最短出口同样不升级为全局 PD。

门：[三维初态和窄室](file:///D:/eab-wt/cx-e2/tests/test_r8fix_initial_state3.py)。[独立交叉核验](file:///D:/eab-wt/cx-e2/reports/codex/R8FIX_evidence/gate_teeth/topology3_review.md) 以 Gordan 分离与独立有理消元核对有限号型，再以 Cartesian 区间并核对逐室状态和精确步长；不调用生产 oracle 作预期。适用合法闭合多面体；平面数及有理数位宽较大时计算可能昂贵，不声称大网格低延迟。

## 2. 冻结几何：原始未归一化 jet 最后才舍入

对冻结片的原始法向 `N`、相对位移 `r`，令 `c=N·r`、`h=N·N`。有符号 gap 为 `c/sqrt(h)`，导数为

```text
(dc - c*(N·dN)/h) / sqrt(h)
```

全部多项式、投影和导数通道在原始输入的 Fraction 上形成；不得把显示单位法向再次有理化后当成特征的精确法向。`frozen_normal` 保留 tuple 兼容显示及未归一化 jet；调用者显式提供的普通法向元组则是独立的输入模型。

冻结升高用 `-c/Nz`，普通标量和 Dual 共用同一有理比值；零种子不改变 primal。最后的 `gap-delta` 及其导数也属于同一次构造，不在 gap 先舍入后再减；`margin_contacts` 的公开 `margin_gap` 也遵守这一原则，不能只修结果恰好变成零的格。代数根差使用精确比较、相邻浮点中点判定，严重相消时在 binary64 有限数序上二分，不依赖固定 Decimal 精度。`margin_contacts` 已有的带精确平方距离证书的显示下溢例外保留，`closed` 仍由精确值判定。

门：[冻结跨度/导数/裕度](file:///D:/eab-wt/cx-e2/tests/test_r8fix_frozen.py)。仍不宣称跨特征切换可微，源面与三角标签的既有模型区别保留。

## 3. 微小角与力学构造

- `dihedral_turn` 从未归一化精确面法向及真实棱方向计算三重积、点积；先共同缩放 atan2 参数，再构造角。不能先分别舍入两个单位法向。二维 `cone_width` 的叉积/点积使用相同原则；`point_side` 也先精确差和行列式，再构造显示值。
- `wrench` 的力臂、叉积先精确形成；旋量平移、速度旋量变换、功率和接触中点也在最终结果处才舍入。内部 LP 调用的 Fraction 速度旋量保持 Fraction，不把证书降为浮点。
- 最终可表达的微小非零值不得因中间范围丢失成为零、NaN 或错号；不能构造的非零结果响亮报错。显示且另带精确见证的既有例外不扩张为数学判据。

门：[三维二面角](file:///D:/eab-wt/cx-e2/tests/test_r8fix_dihedral.py)、[力学构造](file:///D:/eab-wt/cx-e2/tests/test_r8fix_wrench.py)、上述二维门。

## 4. 门的独立性及两种误差票

凸视图的 oracle 必须从保存的原坐标重建支撑面及极点，不调用被测 `exact_convex_view` 预处理 expected。来源编号的保持条件单独核对；稳定纯平移格保留旧完整 facet 标签集合断言，不能用“浮点变换可能改变标签”无条件取消。

非凸距离 G0 与 margin 自校验分开：

1. **精确最近特征完整性票**：被测盖的最小有理平方距离与完整特征真值相等；不加 global-coordinate 噪声地板。
2. **浮点见证构造票**：点坐标显示误差按原有明确口径检查，保留坐标噪声报告；此票不能覆盖前一票的失败。

margin 的全特征核与生产侧共享几何，只是内部佐证；G0 的主 oracle 使用独立表面原语。门：[真实内部变异](file:///D:/eab-wt/cx-e2/tests/test_r8fix_gate_teeth.py)、[独立凸视图 oracle](file:///D:/eab-wt/cx-e2/tests/e5a_convex_oracle.py)。旧 `b6126cf` 门对照及同类迁移扫描的实际范围见主报告，不宣称穷尽全部可能变异。

稳定最终裕度构造不再满足旧 `margin_gap == display_distance-delta` 的逐次舍入等式。原不变性门改为先从原坐标独立构造有理平方距，再对最终值的两个相邻浮点中点作精确平方/符号比较（含 ties-to-even），只接受唯一正确的舍入值；不是改用“一 ULP 内”或更大容差。窗口显示 distance 的原几何误差门和完整标签网格仍保留。门：[裕度舍入证书及内部变异](file:///D:/eab-wt/cx-e2/tests/test_r8fix_margin_gap_gate.py)。
