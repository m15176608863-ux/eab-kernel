## 1. 给定数值的精确性先于浮点过滤

Python 任意大小整数、有限 binary64 float、Fraction 及其混合输入的数学值必须保留。
仅对普通 float 输入适用的误差界，不能用于先隐式转成 float 的大整数。
分支应先核数值类型：缺少严格转换误差界时直接转 Fraction 做精确运算；
已有含转换误差的保守过滤或外扩区间可以保留，但非有限／不确定结果须回退精确。
不能以强制调用方先舍入数据来修复算法新增的信息损失。

二维定向的类型门同时保护其直接调用者：三角化、反射顶点和零窗口线段相交。
同类扫描包括三维定向、双线性符号、多边形区间过滤、分离轴和 LP 的精确证书路径。
已有普通 float／Fraction 三维定向快速路径门保留，不以删门换实现方便。

验证入口：`tests/test_r11fix_numeric_types.py`；既有
`tests/test_filtered_predicates.py` 与 M4a 三组门保持原字节。
反例、有限压力网格及实际扫描清单见 [修复报告](../reports/codex/R11FIX_report.md)。

## 2. 静态构造门的本地 may-state

局部数据流必须同时保存“可能已舍入”“可能可调用对象”“绑定来源”，
分支不能只合流舍入集合而让 aliases/bindings 被最后一次 AST 遍历覆盖。
循环保留零次路径及回边，迭代到有限抽象状态的不动点；分支、推导式、
条件表达式、短路表达式、异常路径与退出路径同样不能以源文本顺序替代运行语义。
别名赋值取得的是当时的值，而不是一个随原变量后续 rebind 改变含义的 AST 引用。

门仍是对已知局部 Python 语法的保守检查，不是任意动态 Python 的证明。
未知用户函数跨过程返回、反射、动态属性和任意对象协议不能据 AST 零违例宣称正确。
真实 `cone_intersection_margin` 路径内植入“先舍向量再求范数”时，
静态门须报 `rounded-vector`，独立 Fraction KKT／中点证书同时核实真实数值错误。

验证入口：`tests/test_r11fix_static_flow.py`，保留 R9/R10 静态门；
报告列出实际语法覆盖、同类反例和关键修复撤回后击中的断言。
