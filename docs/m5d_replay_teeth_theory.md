# M5d：回放双路径与温和 R2 变异的语义门

## R1 双路径（不是双盒）

回放先确认 P1/P2 名义首入相同，再在无接触分支分别认证两条中心轨迹的管。
仅认证 P1 的管不足以覆盖 P2/P3 族。构造 A 的首点 `(10,-1/2)`，半角参数
`u(s)=s/20` 转动；P1 是相同端点的弦，首点 x 恒为 10。B 的左边在
`x=501/50`，纵向包含 0。A 的半径取 1/100，B 的半径 0。

P1 的全管在 x≤10.01，故严格分离。名义 P2 所有点半径不大于
`sqrt(401/4)<501/50`，亦无接触。但 s=1/2 首点为
`(16030/1601,1/3202)`，允许连续扰动 `dx(s)=4r*s*(1-s)` 在中点达到 r，
将首点推入 B 内部。此扰动端点为零，且全时程在 L∞ 管内。
因此完整双路径 R1 必须拒绝；只查 P1 的真实内部接线变异将错误签发。
独立 oracle 仅以 Fraction 的上述有理恒等式、最大半径平方与矩形内部
不等式核对，不调用被测几何、包络或求根函数。

## R2 温和变异

早期证书必须覆盖整个 `[0,l]`。将三次平移轨迹时间压缩为
`t=(s-a)/w, a=(3/5)(1-w)`，选 `w=1/100` 与 `1/10000`，
使先前底边接触恰落在分别被 `hi=0.99*l`、`hi=0.999*l` 漏掉的末端。
独立闭式首时刻 `s=a+w*17/40`，接触点 `(33/32,-2)`；提名的却是随后
`s=3/5` 的墙面标签。真实内部温和缩窗变异均会错签，而完整窗口拒签。

单首盖回放也必须对 P1/P2 都检查。另构造 P1 平移速度 `2001/1000`、
P2 平移速度 2，名义首时刻分别 `1000/2001`、`1/2`，首标签相同。
20 次二分加最大 pad `1/256` 得共同括区
`(519929/1048576,528385/1048576)`。其 P1 / P2 端点允许半径阈值分别
`8198071/1048576000`、`4097/524288`；取两者均值
`r=16392071/2097152000`。这个 r 大于端点残差 `1/1000`。
P1 管能签发；P2 管内常量 x 偏移 `-r` 的首时刻 `(1+r)/2` 落在括区之后。
因此 `all→any`、只检查 P1、将单盖管半径温和乘以 0.99 三个接线变异
都会错签。这里反证的是证书承诺的首时刻括区，不声称该平移族首标签改变。
三个更窄 pad 不能修复已超出最大括区的轨迹。

每个门先检查构造确实满足名义/扰动条件，再用具名拒签断言检查生产结果。
内部变异只替换目标函数源码体；不选择源码哈希/冻结摘要测试，不改产出。

对应具名门：`tests/test_m5d_replay_semantics.py`；数值合同不改生产公式。
参数化早期宽度不重复：两个首时刻和两个括区均互异。所需函数只导入
Fraction、math.comb；Path/sys/pytest 是测试设施，DDAAnchoredMotion 与 rob/replay
仅为被测入口及输入适配器。独立 oracle 不调用其几何/求根/区间原语。
