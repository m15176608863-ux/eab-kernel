## 1. 两种几何对象，不暗中凸化凹块
一般 `Polyhedron(verts, faces)` 仍表示输入面环确定的闭合定向表面。非共面多边形按确定性投影耳切三角化成为折面；不能说舍入后的四个点仍然共面。凹多边形不能扇形填充凹口。

显式凸 API（convex_hull_3d、凸对 E、membership_convex3、local_facets3/G0）采用另一明确语义：**凸块等于输入顶点集的精确凸包**，输入面是来源/拓扑提示。舍入形成的微凹被凸包填平，微凸脊保留；不按噪声抹掉。一般相交 API 不能未经声明替换为凸包，尤其 L/U/互锁块绝不自动凸化。

选择凸包而非微凹拒收，是为了使显式凸 E 定理适用于舍入后的工程输入；代价是区分凸模型与给定表面模型。两模型只有在输入表面精确为凸时才能直接当作相同对象。重复点去重，共线边内点/共面面内点不能成为极点；零体积明确拒收。仅精确 orient3d=0 的相邻三角可以合并，不近似合并微二面角。

## 2. 编号与标签
一般表面 API 保持原始 face/edge/vertex 编号。显式凸路径使用缓存的 canonical convex view：尽量保留来源顶点编号；原面确实等于精确 supporting facet 时保留其编号，其他 facet 确定性排序，并记录输入面包含关系。非共面四边形可能对应多片 facet，也可能出现不属于任何输入面的新 facet，不能把整个四边形冒充一个平面。

凸路径 VF/FV/EE/VE3/EV3/VV3 标签属于同一 canonical view；解释标签的函数必须先解析同一 view。不能把 canonical face 下标直接用于原始 faces。一般单盖 API 按原始表面编号。跨模型比对使用精确支撑顶点集，不按近似法向配对。

## 3. 精确 E、局部规则及 G0 三票
凸 E = conv{b−a}。必须先有理化坐标再相减，不能将已舍入 sub(b,a) 当原问题的精确差点。支撑面用未归一化有理叉积；F_A=argmin n·a，F_B=argmax n·b。仿射维数精确，严格 facet 恰为维数组合 (0,2)、(2,0)、(1,1)；其他二维支撑和是退化 facet，不是 ambiguous。

局部命题4/5用原坐标派生未归一化棱/面法向，精确棱弧、顶点锥及锥的相对内部相交；不能把浮点单位方向再有理化冒充原始法锥。

G0 票一：独立有理数 SAT/表面相交对被测成员。平移也在有理数中相加，防止两票比较不同舍入对象。随机样本之外强制 E 顶点、每条棱有理中点、每个精确 facet 有理重心；内/外/边界全部计分。票二：独立差点凸包支撑集合与局部标签双向全量比较，漏/多一个都失败。票三：完整精确极点集等于局部锥交集，没有 ambiguous/low/low_e/高度豁免。oracle 不借用被测法向/棱弧/锥交原语；共用原始坐标和 Fraction 不算共用几何原语。

## 4. 一般三角化表面的成员与相交
点在三角形、线段−三角形、三角形−三角形用有理符号和闭区间。成员先查精确表面，再用精确射线奇偶；射线遇边/顶点退化换确定性整数方向，不能重试耗尽默认边界。

相交三态为分离 −1、仅边界相触 0、内部相交 1。必须覆盖没有顶点在对方内部的穿透及共面重叠，不能仅靠顶点包含或随机微推。凸表面可用精确 SAT；一般表面需要三角相交和局部体侧/内部见证。一般路径未完整验证时如实标未完成，不以改名宣称精确。

## 5. 域窗口与噪声带
调用方明确给出的搜索 window、贴合距离、角域扩张保留，只能增加候选，不能改变 strict/凸性/共面/零非零。兼容 tol>0 成员报告带必须有真实距离见证并与精确分类分离；tol=0 不加 noise_floor。

删除：凸包可见性/细条删除/极点吸收的噪声阈值、近似共面合并、G0 支撑带/ambiguous/low_e、锥交绝对重心阈值、近平行线独立浮点参数分支。noise_floor/face_noise 仅作可分辨性或构造误差报告，不作本单精确答案裁决。

## 6. 保守过滤与性能
orient3d 用浮点 determinant 和严格误差上界；只有 |det|>bound 才采纳符号，否则 Fraction。界覆盖相减/乘加误差及次正规/下溢绝对传播项，非有限中间值退路。Fraction 输入不得被 float 替代；允许保留原值并在过滤界内额外计入有理数到浮点转换误差，未证实则仍算原值。二维热点仅在不改精确构造和返回契约处加过滤/确定性缓存；LP 保留精确证书。

逐个对拍随机、共面、近平面、工程坐标、指数跨度、次正规。过滤界缩小10倍用真实错号见证击中，未找到就如实列未完成，不能伪造返回值。E5a2 全套目标 <=900 秒（理想 <=600 秒），交付实测而非预估。

### 2. 显式局部贯入厚度窗口的数学定义与限度（E5 已完成）

`contact_resolution(A,B)` 只提供旧口径数值 `max(effective_geom_tol, 1e-12*max(diag)) + rounding_floor`，调用方必须显式传入 `contact_window=w`。w 有限且非负。分离侧精确表面距离平方 ≤ w² 时按相触报告（距离 0、ON_BOUNDARY、闭合）。贯入侧采用所有者批准的**局部贯入厚度窗口**：六轴刚性脱离充分证书 OR 局部径向薄壳证书。`contact_window` 名称保留兼容，未新增参数或别名；该量不是整体最短分离平移的欧氏贯入深度 PD，也不是其完整子水平集：

1. 原实体对；
2. A 沿每个坐标轴精确平移 +w 或 −w 后的六个实体对：任一不贯入证明存在长度 w 的刚性脱离位移；
3. A 或 B 各自可认证的星核收缩模型。中心 c 取原顶点精确平均；必须对每个朝外三角面有 `n·(c−p)<0`。令 `R=max_v ||v−c||_1`，`α=min(w/R,1/2)`，内核顶点为 `c+(1−α)(v−c)`。每条被移除的径向壳段长度 ≤ αR ≤ w。内核与另一实体不贯入即证明重叠只在厚度至多 w 的该表面壳内。无星核证书时不启用该项。

`exact_sweep.contact_models` 唯一生成此集合；margin 对集合作精确 OR，interlock 对同一集合的最早根取最小。证书失败只表示未被该窗口接受，**不能声称真欧氏穿透深度 > w**。六方向证书是坐标系相关的有限政策，不宣称它等于旋转不变的完整欧氏偏置；星核壳证书也不等于最短刚体脱离。双侧微量夹持可能需要很大的整块脱离，却仍属于薄局部接触壳；这正是原抖动墙窗口可以回到名义高度的区别。严格物理默认路径不采用任何此政策。

独立门：原 margin touch/subtol 逐格整数 SAT；墙的独立扫掠 SAT、严格分离轴和自有射线包含排除；`test_interlock_exact.py` 的三尺度/大平移盒对窗口根闭式值与 margin 相触、根前 INSIDE 的一致检查。所有旧不变性断言留在调用方显式窗口下，另保留默认精确 oracle。并未宣称对任意凹体提供完整欧氏穿透深度算法。

### 2a. 可靠性、限制与独立门（WO-PERF 定稿）

“相触”的可靠性是带分支的精确析取，不能把两分支混为 PD 证书：

- 六轴分支：存在 `d ∈ {±w e_x, ±w e_y, ±w e_z}`，`int(A+d) ∩ int(B)=∅`，因而 `PD ≤ ||d||₂ = w`。对原本分离输入另由真实距离平方 `d² ≤ w²` 接受；这不是贯入分支的结论。
- 薄壳分支：存在经认证的 A 或 B 星核 K，`int(K) ∩ int(other)=∅`；原实体每处严格重叠都在该体的闭径向壳内，任意径向壳段欧氏长度至多 `αR ≤ w`。这不意味着有同一个短平移能同时解除每处接触。
- 反向不成立：报 `PENETRATING` 只意味着有限证书未通过，**不推出 PD > w**；默认 `None/0` 则仍是原实体严格精确三态，不走窗口。

独立门均在 `tests/test_perf_contact_window.py`。oracle 只用 Fraction 标量、预先给定的精确正交基、区间积、笛卡尔积及平方范数；不调用被测侧法向、SAT、点成员、星核、距离或三角化原语。每个参与区间判定的实体先证明其八个顶点恰好是区间积的全部角点，防止把 AABB 当真实实体。

### 3. 最早逃逸根与首入

`surface_events` 枚举真实三角表面的 VF/FV/EE（含三角对角边）事件，平行共面持续情形补端点过边/重合事件。仅精确零才平行，近竖直特征不得按噪声删除。所有根是有理数；相邻根之间拓扑不变。在正根处逐个精确判非贯入，首个通过者的每个此前开区间取有理中点，全部须严格贯入；否则响亮失败。`EscapeSolution.exact_height / exact_offset` 是权威运动数据，`interval_certificate` 为胜出模型的逐区间证明，`nonpenetrating_state` 是该模型根处检查。窗口中其他模型在当前上界前逐事件检查以排除更早根；返回的单份区间证书不冒充全部模型的证明清单，可按 `contact_models` 重算。

`height` 为向上舍入的 binary64 **显示值**，不是将每个顶点重新做浮点加法后的安全保证。后者是另一组数据，须重新精确判定。`cover_label/tied_labels` 保留名义浮点报告簇以兼容旧微分实验；真正事件读 `exact_contact_label/normal`。窗口 winner 为 core/shift 时，事件特征属于对应证书模型，不能直接解释成原实体的物理活动接触。非 Dual 冻结高度用原始有理未归一化平面比值，避免近竖直分母放大单位法向舍入。Dual 片内计算仍保留所有导数通道。

`escape_height_brute` 现在保留 bracket 签名但也走完整事件分区，**不再是独立 oracle**：非凸非单调路径不能用二分跳过更早分离区间。独立性由测试专用扫掠 SAT/oracle 提供。

首入的根、时刻比较、并列、t_max、深度平方均精确；t* 前自检使用完整事件前一区间的有理中点。非共面面的 `surface_label/surface_members` 保存三角限定，冻结应消费该视图；FF/FE 合并标签本身不由 frozen_normal 接受，须从 surface_members 选择原始 VF/FV/EE 成员；兼容 `label/members` 不是折面上的精确平面。`merge_degenerate` 只合并精确共面簇，微台阶门及恢复容差突变固定此边界。局部 `shortest_exit3` 不冒充任意凹体全局最短出口。

### 4. 缓存与等价优化

Polyhedron 保留可变外层 API；全部缓存按顶点与面内容签名失效，原地替换后不得复用旧凸视图。元门 `test_e5b_polyhedron_cache.py` 包含内部门缺失顶点签名突变。缓存不依赖对象 id。

精确布尔三角相交以平面切段/二维 SAT 取代构造交点集合；横截严格内部正证书仅提前返回经两原表面精确点包含复核的贯入，其余走完整 arrangement；已认证星核表面的四面体并集使用整数 SAT；点包含射线以清分母整数线性式替代 Fraction 交点构造。正窗口三角距离另加精确支撑平面距离下界：仅 `gap² > w²*n²` 才拒绝，等号仍进入闭窗口；`test_e5b_triangle_near.py` 同时逐值对拍旧全特征路径、独立闭式阈值，并用 `>` 改 `>=` 的内部突变钉住等号。没有浮点否决过滤。逐值旧路径对拍与不共用原语 oracle 见 `test_e5b_triangle_boolean.py`、`test_e5b_transverse_certificate.py`、`test_e5b_surface_integer.py`。margin/事件内容缓存有 cache-versus-uncached 输出对拍。

### 5. DDA / TIA 适配边界

适配器必须显式选择：(a) 默认精确按传入数据回报微贯入，或 (b) 将其物理/离散化接触厚度作为 `contact_window` 传入。库不能暗猜 ctol；不得把窗口相触当作原实体严格不贯入证明。保留源坐标、运动有理根与证书，显示/导出若必须舍入则对舍入后的实际数据重新判定；冻结使用精确 surface 特征而非非共面源环的拟合平面。姊妹三线本单只读，**未改适配器、未部署开关、未进行求解器标定/工程验证**。
