## 1. 两种几何对象，不暗中凸化凹块
一般 `Polyhedron(verts, faces)` 仍表示输入面环确定的闭合定向表面。非共面多边形按确定性投影耳切三角化成为折面；不能说舍入后的四个点仍然共面。凹多边形不能扇形填充凹口。

显式凸 API（convex_hull_3d、凸对 E、membership_convex3、local_facets3/G0）采用另一明确语义：**凸块等于输入顶点集的精确凸包**，输入面是来源/拓扑提示。舍入形成的微凹被凸包填平，微凸脊保留；不按噪声抹掉。一般相交 API 不能未经声明替换为凸包，尤其 L/U/互锁块绝不自动凸化。

选择凸包而非微凹拒收，是为了使显式凸 E 定理适用于舍入后的工程输入；代价是区分凸模型与给定表面模型。两模型只有在输入表面精确为凸时才能直接当作相同对象。重复点去重，共线边内点/共面面内点不能成为极点；零体积明确拒收。仅精确 orient3d=0 的相邻三角可以合并，不近似合并微二面角。

## 2. 编号与标签
一般表面 API 保持原始 face/edge/vertex 编号。显式凸路径使用缓存的 canonical convex view：尽量保留来源顶点编号；原面确实等于精确 supporting facet 时保留其编号，其他 facet 确定性排序，并记录输入面包含关系。非共面四边形可能对应多片 facet，也可能出现不属于任何输入面的新 facet，不能把整个四边形冒充一个平面。

凸路径 VF/FV/EE/VE3/EV3/VV3 标签属于同一 canonical view；解释标签的函数必须先解析同一 view。不能把 canonical face 下标直接用于原始 faces。一般单盖 API 按原始表面编号。跨模型比对使用精确支撑顶点集，不按近似法向配对。

## 3. 精确 E、局部规则及 G0 三票
凸 E = conv{b−a}。必须先有理化坐标再相减，不能将已舍入 sub(b,a) 当原问题的精确差点。支撑面用未归一化有理叉积；F_A=argmin n·a，F_B=argmax n·b。仿射维数精确，严格 facet 恰为维数组合 (0,2)、(2,0)、(1,1)；其他二维支撑和是退化 facet，不是 ambiguous。

局部命题4/5用原坐标派生未归一化棱/面法向，精确棱弧、顶点锥及锥的相对内部相交；不能把浮点单位方向再有理化冒充原始法锥。

G0 票一：独立有理数 SAT/表面相交对被测成员。平移也在有理数中相加，防止两票比较不同舍入对象。随机样本之外强制 E 顶点、每条棱有理中点、每个精确 facet 有理重心；内/外/边界全部计分。票二：独立差点凸包支撑集合与局部标签双向全量比较，漏/多一个都失败。票三：完整精确极点集等于局部锥交集，没有 ambiguous/low/low_e/高度豁免。oracle 不借用被测法向/棱弧/锥交原语；共用原始坐标和 Fraction 不算共用几何原语。

## 4. 一般三角化表面的成员与相交
点在三角形、线段−三角形、三角形−三角形用有理符号和闭区间。成员先查精确表面，再用精确射线奇偶；射线遇边/顶点退化换确定性整数方向，不能重试耗尽默认边界。

相交三态为分离 −1、仅边界相触 0、内部相交 1。必须覆盖没有顶点在对方内部的穿透及共面重叠，不能仅靠顶点包含或随机微推。凸表面可用精确 SAT；一般表面需要三角相交和局部体侧/内部见证。一般路径未完整验证时如实标未完成，不以改名宣称精确。

## 5. 域窗口与噪声带
调用方明确给出的搜索 window、贴合距离、角域扩张保留，只能增加候选，不能改变 strict/凸性/共面/零非零。兼容 tol>0 成员报告带必须有真实距离见证并与精确分类分离；tol=0 不加 noise_floor。

删除：凸包可见性/细条删除/极点吸收的噪声阈值、近似共面合并、G0 支撑带/ambiguous/low_e、锥交绝对重心阈值、近平行线独立浮点参数分支。noise_floor/face_noise 仅作可分辨性或构造误差报告，不作本单精确答案裁决。

## 6. 保守过滤与性能
orient3d 用浮点 determinant 和严格误差上界；只有 |det|>bound 才采纳符号，否则 Fraction。界覆盖相减/乘加误差及次正规/下溢绝对传播项，非有限中间值退路。Fraction 输入不得被 float 替代；允许保留原值并在过滤界内额外计入有理数到浮点转换误差，未证实则仍算原值。二维热点仅在不改精确构造和返回契约处加过滤/确定性缓存；LP 保留精确证书。

逐个对拍随机、共面、近平面、工程坐标、指数跨度、次正规。过滤界缩小10倍用真实错号见证击中，未找到就如实列未完成，不能伪造返回值。E5a2 全套目标 <=900 秒（理想 <=600 秒），交付实测而非预估。

## 8. WO-E5a2 已接线范围与仍不可推论的范围

### 一般闭表面

旧 `point_in_polyhedron`、`segment_crosses_face`、`polyhedra_overlap` 已调用有理表面路径。契约前提为有效、定向朝外、闭合、嵌入的有界表面；不声称自动修复自交、非流形或反向输入。凸 SAT 快路先证明输入每个三角平面对全部原顶点均为支撑平面，不能用凸包替换一般实体。

一般内部重叠：用对方所有三角平面分割每个三角面；共面时还按对方三角边直线分割。每个开二维单元内对方成员状态不变。非空有界三维交集必有一片开边界，或者位于另一实体内部，或者两表面共面且内侧一致。单元有理重心沿内向法线推进，步长是所有平面的首个正截距的一半；再以精确成员核验其同时在两体严格内部，得到证书，而不是随机微推。点成员用精确射线退化换向；线段接口只报告横穿，非共面折棱切向接触不应算穿透。门与内部突变见 `test_e5a2_surface.py` 及本单报告。

点的正 tol 是到三角表面的欧氏报告带；实体相交的正 tol **只在分离侧**报告表面距离带，真实内部重叠始终为 1。旧门中舍入后真实微贯入从“相触”转为内部，原输入/全部网格保留，以独立精确 oracle 迁移；margin 的贯入哨兵因此随之生效，但本单不宣称 margin 其余分支已精确。

### 一般单盖的有限解释（A2 选择允许的边界说明方案）

源面标签的 VF/FV 用 Newell 方向及通过首顶点的锚平面；域判据用主投影绕数；棱/顶点方向由源拓扑产生。对非平面环，这只是描述符：循环移动首顶点可以改变 gap，投影见证可能不在任意源三角面上。两个实值反例门固定此界限（`test_e5a2_covers.py`）；不可称其为三角化折面实体的完整法锥或真实接触见证。canonical convex-view 的标签域独立保留。

### 距离窗口与性能

枚举六类窗口用原坐标的精确平方距离，盖 gap/normal/witness 仍是构造输出。凸 E 正 tol 的内侧最短支撑平面距离等于边界距离；外侧支撑平面距仅是下界，剩余候选由 `conv({b-a-x})` 的精确最小范数点证书裁决。外角例及恢复平面带的真实内部突变有门。

性能优化没有引入新的浮点过滤或缓存层：三维 Fraction 点叉积延迟到最后一次规范化，独立 SAT 与凸成员平面用等价整数行，二维已为 Fraction 的符号用整数分子，EE 参数延后到锥接受之后。既有浮点/Dual 算术次序与独立 oracle 边界不变；逐值对拍、profile、实测和保留的 E5b 工作见 `reports/codex/E5a2_report.md`。本单禁止新 worktree，所有本树回归都不是正式独立六路 G6 退出。

### interlock 接线修正与缓存使用边界

精确实体三态揭示旧逃逸循环不能给同一舍入簇内的不同构造高度复用状态：低一格可能真贯入，高一格已经分离。E5a2 对不同高度分别核验；原候选簇均未通过时，仅在既有法向舍入报告带内构造一次上探，并核验**实际返回高度对应的原对象平移**不再贯入。返回高度是经过精确验收的浮点构造，winner/tied_labels 仍描述 nominal 簇，不声称全链精确首出或折面盖完备。桥接门 `test_e5a2_interlock_bridge.py`；原逃逸、候选和灵敏度门没有删格。

这些调用只消费 `state == 1`，由相交接口正 tol 仅改变分离侧 -1/0 的契约，使用零 tol 与正 tol 的贯入判定严格相同，可省去每次二分的欧氏近带距离。它不同于把微贯入重新吞成相触。

本单扩展既有内容寻址缓存的整数 payload，没有新增缓存层。串用门覆盖内容键及 canonical-self 对象变更；**不覆盖任意源对象原地修改**。交叉审查复现 HEAD 已有 `_convex_view` 对非 canonical 源对象修改后不失效的问题；当前应视输入为不变，修改后重建对象。修复上游缓存失效契约留给后续，不以本单对拍掩盖此限制。
